# Exploratory Data Analysis Cheat Sheet

## 1. Why do EDA?
* **Validate Assumptions:** Check if data matches project hypotheses.
* **Data Prep:** Guide feature engineering, handle missing values, and isolate outliers.
* **Modeling Foundation:** Select appropriate algorithms based on data traits.
* **Reporting:** Uncover initial trends for stakeholder analysis.

---

## 2. Statistical Foundations

### Data Distributions (Shapes)
* **Normal:** Symmetrical, bell-shaped (Mean = Median = Mode).
* **Skewed:** Asymmetrical. Right-skewed (tail points right); Left-skewed (tail points left).
* **Bimodal:** Has two distinct peaks (indicates two underlying subgroups).
* **Uniform:** Flat distribution; all outcomes have equal probability.

### Dispersion (Data Spread)
* **Range:** Max - Min (Highly sensitive to outliers).
* **Variance:** Average of squared deviations from the mean.
* **Standard Deviation:** Square root of variance (brings spread back to original data units).
* **IQR (Interquartile Range):** Q3 - Q1 (Spans the middle 50% of data; robust to outliers).

---

## 3. Univariate Analysis (One Column)

### Numerical Columns
1. **Descriptive Stats:** Check central tendency (mean/median) vs spread (std/IQR).
2. **Visualizations:** Use **Histograms** (shape), **KDE/Density plots** (smooth distribution), and **Box plots** (outliers).
3. **Outliers:** Identify anomalies via box plots or Z-scores; determine if they are errors or legitimate variations.
4. **Skewness Check:** Plan transformations (e.g., log, Box-Cox) if data is heavily skewed.

### Categorical Columns
1. **Frequency Distribution:** Compute structural counts/percentages per category (`value_counts()`).
2. **Visualizations:** Use **Bar/Count plots** (comparisons) or **Pie charts** (composition, if categories are < 5).
3. **Missing Values:** Isolate `NaN` fields; decide whether to drop or impute based on volume.

---

## 4. Bivariate Analysis (Two Columns)

Select two features -> Isolate their relationship type -> Visualize:

| Relationship Type | Key Visualizations | Statistical Metrics |
| :--- | :--- | :--- |
| **Numerical vs. Numerical** | Scatter plot, 2D Histogram, 2D KDE | Pearson/Spearman Correlation Coefficient (r) |
| **Numerical vs. Categorical** | Box plot, Violin plot, Faceted KDE, Bar plot | Grouped descriptive stats (`groupby().mean()`) |
| **Categorical vs. Categorical** | Heatmap, Stacked Bar plot | Contingency Table (`pd.crosstab()`), Chi-Square test |
