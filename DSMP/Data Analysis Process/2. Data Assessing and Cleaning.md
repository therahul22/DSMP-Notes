-   # The Two Dimensions of Unclean Data

    - **Dirty Data** (Quality/Content Issues: 
        Duplicates, missing values, corrupt inputs, or inaccurate entries.

    - **Messy Data** (Tidiness/Structural Issues): 
        Fails "Tidy" standards
            Variables must be columns, 
            observations must be rows, 
            observational units must be distinct tables.

Assessing Data is an Iterative Process
 
# Data Quality Dimensions
    - Completeness -> is data missing?
    - Validity -> is data invalid -> negative height -> duplicate patient id  
    - Accuracy -> data is valid but not accurate -> weight -> 1kg
    - Consistency -> both valid and accurate but written differently -> New York and NY  

-   # Data Quality Hierarchy (Order of Severity)
Completeness < Tidiness < Validity < Accuracy < Consistency
 
    - Steps Involved in Data Cleaning 
        Define problem and solution
        Code solution
        Test

-   #  Data Cleaning Workflow
    Always build a copy first: df_copy = df.copy(). 

    Fix Quality (Completeness)
    Fix Structure (Tidiness)
    Fix remaining Quality issues (Validity -> Accuracy -> Consistency)
