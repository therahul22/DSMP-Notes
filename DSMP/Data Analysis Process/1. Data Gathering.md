#Data Gathering & Data Analysis Process

## 1. The Data Analysis Process
Data analysis is the process of inspecting, cleansing, transforming, and modeling data to discover useful information, inform conclusions, and support decision-making. The process typically involves five non-linear steps:

1. **Asking Questions:** Understanding the problem and defining what you want to achieve.
   * *What features will help the analysis?*
   * *What features are not important?*
   * *What kind of feature manipulation is required?*
   * *Identifying correlations.*
2. **Data Wrangling (Munging/Pre-processing):** This step often takes the most time (~70%). It involves:
   * **Gathering:** Acquiring data from various sources (CSV, Excel, JSON, SQL databases, APIs, Web Scraping).
   * **Assessing:** Getting a high-level overview of the data (shape, columns, missing values).
   * **Cleaning:** Handling missing values, removing duplicates, correcting data types, etc.
3. **Exploratory Data Analysis (EDA):** Discovering patterns and insights.
   * **Exploring:** Value counts, plotting graphs (histograms, scatter plots), finding correlations.
   * **Augmenting (Feature Engineering):** Removing outliers, merging datasets, creating new columns.
4. **Drawing Conclusions:** Answering the initial questions using:
   * Machine Learning (for predictions).
   * Inferential Statistics (for population-level inferences).
   * Descriptive Statistics (for summarizing the data).
5. **Communicating Results (Data Storytelling):** Presenting findings to stakeholders.
   * Using data visualization techniques.
   * Presenting via in-person meetings, reports, or PPTs.

## 2. Importing Data from Various Sources

### A. Importing CSV Files
The `pd.read_csv()` function is highly versatile for loading tabular data.

* **Basic Loading:**
  ```python
  import pandas as pd
  df = pd.read_csv('filename.csv')
  ```
* **Loading from a URL:**
  ```python
  import requests
  from io import StringIO
  import pandas as pd

  url = "your_url_here"
  headers = {"User-Agent": "Mozilla/5.0"} # Prevents rejection by some servers
  req = requests.get(url, headers=headers)
  data = StringIO(req.text)
  df = pd.read_csv(data)
  ```
* **Key `pd.read_csv` Parameters:**
  * `sep`: Specify the separator (e.g., `sep='	'` for TSV files).
  * `names`: Provide custom column names if the file lacks headers (e.g., `names=['Col1', 'Col2']`).
  * `header`: Specify which row to use as column names (e.g., `header=1` if the first row is metadata).
  * `usecols`: Load only specific columns (e.g., `usecols=['Name', 'Age']`).
  * `squeeze`: Return a Series instead of a DataFrame if only one column is selected.
  * `skiprows` / `nrows`: Skip specific rows or restrict the total number of rows loaded.
  * `encoding`: Handle different character encodings (e.g., `encoding='latin-1'`).
  * `on_bad_lines`: Skip lines with incorrect formatting (e.g., `on_bad_lines='skip'`).
  * `dtype`: Specify data types for columns to save memory (e.g., `dtype={'Age': int}`).
  * `parse_dates`: Convert specific columns to datetime objects (e.g., `parse_dates=['Date']`).
  * `converters`: Apply custom functions to columns during import.
  * `na_values`: Define custom strings to be recognized as NaN (e.g., `na_values=['-', 'N/A']`).
  * `chunksize`: Load massive datasets in smaller chunks to avoid RAM overflow.

### B. Importing Excel Files

### C. Importing JSON Files
JSON (JavaScript Object Notation) is heavily used with APIs.
```python
df = pd.read_json('filename_or_url.json')
```

### D. Importing SQL Files
Requires an intermediary library (like `mysql.connector`) to bridge Python and the database.
1. Set up a local server environment (e.g., XAMPP) and import the `.sql` file into a database (e.g., MySQL).
2. Install the connector: `pip install mysql-connector-python`
3. Connect and query:
```python
import mysql.connector
import pandas as pd

conn = mysql.connector.connect(host='localhost', user='root', password='', database='your_db_name')
df = pd.read_sql_query("SELECT * FROM table_name", conn)
```

## 3. Exporting Data
Pandas allows exporting DataFrames to multiple formats using `to_*` methods.

* **To CSV:** `df.to_csv('filename.csv', index=False)`
* **To Excel:** `df.to_excel('filename.xlsx')`
  * *Multiple Sheets:*
    ```python
    with pd.ExcelWriter('filename.xlsx') as writer:
        df1.to_excel(writer, sheet_name="Sheet1")
        df2.to_excel(writer, sheet_name="Sheet2")
    ```
* **To JSON:** `df.to_json('filename.json')`
* **To HTML:** `df.to_html('filename.html')`
* **To SQL:**
  ```python
  from sqlalchemy import create_engine
  # Format: "mysql+pymysql://username:password@host/database_name"
  engine = create_engine("mysql+pymysql://root:@localhost/your_db_name")
  df.to_sql('table_name', con=engine, if_exists='append', index=False)
  ```

## 4. Web Scraping & APIs

### Fetching Data via APIs
APIs allow structured communication between software systems.
```python

import pandas as pd

url = "api_endpoint_url"
response = requests.get(url)
data = response.json() # Extract JSON data
# ... parse the JSON dictionary/list to build a DataFrame ...
```

### Web Scraping using BeautifulSoup
When an API isn't available, you can extract data directly from the HTML structure of a webpage.
```python
import requests
from bs4 import BeautifulSoup

# Define headers to mimic a browser
custom_headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36",
}

# 1. Fetch HTML content
webpage = requests.get('url_here', headers=custom_headers).text

# 2. Parse HTML
soup = BeautifulSoup(webpage, 'lxml')

# 3. Extract elements (Example: Finding all container divs)

## Find the first <h1> tag
heading = soup.find('h1')
containers = soup.find_all('div', class_='container_class_name')

## Find all <a> (anchor) tags
all_links = soup.find_all('a') 

## Find the first 3 <p> tags
paragraphs = soup.find_all('p', limit=3)
