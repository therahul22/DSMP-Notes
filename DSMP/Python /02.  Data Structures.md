## 1. List Architecture & Memory Model 💡 *(Interview Topic)*

In Python, a `list` is defined using square brackets `[]` and can store heterogeneous data types simultaneously:
```python
my_list = [1, 2, True, 'hi']
```

### Lists vs. Arrays (C/C++ Style)
| Feature | Python List | Traditional Array (e.g., C/C++, NumPy) |
| :--- | :--- | :--- |
| **Data Homogeneity** | **Heterogeneous:** Holds mixed data types | **Homogeneous:** Holds elements of a single type |
| **Size / Sizing** | **Dynamic Size:** Grows/shrinks automatically | **Fixed Size:** Allocation size fixed at creation |
| **Execution Speed** | **Slower:** Overhead from pointer dereferencing | **Fast:** Continuous, direct memory access |
| **Memory Footprint** | **Higher:** Stores pointers + object headers | **Lower:** Stores raw bytes contiguously |

### How Lists Work Internally (Referential Arrays)
* Python lists do **not** store the actual data values directly inside the list array structure.
* Instead, a list is a **Referential Array** — an array of **memory addresses (pointers)**, where each pointer refers to an object stored elsewhere in Python's Heap memory.
* **Dynamic Capacity Strategy:** When a list runs out of allocated space during insertions (e.g., via `append`), Python dynamically allocates a larger block of contiguous memory (typically doubling or expanding by an over-allocation factor) and copies the existing element references over.

### Checking Object Identity
Use the built-in `id()` function to inspect the memory address of an object:
```python
x = 10
print(id(x))  # Displays unique memory address of x
```

### Typecasting to List
Passing an iterable (like a string, tuple, or set) to `list()` converts it into a list of individual items:
```python
print(list('hello'))  # Output: ['h', 'e', 'l', 'l', 'o']
```

## 2. Indexing, Slicing & Mutability

### Positive & Negative Indexing
* **Positive Indexing:** `0` to `len(L) - 1` (Left-to-Right)
* **Negative Indexing:** `-1` to `-len(L)` (Right-to-Left, where `-1` is the last element)

### Slicing Syntax
$$\text{L}[\text{start} : \text{end} : \text{step}]$$
* **`start`:** Inclusive start index.
* **`end`:** Exclusive end index (stops at `end - 1`).
* **`step` (jump):** Direction and stride of slicing (e.g., `-1` reverses the list).

```python
nums = [0, 10, 20, 30, 40, 50]
print(nums[1:4])    # Output: [10, 20, 30]
print(nums[::-1])   # Output: [50, 40, 30, 20, 10] (Reversed copy)
```

## 3. Adding, Editing & Deleting Items

### Adding Elements
* **`L.append(item)`:** Adds a **single** element to the end of the list. If you pass a list, it appends the list as a single nested object.
* **`L.extend(iterable)`:** Iterates over the input and appends each element individually (**merges** multiple items).
* **`L.insert(index, item)`:** Inserts an item at a specific target index, shifting existing items to the right.

### Editing Elements
Lists are **mutable**. Modify elements in place via index or slice assignment:
```python
L = [10, 20, 30, 40]
L[0] = 99         # L is now [99, 20, 30, 40]
L[1:3] = [200, 300] # L is now [99, 200, 300, 40]
```

### Deleting Elements
* **`del L[index]` or `del L[start:end]`:** Keywords to delete elements by index/slice, or delete an entire variable reference from memory (`del L`).
* **`L.remove(value)`:** Searches for and removes the **first occurrence** of a specified value. Raises `ValueError` if the item is not found.
* **`L.pop(index=-1)`:** Removes and **returns** the element at the specified index (defaults to deleting and returning the last item).
* **`L.clear()`:** Deletes **all** elements, leaving the list object empty (`[]`).

## 4. List Operations & Iteration

### Arithmetic Operators
* **Concatenation (`+`):** Merges two lists into a brand-new list object.
  ```python
  [1, 2] + [3, 4]  # Output: [1, 2, 3, 4]
  ```
* **Replication (`*`):** Repeats the list $N$ times.
  ```python
  [1, 2] * 3  # Output: [1, 2, 1, 2, 1, 2]
  ```

### Iterating Over Lists
```python
L = ["apple", "banana", "cherry"]

# Direct Element Iteration
for item in L:
    print(item)

# Index-based Iteration
for idx in range(len(L)):
    print(idx, L[idx])
```

## 5. Sorting & Reversing Mechanics 💡 *(Interview Topic)*

> ❓ **Interview Question: What is the difference between `L.sort()` and `sorted(L)`?**
>
> **Answer:**
> * **`L.sort()` (In-Place Mutation):** Sorts the list in-place and returns `None`. The original order of `L` is permanently modified.
> * **`sorted(L)` (Pure Function):** Leaves the original list `L` completely unchanged and returns a **new sorted copy** of the list.

```python
# Permanent In-Place Operations
L = [3, 1, 4, 2]
L.sort()      # L is now permanently [1, 2, 3, 4]
L.reverse()   # L is now permanently [4, 3, 2, 1]

# Non-Destructive Operation
original = [3, 1, 4, 2]
new_list = sorted(original) # original remains [3, 1, 4, 2], new_list is [1, 2, 3, 4]
```

## 6. List Comprehension

**List Comprehension** provides a concise, Pythonic syntax to create lists from existing iterables. It is faster than standard `for` loops because the loop iteration is executed at C-level speed inside Python.

### Syntax
```python
[expression for item in iterable if condition]
```

### Common Code Patterns

#### 1. Basic Transformation
```python
# Create a list of squares from 0 to 4
squares = [x**2 for x in range(5)]
# Output: [0, 1, 4, 9, 16]
```

#### 2. Filtering with `if`
```python
# Extract even numbers
evens = [x for x in range(10) if x % 2 == 0]
# Output: [0, 2, 4, 6, 8]
```

#### 3. Conditional Replacement (`if-else`)
```python
# Label numbers as 'Even' or 'Odd'
labels = ["Even" if x % 2 == 0 else "Odd" for x in range(5)]
# Output: ['Even', 'Odd', 'Even', 'Odd', 'Even']
```
