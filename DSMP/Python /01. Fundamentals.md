## 1. Core Concepts & Execution

* **Dynamic Typing vs. Static Typing** 💡 *(Interview Topic)*
  * *Static:* Type checking happens at compile-time (e.g., C++, Java). You must declare variable types explicitly.
  * *Dynamic:* Type checking happens at runtime (e.g., Python). Variable types are resolved dynamically as code executes.
* **Dynamic vs. Static Binding** 💡 *(Interview Topic)*
  * *Static (Early):* Method/function calls are resolved at compile-time.
  * *Dynamic (Late):* Method/function calls are resolved at runtime based on the actual object type (e.g., method overriding in Python).
* **Compilation & Execution:**
  * Source code is converted into bytecode / machine instructions (0s and 1s).
  * **Interpreter:** Executes code line-by-line (e.g., standard CPython execution step).
  * **Compiler:** Translates the entire source code in one go before execution (e.g., C++ `g++`).
* **Type Conversion:**
  * *Implicit:* Python automatically converts smaller types to larger types (e.g., `3 + 2.0` becomes `5.0`).
  * *Explicit (Typecasting):* Explicitly calling functions like `int()`, `float()`, `str()`.

## 3. Modules & Packages 💡 *(Interview Topic)*

### Modules
* Any independent file with a `.py` extension is called a **module** in Python.
* Modules in Python are conceptually similar to header files or libraries in C++ (pre-written, reusable code logic, e.g., the `math` module for sine waves).

> ❓ **Interview Question: What does `if __name__ == '__main__':` mean?**
>
> **Answer:** 
> * Python sets the special built-in variable `__name__` to `'__main__'` **only** for the file that is currently being executed directly from the entry point.
> * If a file is imported as a module into another script, its `__name__` variable takes on the actual filename (e.g., `'my_module'`).
> * Using `if __name__ == '__main__':` ensures that code inside that block executes **only** when the file is run directly, and **not** when it is imported elsewhere.

### Packages
* A directory/folder containing related modules and sub-packages.
* A directory is treated as a Python package if it contains an `__init__.py` file.
* The `__init__.py` file can either be empty or contain package-level initialization code.

## 4. Control Flow, Encoding & Boolean Logic

* **Loops:** Used for repeating execution blocks (`for`, `while`). Supported by `break` (exit loop) and `continue` (skip to next iteration).
* **Encoding Standard:**
  * **ASCII:** 7 or 8-bit encoding covering standard English characters.
  * **Unicode:** Flexible encoding (e.g., UTF-8 / UTF-16) covering global character sets, symbols, and emojis.
* **String Comparison:** Comparison operators (`>`, `<`) compare strings character-by-character based on their underlying ASCII/Unicode code point values (e.g., `'a' > 'A'` is `True` because ASCII value `97 > 65`).
* **Truthy / Falsy Strings:**
  * Empty string `""` evaluates to `False`.
  * Any non-empty string evaluates to `True`.
* **Logical Operator Evaluations (`or` / `and`):**
  * `'hello' or 'world'` $\rightarrow$ `'hello'` *(Short-circuits on the first Truthy value)*
  * `'hello' and 'world'` $\rightarrow$ `'world'` *(Evaluates both, returning the last evaluated value)*

> ❓ **Problem: Calculate the acute angle between the Hour and Minute hands of a clock**
> 
> **Solution / Formula:**
> Given time as `H` hours and `M` minutes:
> * Hour hand movement rate: $0.5^\circ$ per minute ($30^\circ$ per hour).
> * Minute hand movement rate: $6^\circ$ per minute.
>
> $$\text{Angle} = |(30 \times H + 0.5 \times M) - (6 \times M)| = |30H - 5.5M|$$
>
> To find the smaller (acute) angle: $\min(\text{Angle}, 360^\circ - \text{Angle})$.

* **Key Built-in Functions & Concepts:**
  * `enumerate(iterable)`: Yields pairs of `(index, item)` while iterating.
  * **Lambda Functions:** Anonymous single-expression functions syntax: `lambda arguments: expression`.
  * **Common Sequence Functions:** `len()`, `min()`, `max()`, `sorted()`.
