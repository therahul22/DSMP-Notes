# Chi-Square Distribution & Hypothesis Testing

## 1. The Chi-Square ($\chi^2$) Distribution
* It is a continuous probability distribution used extensively in statistical hypothesis testing.
* It arises when you sum the squares of independent standard normal random variables.
* **Parameter:** It relies entirely on a single parameter called Degrees of Freedom ($df$).
* **Key Properties:**
    * It is defined strictly for non-negative values ($x \ge 0$).
    * It is positively skewed, but the skewness decreases as the degrees of freedom increase.
    * The mean of the distribution is exactly equal to its $df$.
    * The variance is exactly equal to twice its $df$ ($2 \times df$).
    * As the degrees of freedom become very large, its shape closely approaches a standard normal distribution.

---

## 2. Chi-Square Goodness-of-Fit Test
* This test determines if the observed frequency distribution of a single categorical variable matches an expected theoretical distribution.
* Used to verify if your sample data follows a specific distribution (e.g., uniform, binomial, or Poisson).
* It is a non-parametric test, meaning it does not make assumptions about underlying population parameters like the mean or standard deviation.
* **The Hypotheses:**
    * $H_0$: The observed data perfectly follows the expected theoretical distribution.
    * $H_1$: The observed data does not follow the expected distribution.
* **The Formula:** $$\chi^2 = \sum \frac{(O_i - E_i)^2}{E_i}$$
    * $O_i$ = Observed frequency count for category $i$.
    * $E_i$ = Expected frequency count for category $i$.
* **Degrees of Freedom:** $df = k - 1$ (where $k$ is the total number of categories).
* **Key Assumptions to Check:**
    1. **Independence:** The observations must be completely independent of each other.
    2. **Categorical Data:** The variable being analyzed must be grouped into mutually exclusive nominal or ordinal categories.
    3. **Minimum Expected Frequency:** Each category must have an expected frequency ($E_i$) of at least 5 to ensure accuracy and prevent an inflation of Type I or Type II errors.

---

## 3. Chi-Square Test for Independence
* This test determines whether there is a statistically significant association between two distinct categorical variables.
* It evaluates if the occurrence of one variable depends on the occurrence of another, or if they are completely independent.
* Compares the observed cell counts in a cross-tabulation table (contingency table) against the counts expected if the variables had no relationship.
* **The Hypotheses:**
    * $H_0$: There is no association between the two categorical variables (they are independent).
    * $H_1$: There is a significant association between the two categorical variables (they are dependent).
* **Degrees of Freedom:** $$df = (\text{Number of Rows} - 1) \times (\text{Number of Columns} - 1)$$
* **Key Assumptions to Check:**
    1. **Independence of Observations:** The data points must be independent, typically gathered via simple random sampling.
    2. **Strictly Categorical:** Both variables must be categorical. This test cannot handle continuous metrics directly.
    3. **Adequate Sample Size:** The expected frequency for *every single cell* in your contingency table must be at least 5. If it falls below 5, the test becomes invalid and an alternative like Fisher's Exact Test must be used.
    4. **Fixed Marginal Totals:** The row and column sums should be fixed before data collection to avoid bias.

---

## 4. Applications in Machine Learning
* **Feature Selection:** Functions as a filter-based feature selection method to rank and select the most relevant categorical features relative to a categorical target variable, allowing you to drop redundant variables.
* **Confusion Matrix Evaluation:** Applied to multi-class classification problems to compare observed vs. expected class distributions within a confusion matrix to evaluate a model's goodness of fit.
* **Exploratory Data Analysis (EDA):** Identifies underlying dependency structures between input attributes to guide downstream feature engineering.
* **Discretization (Binning):** Helps determine the optimal intervals or number of bins when converting continuous features into categorical features based on relationship strengths with the target.
* **Decision Trees:** Used directly by specialized tree-building algorithms (such as CHAID) to mathematically determine the most significant categorical attributes to split on at each node.

## 5. Case Study: Chi-Square Goodness-of-Fit Test

### Scenario
A streaming platform uses an AI recommendation algorithm to suggest 5 music genres (Lo-Fi, Synthwave, Acoustic, Progressive Rock, and Jazz) to users during study hours. The product team assumes that users select these 5 genres equally, which means the data should follow a **Uniform Distribution**. 

To test this, you track a random sample of 200 users and record the genre they choose to stream first. You want to see if the actual user choices match the expected uniform distribution.



### Step 1: Formulate the Hypotheses
* **Null Hypothesis ($H_0$):** User genre choices follow a uniform distribution (every genre is equally likely to be picked).
* **Alternative Hypothesis ($H_a$):** User genre choices do not follow a uniform distribution.
* **Why we do this step:** We must explicitly state our baseline assumption of "no difference" ($H_0$) and the new pattern we are trying to prove ($H_a$).

### Step 2: Select the Significance Level
* We set $\alpha = 0.05$.
* **Why we do this step:** This establishes our error tolerance. We will only reject the null hypothesis if there is less than a 5% probability that our observed differences happened by pure random chance.

### Step 3: Calculate Expected Frequencies & Check Assumptions
* **Total sample ($N$):** 200 users.
* **Number of categories ($k$):** 5 genres.
* **Expected Frequency ($E$):** If distributed uniformly, each genre should get exactly $\frac{200}{5} = 40$ streams.
* **Assumption Check:** 1. The data is strictly categorical (nominal genres).
    2. Every expected frequency is 40, which easily satisfies the rule of being $\ge 5$.
* **Why we do this step:** We must calculate what a "perfectly uniform" world looks like to compare it to our real world, and ensure our sample size is large enough so the test math remains valid.

### Step 4: Collect Observed Data and Compute the Test Statistic ($\chi^2$)
Suppose your tracking script collects the following **Observed ($O$)** counts:
* Lo-Fi: 55 | Synthwave: 45 | Acoustic: 30 | Progressive Rock: 42 | Jazz: 28

Now apply the formula: $\chi^2 = \sum \frac{(O_i - E_i)^2}{E_i}$

$$\chi^2 = \frac{(55-40)^2}{40} + \frac{(45-40)^2}{40} + \frac{(30-40)^2}{40} + \frac{(42-40)^2}{40} + \frac{(28-40)^2}{40}$$
$$\chi^2 = \frac{225}{40} + \frac{25}{40} + \frac{100}{40} + \frac{4}{40} + \frac{144}{40} = \frac{498}{40} = 12.45$$

* **Why we do this step:** The score of `12.45` mathematically quantifies the total squared deviation between reality and our uniform assumption. A higher score means reality looks vastly different from the hypothesis.

### Step 5: Determine Degrees of Freedom & Find the P-Value
* **Degrees of Freedom ($df$):** $k - 1 = 5 - 1 = 4$.
* Using a Chi-Square distribution table or code with $df = 4$ and a test statistic of $12.45$, the resulting **P-value is `0.014`**.
* **Why we do this step:** The shape of the Chi-Square curve changes based on the number of categories ($df$). We need the $df$ to find the exact probability (P-value) of getting a score of 12.45 or worse on that specific curve.

### Step 6: Make the Decision & Interpret
* **Decision:** Since **P-value (0.014) < $\alpha$ (0.05)**, we **Reject $H_0$**.
* **Conclusion:** The user choices do not follow a uniform distribution. 
* **What to keep in mind:** The recommendation algorithm shouldn't treat all 5 genres equally. The data proves a real preference exists, meaning the backend should favor the higher-performing genres like Lo-Fi.

## 6. Case Study: Chi-Square Test for Independence

### Scenario
You want to see if a user's **Subscription Plan** (Free Tier vs. Premium Tier) has a significant association with their **Device Preference** (Desktop, Mobile, or Tablet). You want to know if certain device users are more likely to upgrade, or if device type and subscription plans are completely independent.

You pull a random sample of 300 users.

### Step 1: Formulate the Hypotheses
* **Null Hypothesis ($H_0$):** Subscription Plan and Device Preference are independent (there is no association).
* **Alternative Hypothesis ($H_a$):** Subscription Plan and Device Preference are dependent (associated).

### Step 2: Select the Significance Level
* We set $\alpha = 0.05$.

### Step 3: Create the Contingency Table (Observed Data)
You arrange your raw data into a cross-tabulation grid and sum up the rows and columns:

| Subscription Plan | Desktop | Mobile | Tablet | **Row Total** |
| :--- | :---: | :---: | :---: | :---: |
| **Free Tier** | 70 | 90 | 20 | **180** |
| **Premium Tier** | 50 | 40 | 30 | **120** |
| **Column Total** | **120** | **130** | **50** | **Grand Total: 300** |

* **Why we do this step:** For a test of independence, we must look at the intersection of two distinct categorical fields simultaneously. 

### Step 4: Calculate Expected Frequencies for Every Cell
If the plan type and device type are truly independent, the expected count for any cell is calculated as: 
$$E = \frac{\text{Row Total} \times \text{Column Total}}{\text{Grand Total}}$$

* *Expected Free + Desktop:* $(180 \times 120) / 300 = 72$
* *Expected Free + Mobile:* $(180 \times 130) / 300 = 78$
* *Expected Free + Tablet:* $(180 \times 50) / 300 = 30$
* *Expected Premium + Desktop:* $(120 \times 120) / 300 = 48$
* *Expected Premium + Mobile:* $(120 \times 130) / 300 = 52$
* *Expected Premium + Tablet:* $(120 \times 50) / 300 = 20$

* **Assumption Check:** Every calculated expected value is $\ge 5$. The assumption holds.
* **Why we do this step:** This mathematically calculates what the grid values *should* have been if there was absolutely zero relationship between owning a premium account and using a specific device type.

### Step 5: Compute the Chi-Square Test Statistic ($\chi^2$)
Compare every observed cell to its corresponding expected cell using the formula: $\sum \frac{(O - E)^2}{E}$

$$\chi^2 = \frac{(70-72)^2}{72} + \frac{(90-78)^2}{78} + \frac{(20-30)^2}{30} + \frac{(50-48)^2}{48} + \frac{(40-52)^2}{52} + \frac{(30-20)^2}{20}$$
$$\chi^2 = 0.055 + 1.846 + 3.333 + 0.083 + 2.769 + 5.000 = 13.086$$

### Step 6: Calculate Degrees of Freedom & P-Value
* **Degrees of Freedom ($df$):** $(\text{Rows} - 1) \times (\text{Columns} - 1) = (2 - 1) \times (3 - 1) = 1 \times 2 = 2$.
* Using the Chi-Square distribution for $df = 2$ with a score of $13.086$, the **P-value is `0.0014`**.

### Step 7: Final Decision & Interpretation
* **Decision:** Since **P-value (0.0014) < $\alpha$ (0.05)**, we **Reject $H_0$**.
* **Conclusion:** Subscription plans and device types are significantly associated. 
* **ML Application:** Because a strong relationship exists, "Device Type" is an excellent, predictive categorical feature to select and feed into a binary classification model designed to predict user conversions.
