# Chi-Square Distribution & Hypothesis Testing

## 1. The Chi-Square ($\chi^2$) Distribution
* It is a continuous probability distribution used extensively in statistical hypothesis testing.
* It arises when you sum the squares of independent standard normal random variables.
* **Parameter:** It relies entirely on a single parameter called Degrees of Freedom ($df$).
* **Key Properties:**
    * It is defined strictly for non-negative values ($x \ge 0$).
    * It is positively skewed, but the skewness decreases as the degrees of freedom increase.
    * The mean of the distribution is exactly equal to its $df$.
    * The variance is exactly equal to twice its $df$ ($2 \times df$).
    * As the degrees of freedom become very large, its shape closely approaches a standard normal distribution.

---

## 2. Chi-Square Goodness-of-Fit Test
* This test determines if the observed frequency distribution of a single categorical variable matches an expected theoretical distribution.
* Used to verify if your sample data follows a specific distribution (e.g., uniform, binomial, or Poisson).
* It is a non-parametric test, meaning it does not make assumptions about underlying population parameters like the mean or standard deviation.
* **The Hypotheses:**
    * $H_0$: The observed data perfectly follows the expected theoretical distribution.
    * $H_1$: The observed data does not follow the expected distribution.
* **The Formula:** $$\chi^2 = \sum \frac{(O_i - E_i)^2}{E_i}$$
    * $O_i$ = Observed frequency count for category $i$.
    * $E_i$ = Expected frequency count for category $i$.
* **Degrees of Freedom:** $df = k - 1$ (where $k$ is the total number of categories).
* **Key Assumptions to Check:**
    1. **Independence:** The observations must be completely independent of each other.
    2. **Categorical Data:** The variable being analyzed must be grouped into mutually exclusive nominal or ordinal categories.
    3. **Minimum Expected Frequency:** Each category must have an expected frequency ($E_i$) of at least 5 to ensure accuracy and prevent an inflation of Type I or Type II errors.

---

## 3. Chi-Square Test for Independence
* This test determines whether there is a statistically significant association between two distinct categorical variables.
* It evaluates if the occurrence of one variable depends on the occurrence of another, or if they are completely independent.
* Compares the observed cell counts in a cross-tabulation table (contingency table) against the counts expected if the variables had no relationship.
* **The Hypotheses:**
    * $H_0$: There is no association between the two categorical variables (they are independent).
    * $H_1$: There is a significant association between the two categorical variables (they are dependent).
* **Degrees of Freedom:** $$df = (\text{Number of Rows} - 1) \times (\text{Number of Columns} - 1)$$
* **Key Assumptions to Check:**
    1. **Independence of Observations:** The data points must be independent, typically gathered via simple random sampling.
    2. **Strictly Categorical:** Both variables must be categorical. This test cannot handle continuous metrics directly.
    3. **Adequate Sample Size:** The expected frequency for *every single cell* in your contingency table must be at least 5. If it falls below 5, the test becomes invalid and an alternative like Fisher's Exact Test must be used.
    4. **Fixed Marginal Totals:** The row and column sums should be fixed before data collection to avoid bias.

## 4. Applications in Machine Learning
* **Feature Selection:** Functions as a filter-based feature selection method to rank and select the most relevant categorical features relative to a categorical target variable, allowing you to drop redundant variables.
* **Confusion Matrix Evaluation:** Applied to multi-class classification problems to compare observed vs. expected class distributions within a confusion matrix to evaluate a model's goodness of fit.
* **Exploratory Data Analysis (EDA):** Identifies underlying dependency structures between input attributes to guide downstream feature engineering.
* **Discretization (Binning):** Helps determine the optimal intervals or number of bins when converting continuous features into categorical features based on relationship strengths with the target.
* **Decision Trees:** Used directly by specialized tree-building algorithms (such as CHAID) to mathematically determine the most significant categorical attributes to split on at each node.
