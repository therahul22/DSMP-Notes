# Applied Statistics for Machine Learning: Core Notes

## 1. Data Foundations & Types
Understanding underlying data structures is the first step before feeding data into any model or analysis pipeline.

* **Population vs. Sample:** A population is the complete set of observations, while a sample is a subset used to estimate population characteristics.
* **Categorical (Qualitative) Data:**
    * **Nominal:** No inherent order (e.g., gender, categories).
    * **Ordinal:** Ordered categories (e.g., rankings like bad, average, good).
* **Numerical (Quantitative) Data:**
    * **Discrete:** Countable values (e.g., age, rank).
    * **Continuous:** Measurable values (e.g., weight, height).

---

## 2. Measures of Central Tendency
These metrics identify the typical or central value for a dataset.

* **Mean:** The mathematical average. It is highly sensitive to outliers.
    * Population Mean: $\mu = \frac{\sum_{i=1}^{N} x_i}{N}$
    * Sample Mean: $\bar{x} = \frac{\sum_{i=1}^{n} x_i}{n}$
* **Weighted Mean:** Used when values have different importance or frequency.
* **Trimmed Mean:** Calculated by removing a certain percentage of the smallest and largest values before averaging. Useful for handling outliers robustly.
* **Median:** The middle value of a sorted dataset. Robust to outliers.
* **Mode:** The most frequently occurring value.

---

## 3. Dispersion & Variability
Understanding how data spreads is critical for feature scaling and identifying anomalies.

* **Range:** The difference between the maximum and minimum values.
* **Variance:** The average of squared differences from the mean. It measures average distance but heavily penalizes large deviations.
    * Population Variance: $\sigma^2$
    * Sample Variance: $s^2 = \frac{\sum (x - \bar{x})^2}{n - 1}$
* **Standard Deviation (SD):** The square root of variance ($\sigma$ or $s$). It brings the unit back to the original scale.
* **Coefficient of Variation (CV):** The ratio of SD to the mean, expressed as a percentage. Useful for comparing the variability of datasets with drastically different scales.
    * Formula: $\frac{\sigma}{\mu} \times \mathbf{100\%}$

---

## 4. Position, Outliers & Bivariate Analysis
* **Quantiles & Percentiles:** Divide sorted data into equal-sized groups. The location of a percentile $p$ is calculated as $PL = \frac{p}{100} (N+1)$.
* **The 5-Number Summary & Boxplots:** Visualizes the Minimum, Q1 (25th percentile), Median (Q2), Q3 (75th percentile), and Maximum.
    * **Interquartile Range (IQR):** The spread of the middle 50%, calculated as $Q_3 - Q_1$.
    * **Outliers:** Values falling below $Q_1 - 1.5 \times \text{IQR}$ or above $Q_3 + 1.5 \times \text{IQR}$.
* **Covariance:** Measures the direction of a linear relationship between two variables (positive means they move together, negative means opposite). However, its magnitude is unscaled.
* **Correlation:** A normalized measure (from **-1** to **1**) quantifying both the direction and strength of a relationship. Calculated as $\frac{Cov(x,y)}{\sigma_x \sigma_y}$. (Note: Correlation does not imply causation).

---

## 5. Random Variables & Probability Distributions
Distributions form the mathematical backbone of probabilistic ML models and generative systems.

* **Random Variables (RV):** A set of possible values from a random experiment. Can be Discrete (e.g., coin toss) or Continuous.
* **Probability Mass Function (PMF):** For discrete RVs. Assigns a specific, non-negative probability to each possible value. All probabilities sum to **1**.
* **Probability Density Function (PDF):** For continuous RVs. The probability of an exact point is **0**; instead, probability is represented by the area under the curve between two points (found via integration).
* **Cumulative Distribution Function (CDF):** Defines the probability that a random variable $X$ will take a value less than or equal to $x$ (i.e., $P(X \le x)$).

---

## 6. Density Estimation (DE)
Techniques used to estimate the underlying probability density function based on raw data observations.

* **Parametric Density Estimation:** Assumes data follows a specific mathematical distribution (e.g., Normal, Poisson). You calculate parameters (like $\mu$ and $\sigma$) from the sample to define the entire curve.
* **Non-Parametric Density Estimation (KDE):** Used when the distribution is unknown or complex. Kernel Density Estimation (KDE) smoothes out data points using a kernel function to create a continuous density estimate without rigid mathematical assumptions.
