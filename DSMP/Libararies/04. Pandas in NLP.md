## 2. Text Cleaning (Pandas Vectorized Transformations)

Text data collected from web scrapes or user input often contains noise like HTML markup, URLs, and arbitrary casing. Cleaning standardizes the input before modeling.

```python
import pandas as pd
import re

# Mock Dataset
df = pd.DataFrame({
    'review': [
        '  <p>Great movie! Check out [http://example.com](http://example.com) for more info...</p>  ',
        'BAD experience, completely waste of money!!!',
        'I loved the acting, it was totaly awsum!  '
    ],
    'sentiment': ['positive', 'negative', 'positive']
})
```

### 1. Lowercasing & Space Strip
```python
# Convert all text to lowercase and remove leading/trailing whitespace
df['clean_review'] = df['review'].str.lower().str.strip()
```

### 2. Removing HTML Tags & URLs (Using Regular Expressions)
```python
# HTML Tag Removal: Matches anything inside <...>
df['clean_review'] = df['clean_review'].str.replace(r'<[^>]*>', '', regex=True)

# URL Removal: Matches http/https or www patterns
url_pattern = r'https?://\S+|www\.\S+'
df['clean_review'] = df['clean_review'].str.replace(url_pattern, '', regex=True)
```

### 3. Abbreviation Expansion & Spelling Correction
```python
# Custom mapping for abbreviation expansion
abbreviations = {"awsum": "awesome", "totaly": "totally"}

def expand_abbrev(text):
    words = text.split()
    return " ".join([abbreviations.get(w, w) for w in words])

df['clean_review'] = df['clean_review'].apply(expand_abbrev)
```

### 4. Punctuation & Special Character Removal
```python
# Keeps only alphanumeric characters and spaces
df['clean_review'] = df['clean_review'].str.replace(r'[^a-zA-Z0-9\s]', '', regex=True)
```

## 3. Text Pre-processing (Tokenization, Stopwords & Stemming)

### 1. Tokenization
Tokenization breaks continuous raw text into discrete units (tokens), typically individual words.

```python
# Simple space-based tokenization using standard Pandas string methods
df['tokens'] = df['clean_review'].str.split()
# Example output: ['great', 'movie', 'check', 'out', 'for', 'more', 'info']
```

### 2. Stop Word Removal
Stop words (e.g., *"and"*, *"is"*, *"the"*) carry low semantic information in tasks like classification and can be safely filtered out.

```python
stop_words = {'i', 'am', 'and', 'for', 'out', 'of', 'it', 'was', 'the'}

def remove_stopwords(tokens):
    return [word for word in tokens if word not in stop_words]

df['tokens'] = df['tokens'].apply(remove_stopwords)
```

### 3. Stemming
Stemming reduces derived words to their base or root form (e.g., *"danced"*, *"dancing"* $\rightarrow$ *"dance"*).

```python
from nltk.stem.porter import PorterStemmer

ps = PorterStemmer()

def stem_tokens(tokens):
    return [ps.stem(word) for word in tokens]

df['stemmed_tokens'] = df['tokens'].apply(stem_tokens)
# Rejoin tokens back into processed string sentences
df['final_text'] = df['stemmed_tokens'].apply(lambda x: " ".join(x))
```

## 4. Exploratory Data Analysis (EDA) & Feature Extraction

### Structural Metadata Features
Before vectorizing text, structural characteristics (e.g., document length, word count) can serve as useful metadata features.

```python
# 1. Total Character Length
df['char_len'] = df['review'].str.len()

# 2. Total Word Count
df['word_count'] = df['review'].apply(lambda x: len(x.split()))
```

### Extracting N-Grams (Unigrams, Bigrams, Trigrams)
An N-gram represents a contiguous sequence of $n$ items from a given sample of text:
* **Unigram ($n=1$):** Single words (e.g., `["great", "movie"]`)
* **Bigram ($n=2$):** Word pairs (e.g., `["great movie"]`)
* **Trigram ($n=3$):** Triplets (e.g., `["waste of money"]`)

```python
from sklearn.feature_extraction.text import CountVectorizer

# Extracting Top 5 Bigrams
cv_bigram = CountVectorizer(ngram_range=(2, 2), stop_words='english')
bigram_matrix = cv_bigram.fit_transform(df['final_text'])

# Convert to DataFrame to inspect frequencies
bigram_df = pd.DataFrame(
    bigram_matrix.toarray(), 
    columns=cv_bigram.get_feature_names_out()
)
```
