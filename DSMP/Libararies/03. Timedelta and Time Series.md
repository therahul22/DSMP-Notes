## 1. The `Timedelta` Object

A `Timedelta` object in Pandas represents an exact duration—the relative difference between two dates, timestamps, or time instances.

### Creating & Computing Timedeltas
```python
import pandas as pd

# 1. Direct Time Arithmetic (Timestamp Difference)
t1 = pd.Timestamp('2026-06-01 10:00:00')
t2 = pd.Timestamp('2026-06-05 14:30:00')
duration = t2 - t1
print(duration)          # Output: 4 days 04:30:00
print(type(duration))    # Output: <class 'pandas._libs.tslibs.timedeltas.Timedelta'>

# 2. Explicit Instantiation & Date Arithmetic
dt_offset = pd.Timedelta(days=3, hours=9, minutes=56)
future_date = t1 + dt_offset
print(future_date)       # Output: 2026-06-04 19:56:00
```

## 2. Time Series Data & Primary Workflows 💡 *(Interview Topic)*

A **Time Series** is a sequence of data points recorded at sequential time intervals. Analyzing time series tracks how variables evolve across periods and identifies underlying patterns (trends, seasonality, or cyclical behavior).

### Common Real-World Datasets
* **Financial Data:** Daily closing stock prices, trading volumes.
* **Natural Data:** Daily or monthly rainfall, temperature variations.
* **Event Data:** Epidemic tracking, daily active users (DAU).
* **Medical Data:** Continuous ECG/heart rate monitoring.

### Core Disciplines

## 3. Resampling Mechanics: Downsampling vs. Upsampling

Resampling changes the observation frequency of a time-series dataset.

```python
# Create a dummy daily time-series Series
ts = pd.Series(
    [10, 20, 30, 40, 50], 
    index=pd.date_range('2026-06-01', periods=5, freq='D')
)
```

### 1. Downsampling (Decreasing Frequency)
* **Definition:** Converting data from a higher frequency to a lower frequency (e.g., Daily $\rightarrow$ Monthly, Minutes $\rightarrow$ Hours).
* **Requirement:** Requires an **aggregation function** (e.g., `mean()`, `sum()`, `max()`) to combine multiple high-frequency data points into a single lower-frequency bin.

```python
# Downsampling daily subscriber additions to monthly total
monthly_subs = yt['subscribers'].resample('M').sum()
```

### 2. Upsampling (Increasing Frequency)
* **Definition:** Converting data from a lower frequency to a higher frequency (e.g., Days $\rightarrow$ Hours, Minutes $\rightarrow$ Seconds).
* **Requirement:** Introduces empty/missing intervals that require **interpolation** or filling techniques to estimate missing points.

```python
# Upsampling daily share values to hourly and linearly interpolating missing values
hourly_shares = google['share-value'].resample('H').interpolate(method='linear')
```

| Feature | Downsampling | Upsampling |
| :--- | :--- | :--- |
| **Frequency Change** | High $\rightarrow$ Low (e.g., Days to Months) | Low $\rightarrow$ High (e.g., Days to Hours) |
| **Data Operation** | Aggregation (`sum`, `mean`, `max`) | Interpolation (`linear`, `ffill`, `bfill`) |
| **Data Size** | Reduces row count | Increases row count |

## 4. Rolling Windows (Data Smoothing) 💡 *(Interview Topic)*

Raw high-frequency time-series data often contains short-term noise and volatility. A **Rolling Window (Moving Average)** smooths out fluctuations to expose underlying long-term trends.

$$\text{MA}_t = \frac{1}{k} \sum_{i=0}^{k-1} X_{t-i}$$

```python
# Computing a 7-day moving average on closing prices
df['7D_Moving_Avg'] = df['Close'].rolling(window=7).mean()

# Centered rolling window for symmetrical smoothing
df['Centered_MA'] = df['Close'].rolling(window=7, center=True).mean()
```

## 5. Shifting Mechanics (`shift`)

The `.shift()` method moves an entire time-series forward or backward by a specified number of periods along the time index.

### Primary Applications
* **Calculating Period-over-Period Growth / Returns:** Comparing $X_t$ against lagged value $X_{t-1}$.
* **Feature Engineering for ML:** Creating lagged features ($t-1, t-2$) for autoregressive prediction models.

```python
df = pd.DataFrame({'Sales': [100, 120, 150, 130]}, 
                  index=pd.date_range('2026-06-01', periods=4, freq='D'))

# Positive shift: Moves values DOWN (Lagging feature)
df['Lag_1'] = df['Sales'].shift(1)

# Negative shift: Moves values UP (Leading feature)
df['Lead_1'] = df['Sales'].shift(-1)

# Computing daily percentage return using shift
df['Daily_Growth_%'] = ((df['Sales'] - df['Sales'].shift(1)) / df['Sales'].shift(1)) * 100

print(df)
```
