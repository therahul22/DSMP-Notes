# Pandas Vectorized Strings & Advanced DateTime Mechanics

A comprehensive reference guide covering vectorized string operations using the `.str` accessor, regular expression matching, NumPy/Pandas time-series architecture, `Timestamp` vs. `DatetimeIndex` objects, and date-range resampling techniques.

## 1. Vectorized String Operations (`.str` Accessor)

When working with string data in Pandas Series or DataFrames, applying standard Python string methods element-wise requires the `.str` accessor. Vectorized string operations automatically handle missing values (`NaN`) without raising errors.

### Core Vectorized String Methods
```python
import pandas as pd

s = pd.Series(['  john doe  ', 'JANE SMITH', 'alice_brown', None])

# Case Transformations & Cleaning
s.str.upper()         # Converts to UPPERCASE
s.str.lower()         # Converts to lowercase
s.str.capitalize()    # Capitalizes first character
s.str.title()         # Capitalizes First Letter Of Each Word
s.str.strip()         # Removes leading and trailing whitespaces
s.str.len()           # Returns string length (preserves NaN)
```

### Splitting, Index Extraction & Replacement
```python
df = pd.DataFrame({'fullname': ['John,Doe', 'Jane,Smith', 'Alice,Brown']})

# Basic Split: Returns a Series of Lists
df['fullname'].str.split(',')

# Advanced Split: Controlled Splitting & Expansion to DataFrame Columns
# n=1 limits to 1 split, expand=True converts output to DataFrame
names_df = df['fullname'].str.split(',', n=1, expand=True)
names_df.columns = ['First_Name', 'Last_Name']

# Direct Index Retrieval from Split Lists via .get()
df['LastName'] = df['fullname'].str.split(',').str.get(1)  # Extracts 2nd element (index 1)

# Replacement
df['fullname'].str.replace(',', ' ')  # Replaces ',' with ' '
```

### Boolean Filtering & String Inspection
```python
s = pd.Series(['John', 'jane', '12345', 'John123'])

s.str.startswith('J')                 # Checks prefix match
s.str.endswith('e')                   # Checks suffix match
s.str.isdigit()                      # Checks if string contains only digits
s.str.contains('john', case=False)    # Substring search (Case-insensitive)
```

## 2. Advanced Pattern Matching with Regular Expressions (Regex) 💡 *(Interview Favorite)*

The `.str.contains()` method supports Regex patterns for complex pattern detection.

### Problem: Find last names that start AND end with a vowel
```python
# Regex Breakdown:
# ^            : Asserts start of the string
# [aeiouAEIOU] : First character must be a vowel (case-insensitive)
# .+           : One or more of any characters in between
# [aeiouAEIOU] : Last character must be a vowel
# $            : Asserts end of the string

regex_pattern = r'^[aeiouAEIOU].+[aeiouAEIOU]$'
df['lastname'].str.contains(regex_pattern)
```

### Vectorized Slicing
You can slice strings directly using standard Python index slicing syntax via `.str[start:stop:step]`:
```python
s = pd.Series(['Python', 'Pandas', 'NumPy'])
s.str[0:3]   # Extracts first 3 characters -> ['Pyt', 'Pan', 'Num']
s.str[::-1]  # Reverses strings -> ['nohtyP', 'sadnaP', 'ypMuN']
```

## 3. DateTime Architecture: Python vs. NumPy vs. Pandas 💡 *(Interview Topic)*

> ❓ **Interview Question: Why use Pandas DateTime objects over standard Python `datetime` objects?**
>
> **Answer:**
> * **Python `datetime` module:** Stores dates as Python objects. Operations over large collections require standard Python loops, leading to high memory overhead and poor execution speed (similar to Python Lists).
> * **NumPy `datetime64`:** Encodes dates as uniform 64-bit integers in contiguous memory allocations. Supports vectorized, C-level speed arithmetic over array collections.
> * **Pandas `Timestamp`:** Blends the intuitive, convenient API of Python's `datetime` with the low memory footprint and vectorized execution engine of NumPy's `datetime64`. Multiple `Timestamp` objects aggregate into a `DatetimeIndex`.

### Creating Timestamp Objects
```python
import datetime as dt

# 1. Pure Pandas Timestamp
ts1 = pd.Timestamp('2026-02-18')

# 2. Converting Python datetime to Pandas Timestamp
py_dt = dt.datetime(2026, 5, 25, 10, 30)
ts2 = pd.Timestamp(py_dt)
```

## 4. `DatetimeIndex` & Date Generation

A `DatetimeIndex` is a specialized array of Pandas `Timestamp` objects used as primary index structures for time-series operations.

### Generating Date Ranges (`pd.date_range`)
```python
# 1. Fixed Range with Frequency
dti = pd.date_range(start='2026-05-10', end='2026-05-20', freq='D')

# 2. Custom Frequencies
pd.date_range(start='2026-05-01', periods=10, freq='2D') # Every 2 days
pd.date_range(start='2026-05-01', periods=10, freq='B')  # Business days (Excludes Sat & Sun)
pd.date_range(start='2026-05-01', periods=10, freq='W')  # Weekly (Sundays)
pd.date_range(start='2026-05-01', periods=10, freq='H')  # Hourly

# 3. Periods Parameter
# Generating 20 timestamps starting from a given date
pd.date_range(start='2026-05-01', periods=20, freq='D')
```

## 5. Type Conversion & The `.dt` Accessor

To convert string/object series into datetime structures, use `pd.to_datetime()`.

### Handling Malformed Dates (`errors='coerce'`)
```python
dates = pd.Series(['2026-01-01', 'Invalid Date', '2026-05-25'])

# errors='coerce' replaces unparseable/invalid strings with NaT (Not a Time)
clean_dates = pd.to_datetime(dates, errors='coerce')
# Output: [2026-01-01, NaT, 2026-05-25]
```

### Accessing DateTime Components (`.dt`)
Similar to the `.str` string accessor, the `.dt` accessor exposes time-series properties:

```python
s_dates = pd.Series(pd.date_range('2026-01-01', periods=3, freq='D'))

s_dates.dt.year         # Returns Year [2026, 2026, 2026]
s_dates.dt.month        # Returns Month [1, 1, 1]
s_dates.dt.day          # Returns Day [1, 2, 3]
s_dates.dt.month_name() # Returns Month Name ['January', ...]
s_dates.dt.day_name()   # Returns Day Name ['Thursday', ...]
```

## 6. Frequency Resampling (`asfreq`)

The `asfreq()` method sets or converts the explicit frequency of a time-series index. If dates are missing in the sequence after setting a higher frequency, Pandas introduces empty (`NaN` / `NaT`) rows to preserve uniform time gaps.

```python
# Time series with missing date gaps
ts_data = pd.Series([100, 200], index=pd.to_datetime(['2026-05-01', '2026-05-03']))

# Enforce daily frequency ('D')
resampled = ts_data.asfreq('D')

# Result:
# 2026-05-01    100.0
# 2026-05-02      NaN  <- Automatically inserted to fill frequency gap
# 2026-05-03    200.0
# Freq: D
```
