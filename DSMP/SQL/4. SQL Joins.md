## 1. What is a SQL Join?
A join combines data from two or more database tables based on a related column between them. It is used when the required information is distributed across multiple tables.

*Mental Model for Examples below:*
Assume we have two tables: `Users` (user_id, name, city) and `Orders` (order_id, user_id, amount).

## 2. Core Join Types

### Inner Join:

Returns ONLY the rows where there is a match in both tables.

    -- Example: Find the names of users and their corresponding order amounts.
    SELECT Users.name, Orders.amount 
    FROM Users
    INNER JOIN Orders ON Users.user_id = Orders.user_id;

### Left Join (Left Outer Join):

Returns ALL rows from the left table (`Users`), and only matching rows from the right table.

    -- Example: Get a list of all users, and show their order IDs if they have any.
    SELECT Users.name, Orders.order_id 
    FROM Users
    LEFT JOIN Orders ON Users.user_id = Orders.user_id;

### Right Join (Right Outer Join):

Returns ALL rows from the right table (`Orders`), and matching rows from the left table.

    -- Example: Get a list of all orders, and show the user's name if available.
    SELECT Users.name, Orders.amount 
    FROM Users
    RIGHT JOIN Orders ON Users.user_id = Orders.user_id;

### Full Outer Join:

Returns ALL rows from both tables. It matches where it can, and fills the rest with NULLs.

    -- Example: Get absolutely all users and all orders, matched where possible.
    SELECT Users.name, Orders.amount 
    FROM Users
    FULL OUTER JOIN Orders ON Users.user_id = Orders.user_id;


## 3. Special Join Types

### Cross Join (Cartesian Product):

Combines every single row from the first table with every single row from the second table. (e.g., 5 Users * 5 Orders = 25 rows).

    -- Example: Create every possible combination of Users and Products.
    SELECT Users.name, Products.product_name 
    FROM Users
    CROSS JOIN Products;

### Self Join:

A table is joined with itself. Useful for comparing rows within the same table.

    -- Example: Find employees and their managers from a single 'Employees' table.
    -- (Assuming the table has 'emp_id', 'name', and 'manager_id')
    SELECT E1.name AS 'Employee', E2.name AS 'Manager'
    FROM Employees E1
    JOIN Employees E2 ON E1.manager_id = E2.emp_id;


## 4. SQL Set Operations
Set operations stack the results of two SELECT queries vertically. Both queries must return the same number of columns with matching data types.

#### UNION (Removes Duplicates):

    -- Example: Get a single, unique list of all email addresses from both tables.
    SELECT email FROM Users
    UNION
    SELECT email FROM Employees;

#### UNION ALL (Keeps Duplicates):

    -- Example: Get every single email address from both tables, even if repeated.
    SELECT email FROM Users
    UNION ALL
    SELECT email FROM Employees;

#### INTERSECT (Matching Rows Only):

    -- Example: Find people who are BOTH Users and Employees.
    SELECT email FROM Users
    INTERSECT
    SELECT email FROM Employees;

#### EXCEPT / MINUS (Difference):
    -- Example: Find people who are Users, but are NOT Employees.
    SELECT email FROM Users
    EXCEPT
    SELECT email FROM Employees;


## 5. Advanced Join Concepts

### Joining on Multiple Columns:

You can specify multiple conditions in the ON clause for stricter matching.

    -- Example: Match students to classes only if both the ID and the Year match.
    SELECT * FROM Students S
    JOIN Classes C 
      ON S.class_id = C.class_id AND S.enrollment_year = C.class_year;

### Joining Multiple Tables:

You can chain joins together to connect 3 or more tables in a single query.

    -- Example: Get the Order ID, User's Name, and the Product Category Name.
    SELECT o.order_id, u.name, c.category_name
    FROM Orders o
    JOIN Users u ON o.user_id = u.user_id
    JOIN Category c ON o.category_id = c.category_id;

### Filtering with Joins:

You can add a WHERE clause after the JOIN to filter the combined data.

    -- Example: Find the names of users who placed an order over $500.
    SELECT Users.name, Orders.amount
    FROM Users
    JOIN Orders ON Users.user_id = Orders.user_id
    WHERE Orders.amount > 500;
