## 1. What is SQL & Command Categories
SQL (Structured Query Language) is used for managing and manipulating data in relational databases. It allows you to perform CRUD (Create, Read, Update, Delete) operations 30].
Commands are grouped into four main categories 51, 52, 59, 61]:

* DDL (Data Definition Language): Deals with database schemas and structures.
  *CREATE: Create new database objects.
  *ALTER: Modify existing database objects.
  *DROP: Delete existing database objects entirely.
  *TRUNCATE: Remove all rows from a table (but keep the structure).
* DML (Data Manipulation Language): Deals with the actual data inside tables.
  *INSERT (Create), UPDATE (Modify), DELETE (Remove), SELECT (Retrieve) 68, 69, 70, 71, 75, 76, 78].
* DCL (Data Control Language): Handles permissions.
  *GRANT: Provide access rights.
  *REVOKE: Withdraw access rights.
* TCL (Transaction Control Language): Handles transactions.
  *COMMIT: Save database changes and end transaction.
  *ROLLBACK: Undo uncommitted changes.


## 2. DDL Syntax: Databases & Tables

  - CREATE DATABASE database_name;
  - CREATE DATABASE IF NOT EXISTS database_name;
  - DROP DATABASE database_name;

Table Level (CREATE):
  - CREATE TABLE Users
      - userid INT PRIMARY KEY,
      - name VARCHAR(255) NOT NULL,
      - email VARCHAR(255) UNIQUE

      - CONSTRAINT users_email_unique UNIQUE (email,name) # can add constraints on multiple columns, can be removed later, 
  );

Table Level (TRUNCATE & DROP):
  - TRUNCATE TABLE Users;  -- Deletes all data, resets identity/auto-increment, keeps table structure.
  - DROP TABLE Users;      -- Deletes the table structure and all data completely.


## 3. ALTER TABLE Operations

The ALTER TABLE statement modifies the structure of an existing table.You can Add, Delete, or Modify columns.

    -- 1. Add a new column
    ALTER TABLE Users ADD age INT;

    -- 2. Drop an existing column
    ALTER TABLE Users DROP COLUMN age;

    -- 3. Modify a column's data type
    ALTER TABLE Users MODIFY COLUMN name VARCHAR(500);

    -- 4. Rename a column (MySQL syntax)
    ALTER TABLE Users RENAME COLUMN name TO full_name;


## 4. Data Integrity & Constraints

Data integrity refers to the accuracy, completeness, and consistency of data.
Constraints are rules applied to columns to enforce this integrity and prevent invalid data entry.
Core Constraints:

* NOT NULL: Ensures a column cannot have a NULL value.
* UNIQUE: Ensures all values in a column are different.
* PRIMARY KEY: A combination of a NOT NULL and UNIQUE. Uniquely identifies each row.
* FOREIGN KEY: Prevents actions that would destroy links between tables.
* CHECK: Ensures the values in a column satisfy a specific condition (e.g., age >= 18).
* DEFAULT: Sets a default value for a column if no value is specified.
* AUTO_INCREMENT: Automatically generates a unique number when a new record is inserted.

### Referential Actions for Foreign Keys:
When a referenced record in a parent table is deleted or updated, these rules dictate what happens to the child records:
* RESTRICT: Prevents deletion/update of the parent row if a child row exists.
* CASCADE: Automatically deletes/updates the matching child rows when the parent row is deleted/updated.
* SET NULL: Sets the foreign key column in the child table to NULL when the parent row is deleted.
* SET DEFAULT: Sets the foreign key column to its default value.

### Handling Constraints via ALTER (Important for Tests):
Note: You generally cannot directly "Edit" an existing constraint. You must DROP it and ADD a new one.

    -- Add a constraint to an existing table
    ALTER TABLE Users ADD CONSTRAINT chk_age CHECK (age >= 18);

    -- Drop a constraint
    ALTER TABLE Users DROP CONSTRAINT chk_age;


## 5. SQL FunctionsFunctions perform operations on data and are categorized into Built-in (Scalar vs. Aggregate) and User-Defined.

### Scalar Functions (Operate on a single value and return a single value):

* ROUND(): Rounds a numeric field to the number of decimals specified.
* SQRT(): Returns the square root.
* ABS(): Returns the absolute value.
* LOWER() / UPPER(): Converts strings to lower/upper case.

### Aggregate Functions (Operate on multiple values/a column and return a single summary value):
* AVG(): Returns the average value.
* SUM(): Returns the total sum.
* MIN(): Returns the smallest value.
* MAX(): Returns the largest value.
* COUNT(): Returns the number of rows.


## 6. Interview Classic: DROP vs. TRUNCATE vs. DELETE
This is highly tested in placement interviews. Know the difference:

* DROP (DDL): Completely removes the table structure, data, indexes, and privileges. Cannot be rolled back.
* TRUNCATE (DDL): Removes all rows quickly by deallocating pages. Resets AUTO_INCREMENT counters. Cannot be rolled back. Faster than DELETE.
* DELETE (DML): Removes specific rows (or all rows) one by one and records each deletion in the transaction log. Can be rolled back. Does NOT reset AUTO_INCREMENT.
