## 1. Special Matrices & Their Properties

### I. Diagonal Matrix
A square matrix where all entries outside the main diagonal are exactly zero. 
* **Powers:** The $n$-th power of a diagonal matrix is obtained by simply raising each diagonal element to the power of $n$ (e.g., $A^{100}$).
* **Eigenvalues & Eigenvectors:** The eigenvalues are exactly the values on the main diagonal. The corresponding eigenvectors are the standard basis vectors.
* **Multiplications:** Multiplying a diagonal matrix by a vector scales each component of the vector by the corresponding diagonal element. 

### II. Orthogonal Matrix
A square matrix whose rows and columns are orthogonal unit vectors (orthonormal), meaning they have a unit length of 1 and are at $90^\circ$ to each other.
* **Geometric Transformation:** Represents a perfect rotation without any scaling or shearing.
* **Inverse equals Transpose:** The transpose of an orthogonal matrix is strictly equal to its inverse ($A^T = A^{-1}$). This makes calculations highly computationally efficient.

### III. Symmetric Matrix
A square matrix that is equal to its own transpose ($A = A^T$). 
* **Real Eigenvalues:** The eigenvalues of a real symmetric matrix are always real numbers, never complex.
* **Orthogonal Eigenvectors:** Eigenvectors corresponding to distinct eigenvalues are always completely orthogonal to one another.

## 2. Matrix Composition vs. Decomposition

* **Composition:** The process of multiplying multiple matrices together to form a single, more complex matrix (e.g., $D = A B C$).
* **Decomposition:** The reverse process of breaking a complex matrix down into simpler foundational matrices. Common techniques include:
    * LU Decomposition
    * QR Decomposition
    * Singular Value Decomposition (SVD)
    * Eigen Decomposition

## 3. Eigen Decomposition

### The Core Equation
The eigen decomposition of a matrix $A$ is represented by the formula:

$$A = V \Lambda V^{-1}$$

Where:
* **$V$**: A matrix whose columns are the eigenvectors of $A$.
* **$\Lambda$**: A diagonal matrix whose entries are the corresponding eigenvalues of $A$.
* **$V^{-1}$**: The inverse of matrix $V$.

### Requirements & Properties
* **Square Matrices Only:** Eigen decomposition is mathematically defined only for square matrices.
* **Diagonalizability:** An $n \times n$ matrix can only be decomposed if it has $n$ linearly independent eigenvectors.
* **Symmetric Matrix Decomposition (Spectral Theorem):** When decomposing a symmetric matrix, $V$ becomes an orthogonal matrix, meaning $V^{-1} = V^T$. The decomposition becomes $A = V \Lambda V^T$. Geometrically, this represents a rotation, a scaling operation, and another rotation.
* **Computational Advantage:** It drastically simplifies raising a matrix to a high power. Because $V$ and $V^{-1}$ cancel each other out during sequential multiplications, computing large powers becomes trivial: $A^{1000} = V \Lambda^{1000} V^{-1}$.

## 4. Principal Component Analysis (PCA) & Kernel PCA

### PCA Variants
Depending on the data structure and computational needs, different variants of PCA are utilized:
* **Incremental PCA**
* **Randomized PCA**
* **Kernel PCA**

### The Limitation of Standard PCA
Standard PCA assumes that principal components are a linear combination of the original features. It fails to effectively separate data with complex, non-linear relationships (e.g., concentric circles in a 2D space).

### The Solution: The Kernel Trick (Kernel PCA)
* Kernel PCA uses a mathematical function to project lower-dimensional non-linear data into a much higher-dimensional space (e.g., transforming 2D data to 3D), where a linear plane can then easily separate it.
* **Similarity/Kernel Functions:** A common mapping used is the Radial Basis Function (RBF) or Gaussian kernel, structured as $y = e^{-x^2}$ or $e^{-\gamma \times \text{distance}^2}$.
* **Mechanism:** Instead of dealing with the raw features directly, Kernel PCA evaluates the dataset by computing the Euclidean distance between every single data point. For a dataset of 400 points, this results in a $400 \times 400$ symmetric similarity matrix.
* Standard Eigen Decomposition is then performed directly on this massive symmetric matrix to extract the principal components.
