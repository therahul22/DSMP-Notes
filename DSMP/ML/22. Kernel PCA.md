# Linear Algebra: Matrix Decomposition & Kernel PCA

---

## 1. Special Matrices & Their Properties

### I. Diagonal Matrix
A square matrix where all entries outside the main diagonal are exactly zero. 
* **Powers:** The $n$-th power of a diagonal matrix is obtained by simply raising each diagonal element to the power of $n$ (e.g., $A^{100}$).
* **Eigenvalues & Eigenvectors:** The eigenvalues are exactly the values on the main diagonal. The corresponding eigenvectors are the standard basis vectors.
* **Multiplications:** Multiplying a diagonal matrix by a vector scales each component of the vector by the corresponding diagonal element. 

### II. Orthogonal Matrix
A square matrix whose rows and columns are orthogonal unit vectors (orthonormal), meaning they have a unit length of 1 and are at $90^\circ$ to each other.
* **Geometric Transformation:** Represents a perfect rotation without any scaling or shearing.
* **Inverse equals Transpose:** The transpose of an orthogonal matrix is strictly equal to its inverse ($A^T = A^{-1}$). This makes calculations highly computationally efficient.

### III. Symmetric Matrix
A square matrix that is equal to its own transpose ($A = A^T$). 
* **Real Eigenvalues:** The eigenvalues of a real symmetric matrix are always real numbers, never complex.
* **Orthogonal Eigenvectors:** Eigenvectors corresponding to distinct eigenvalues are always completely orthogonal to one another.

## 2. Matrix Composition vs. Decomposition

* **Composition:** The process of multiplying multiple matrices together to form a single, more complex matrix (e.g., $D = A B C$).
* **Decomposition:** The reverse process of breaking a complex matrix down into simpler foundational matrices. Common techniques include:
    * LU Decomposition
    * QR Decomposition
    * Singular Value Decomposition (SVD)
    * Eigen Decomposition

## 3. Eigen Decomposition & Spectral Decomposition

### The Core Equation
The eigen decomposition of a square matrix $A$ is represented by the formula:

$$A = V \Lambda V^{-1}$$

Where:
* **$V$**: A matrix whose columns are the eigenvectors of $A$.
* **$\Lambda$**: A diagonal matrix whose entries are the corresponding eigenvalues of $A$.
* **$V^{-1}$**: The inverse of matrix $V$.

### Spectral Decomposition (Symmetric Matrices)
When the matrix $A$ is **symmetric**, its eigen decomposition is specifically known as **Spectral Decomposition**.
* In this case, the eigenvector matrix $V$ is **orthogonal** ($V^{-1} = V^T$).
* **Geometric Interpretation:** The transformation $A$ can be broken down into three geometric steps: **Rotate $\rightarrow$ Scale $\rightarrow$ Rotate** ($A = V \Lambda V^T$).

### Why is this useful? (The $A^{100}$ Problem)
Eigen decomposition makes computing high powers of a matrix computationally trivial. If you need to calculate $A^{100}$:
1. Decompose $A$ into $V \Lambda V^{-1}$.
2. Instead of multiplying $A$ by itself 100 times, you calculate $V \Lambda^{100} V^{-1}$.
3. Because $\Lambda$ is a diagonal matrix, finding $\Lambda^{100}$ simply requires raising its diagonal elements to the 100th power, saving immense computational power.

## 4. Principal Component Analysis (PCA) & Kernel PCA

Standard PCA assumes that principal components are a linear combination of the original features, which causes it to fail on non-linear data.

### The Limitation: Concentric Circles
If you have a 2D dataset forming concentric circles (e.g., a yellow cluster in the center surrounded by a purple ring), standard PCA cannot draw a linear line to separate them. As seen in the visualizations, when PCA tries to reduce this 2D data to 1D along a straight axis, the yellow and purple points completely overlap, destroying the separability.

### The Solution: The Kernel Trick (Kernel PCA)
Kernel PCA (closely linked with concepts from Support Vector Machines / SVMs) solves this by projecting the data into a higher dimension where it *can* be separated linearly.

**The Concept:**
1. Use a mathematical function (like $y = e^{-x^2}$) to project the 2D concentric circles into 3D space. This acts to "elevate" the center cluster (yellow dots) along a new axis.
2. Once in 3D, a flat plane can easily slice between the yellow and purple clusters.
3. The data is then projected back down to a lower dimension (like 1D or 2D) where the clusters are now cleanly separated.

**How Kernel PCA is Calculated (Step-by-Step):**
1. **Mean Centering:** The data is centered around the origin.
2. **Apply the Kernel:** A kernel function is applied. A common choice is the Radial Basis Function (RBF), which uses distance: $e^{-\gamma \times \text{distance}^2}$.
3. **Construct the Similarity Matrix:** An $N \times N$ grid is created using all rows of the dataset. The algorithm calculates the Euclidean distance from every single point to every other point and applies the kernel.
4. **Symmetric Properties:** This resulting grid is a massive **similarity matrix** (e.g., $400 \times 400$ for 400 data points), which is inherently **symmetric**.
5. **Decomposition:** Finally, standard Eigen Decomposition is performed on this symmetric similarity matrix to extract the new principal components.

> **Note on Optimization:** To find the absolute *best* principal component, a classification algorithm is sometimes run iteratively, calculating the accuracy for each potential component and keeping the one that yields the highest accuracy.
