# Support Vector Machine (SVM) — Complete Notes

## 1. High-Level Overview & Model Hierarchy

### Rank of Importance
In practical industry applications on tabular data, ensemble models generally rank as follows:
1. **XGBoost (or Gradient Boosting):** Top choice for structured/tabular data due to speed, handling missing values, and high predictive power.
2. **Random Forest:** Very robust baseline, highly parallelizable, resistant to overfitting.
3. **SVM:** Excellent for high-dimensional feature spaces and complex non-linear boundaries, but computationally heavier $O(n^3)$ on large datasets.

### Applicability Matrix
* **Classification:** Primary strength (binary and multi-class classification).
* **Regression:** Applicable via **Support Vector Regression (SVR)**.
* **Image Processing:** Historically widely used (e.g., face recognition, OCR/digit recognition) using kernel tricks before deep learning/CNNs dominated.
* **Linear or Non-Linear Data:** Handles both seamlessly (linearly separable data via standard hyperplanes; non-linear data via kernel methods).

## 3. Hard Margin Classifier (Maximal Margin Classifier)

### 3.1 Setup & Intuition
* **Problem Setting:** Predict Placement status ($Y_i \in \{+1, -1\}$) using features like $X_1$ (CGPA) and $X_2$ (IQ).
* **Core Assumption:** Classes **must be linearly separable**.
* **Goal:** Classify data by drawing a straight line (or decision boundary) such that the **margin** between the classes is **maximized**.
* **Which Model is Good?** The model with the **largest margin**, as it maximizes separation distance and generalizes best to unseen test data.

---

### 3.2 Line Equations & Geometry

In standard 2D Cartesian geometry, a line is written as:
$$ax + by + c = 0$$

In Machine Learning feature space:
* $x \to X_1$ (Feature 1, e.g., CGPA)
* $y \to X_2$ (Feature 2, e.g., IQ)
* $a, b, c \to A, B, C$ (Model parameters / weights)

SVM constructs three parallel lines:

1. **Center Line (Decision Boundary):**
   $$AX_1 + BX_2 + C = 0$$
2. **Positive Margin Line:**
   $$AX_1 + BX_2 + C = +1$$
3. **Negative Margin Line:**
   $$AX_1 + BX_2 + C = -1$$

```
                   AX1 + BX2 + C = +1  (Positive Margin)
                   .   .   . (Class +1: Placed)
             -------------------------------------------
                   AX1 + BX2 + C = 0   (Center Line / Decision Boundary)
             -------------------------------------------
                   .   .   . (Class -1: Unplaced)
                   AX1 + BX2 + C = -1  (Negative Margin)
```

---

### 3.3 Support Vectors
* Every student/data point is represented as a feature vector $\mathbf{x}_i = (X_{1i}, X_{2i})$.
* Data points that sit **directly on the boundary lines** ($AX_1 + BX_2 + C = \pm 1$) are called **Support Vectors**.
* These boundary points are critical: if any non-support vector point is removed, the decision boundary stays identical. The support vectors uniquely define and "support" the hyperplane.

### 3.4 Mathematical Formulation

#### Conditions on Data Points
To ensure all positive samples stay on/above the positive margin line and all negative samples stay on/below the negative margin line:

* If $Y_i = +1 \implies AX_{1i} + BX_{2i} + C \ge +1$
* If $Y_i = -1 \implies AX_{1i} + BX_{2i} + C \le -1$

#### Simplified Unified Equation
Multiplying both sides by $Y_i$ merges both cases into a single mathematical constraint:
$$Y_i(AX_{1i} + BX_{2i} + C) \ge 1 \quad \forall i$$

#### Margin Derivation
The perpendicular distance $d$ between two parallel lines $AX_1 + BX_2 + C_1 = 0$ and $AX_1 + BX_2 + C_2 = 0$ is given by:
$$d = \frac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}$$

For our margin lines ($C_1 = C - 1$ and $C_2 = C + 1$):
$$d = \frac{|(C - 1) - (C + 1)|}{\sqrt{A^2 + B^2}} = \frac{2}{\sqrt{A^2 + B^2}}$$

#### Optimization Problem
We want to maximize $d = \frac{2}{\sqrt{A^2 + B^2}}$, which is equivalent to minimizing $\frac{\sqrt{A^2 + B^2}}{2}$:

$$\arg\min_{A, B, C} \frac{\sqrt{A^2 + B^2}}{2} \quad \text{subject to} \quad Y_i(AX_{1i} + BX_{2i} + C) \ge 1$$

*(This is a classic **constrained optimization programming** problem.)*

---

### 3.5 Prediction Phase
Margin lines are used **only during training**. For making predictions on new data points, we evaluate only against the center line:

$$\hat{Y}_{\text{new}} = \begin{cases} +1 & \text{if } AX_{1,\text{new}} + BX_{2,\text{new}} + C \ge 0 \\ -1 & \text{if } AX_{1,\text{new}} + BX_{2,\text{new}} + C < 0 \end{cases}$$

## 4. Soft Margin Classifier

### 4.1 Limitations of Hard Margin SVM
1. **Inability to handle overlap:** If red points mixed with green points (noisy or non-linearly separable data), no straight line can satisfy $Y_i(AX_{1i} + BX_{2i} + C) \ge 1$ for all points simultaneously.
2. **Extreme Sensitivity to Outliers:** A single outlier close to the opposite class dramatically distorts the margin or makes the optimization infeasible.
3. **Unrealistic for Real-World Data:** Hard margin constraints are too rigid for noisy real-world datasets.

---

### 4.2 Slack Variable ($\xi_i$)

Introduced by **Vladimir Vapnik (1995)** to allow controlled errors and margin violations in non-linearly separable data.

For each data point $i$, a slack variable $\xi_i \ge 0$ measures the distance by which point $\mathbf{x}_i$ violates the ideal margin:

* **$\xi_i = 0$:** Point is on the correct side of the margin (no violation).
* **$0 < \xi_i < 1$:** Point is on the correct side of the decision boundary, but inside the margin street (margin violation).
* **$\xi_i \ge 1$:** Point is on the wrong side of the decision boundary (misclassified point).

#### Hinge Loss Representation
$$\text{Hinge Loss}_i = \max\left(0, 1 - Y_i(AX_{1i} + BX_{2i} + C)\right)$$

---

### 4.3 Integrating Slack into Hard Margin SVM

#### Relaxed Constraint
We modify the hard constraint by subtracting $\xi_i$:
$$Y_i(AX_{1i} + BX_{2i} + C) \ge 1 - \xi_i \quad \text{where } \xi_i \ge 0$$

#### The Need for a Penalty
If we only relax the constraint, the optimizer could arbitrarily set $\xi_i \to \infty$ for all points, making margins infinitely wide without any penalization, resulting in total misclassification.

To prevent this, we introduce a trade-off penalty parameter $C$:

#### Soft Margin Optimization Formula
$$\arg\min_{A, B, C} \left( \frac{\sqrt{A^2 + B^2}}{2} + C \cdot \frac{1}{n} \sum_{i=1}^{n} \xi_i \right) \quad \text{subject to } Y_i(AX_{1i} + BX_{2i} + C) \ge 1 - \xi_i, \quad \xi_i \ge 0$$

Here, two opposing forces compete:
1. **Force 1 ($\frac{\sqrt{A^2 + B^2}}{2}$):** Maximize margin width.
2. **Force 2 ($C \cdot \frac{1}{n}\sum \xi_i$):** Minimize total misclassification errors.

The hyperparameter $C$ decides which force dominates. *(Note: This hyperparameter $C$ is distinct from the intercept parameter $C$ in the line equation).*

---

## 5. Hyperparameter $C$ & Bias-Variance Tradeoff

| Value of $C$ | Behavior | Decision Boundary | Bias / Variance | Risk |
| --- | --- | --- | --- | --- |
| **High $C$** | Strictly penalizes violations ($\xi$). Prioritizes classifying training points correctly. | Complex, narrow margin | **Low Bias, High Variance** | Overfitting |
| **Low $C$** | Tolerates violations ($\xi$). Prioritizes maximizing margin width over errors. | Smooth, wide margin | **High Bias, Low Variance** | Underfitting |

## 6. Relationship with Logistic Regression & Regularization

Rewriting SVM weights as $\beta_1, \beta_2, \beta_0$:

$$\arg\min_{\beta_1, \beta_2, \beta_0} \left( \frac{\sqrt{\beta_1^2 + \beta_2^2}}{2} + C \cdot \frac{1}{n} \sum_{i=1}^{n} \xi_i \right)$$

### Structural Comparison
Both SVM and Logistic Regression can be viewed through the general loss-minimization framework:

$$\text{Total Cost} = \text{Loss Term} + \text{Regularization Term}$$

* **Soft Margin SVM:** Hinge Loss + Margin Maximization Penalty ($\sqrt{\beta_1^2 + \beta_2^2}/2$)
* **L2 Regularized Logistic Regression:** Log Loss + $\lambda \sqrt{\beta_1^2 + \beta_2^2}$

### Duality of Hyperparameters
* In **SVM**, $C$ multiplies the **loss term**:
  * High $C \implies$ High penalty on loss $\implies$ Weak regularization.
* In **Logistic Regression**, $\lambda$ multiplies the **regularization term**:
  * High $\lambda \implies$ High penalty on weights $\implies$ Strong regularization.
* **Relationship:**
  $$\lambda \propto \frac{1}{C}$$
