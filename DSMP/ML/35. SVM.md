mathematical formulation
need a line segment that maximize distance such that
condition: no point lies between them
ax + by + c = 0, need a, b, c
+ve direction: ax + by + c = 1
-ve direction: ax + by + c = -1
we can change margin using these lines

points conditions:
maximize d such that
for centre line: AX1 + BX2 + C = 0,
IF Yi = 1
 AX1i + BX2i + C >= 1
IF Yi = -1
 AX1i + BX2i + C <= -1

simplified eqn:
Yi(AX1 + BX2 + C) >=1

dist between two lines = |c1 -c2|/root(a2 + b2)
for our eqn : 
d = 2//root(a2 + b2)
maximize this given Yi(AX1 + BX2 + C) >=1
this is constrained optimization programming
