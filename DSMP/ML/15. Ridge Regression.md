#Ridge Regression (L2)

These notes cover the intuition and mathematical proof behind Ridge Regression, a technique used to reduce overfitting in machine learning models.

## 1. Introduction to Regularization

The core purpose of regularization is to **induce some extra information into a model to reduce overfitting.**

* **Overfitting:** Occurs when a model performs exceptionally well on training data but poorly on unseen testing data. The model memorizes the noise instead of learning the general trend.
* **The Problem:** In a simple linear regression equation $y = mx + b$, an excessively large slope (weight $m$) usually indicates overfitting. The model is reacting too sharply to small changes in $x$.
* **The Solution:** Introduce a hyperparameter $\lambda$ (lambda) to penalize large weights/slopes.

There are three main types of regularization:
1. **Ridge Regression (L2):** Adds a squared magnitude penalty.
2. **Lasso Regression (L1):** Adds an absolute magnitude penalty.
3. **Elastic Net:** A combination of L1 and L2.

## 2. The Ridge Regression Loss Function

In standard Ordinary Least Squares (OLS), the loss function only calculates the error between the actual values ($y_i$) and the predicted values ($\hat{y}_i$). Ridge Regression adds a penalty term for the slope ($m$):

$$L = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 + \lambda(m)^2$$

## 3. A Practical Proof ($L_N$ vs $L_R$ Example)

Let's look at a mathematical example proving why the model prefers a flatter line over a perfectly fitted line when regularization is applied.

Assume we are trying to fit two training points, **A (1, 2.3)** and **B (3, 5.3)**.

* **Line $L_N$ (No Regularization):** A line that perfectly connects the points. Let's assume the equation is $y = 1.5x + 0.8$. Because it fits perfectly, the squared error is 0.
* **Line $L_R$ (Regularized):** A flatter line that doesn't fit perfectly. Equation: $y = 0.9x + 1.5$.

If we set our hyperparameter $\lambda = 1$, let's calculate the new Loss ($L$):

* **Loss for $L_N$:**
  $$L_N = 0 + 1(1.5)^2 = 2.25$$

* **Loss for $L_R$:**
  Even though it has some error (bias) on the training data, the total loss calculation yields:
  $$L_R = (2.3 - (0.9(1) + 1.5))^2 + (5.3 - (0.9(3) + 1.5))^2 + (0.9)^2 \approx 2.03$$

**Conclusion:** The optimizer will choose line $L_R$ because $2.03 < 2.25$. Regularization intentionally accepts a little bit of error (bias) on the training data to significantly reduce the slope (variance), leading to better generalization.

## 4. Mathematical Derivation (2D Data)

To find the optimal values for $m$ and $b$, we differentiate the Loss function and set it to zero.

**Step 1: Differentiate with respect to $b$**
$$\frac{\partial L}{\partial b} = 0 \implies b = \bar{y} - m\bar{x}$$
*(Note: The intercept $b$ is usually not penalized in regularization, which is why there is no $\lambda$ term here).*

**Step 2: Differentiate with respect to $m$**
Substitute $b$ into the loss function and find $\frac{\partial L}{\partial m} = 0$. After applying the chain rule and rearranging the summation terms, we arrive at the crucial formula for the regularized slope:

$$m = \frac{\sum (y_i - \bar{y})(x_i - \bar{x})}{\sum (x_i - \bar{x})^2 + \lambda}$$

**Key Takeaway:** Look at the denominator. Because we are adding a positive $\lambda$ value to the denominator, the overall value of $m$ will shrink compared to standard linear regression. This is the exact mathematical mechanism that forces the slope to be smaller!

## 5. N-Dimensional Data (Matrix Formulation)

In the real world, data has multiple features ($x_1, x_2, ..., x_n$), so we must use matrices instead of simple scalars.

* $X$ = A matrix of input features (with a column of 1s for the intercept).
* $Y$ = A vector of target values.
* $W$ = A vector of weights ($w_0, w_1, ..., w_n$).

The Loss function translates to matrix notation as follows:
$$L = (XW - Y)^T (XW - Y) + \lambda ||W||^2$$

Expanding this out yields:
$$L = W^T X^T X W - 2 W^T X^T Y + Y^T Y + \lambda W^T W$$

Taking the gradient with respect to the weight vector $W$ and setting it to zero gives the closed-form solution for Ridge Regression:
$$W = (X^T X + \lambda I)^{-1} X^T Y$$

## Ridge Regression: Questions

### 1. How Coefficients Get Affected (Shrinking Towards Zero)
In Ridge Regression, we add a penalty to the model for having large weights (coefficients). Think of it as a budget constraint controlled by the hyperparameter **$\lambda$ (Lambda)**. To minimize the overall error while staying within this budget, the model is forced to pull the values of its coefficients closer to zero. They shrink, but because of the squared mathematical constraint, they almost never become exactly zero.

### 2. Why Higher Values Are Impacted More
The penalty in Ridge Regression is **squared** ($\lambda \sum \beta^2$). Because of the square, large coefficients create a massive penalty. For example, a weight of 2 adds 4 to the penalty, but a weight of 10 adds 100. The optimization algorithm will always prioritize shrinking the largest coefficients first because that is the fastest way to reduce the total penalty.

### 3. Impact of Lambda ($\lambda$) on Bias & Variance
The value of $\lambda$ dictates exactly how much the coefficients shrink, directly controlling the bias-variance trade-off:
* **$\lambda = 0$ (No Penalty):** The model acts like standard Ordinary Least Squares (OLS) regression. It fits the training data perfectly, resulting in **low bias but very high variance** (high risk of overfitting).
* **As $\lambda$ Increases:** The penalty becomes stricter. The model sacrifices accuracy on the training data (increasing **bias**) to restrict the coefficients. This restriction makes the model much more stable on unseen data (decreasing **variance**).
* **$\lambda \to \infty$ (Extremely High Penalty):** The penalty completely overwhelms the actual prediction error. All coefficients are pushed infinitesimally close to zero. This leads to **very high bias and low variance** (severe underfitting).

### 4. The Bias-Variance Trade-off Explained
Standard models try to fit the training data perfectly but often fail on unseen data because they are too complex and memorize noise. Ridge intentionally introduces a tiny bit of error on the training data (bias) by tuning $\lambda$ up from zero. This small sacrifice makes the model simpler and prevents wild fluctuations, leading to a massive improvement when tested on new, unseen data (lower variance).

### 5. Impact on the Loss Function
The standard loss function only looks at the prediction error. Ridge changes this by adding the penalty term: 

**New Loss = Prediction Error + $\lambda \sum \beta^2$**

This extra penalty reshapes the math. It turns a potentially flat or messy loss function into a strict "bowl" shape (strictly convex). This guarantees that the algorithm will always find one unique, stable best answer, even if the dataset has highly overlapping or correlated features.
