# The Curse of Dimensionality

In machine learning, there is a common misconception that adding more features (columns) will always make a model perform better. In reality, adding features beyond an optimal point leads to a sharp decline in performance, a phenomenon known as the **Curse of Dimensionality**.

## The Core Problems
1. **Performance Degradation:** As the number of dimensions increases, the volume of the feature space grows exponentially. The available training data becomes extremely sparse within this massive space.
2. **Data Sparsity:** "Sparse data" means that data points move structurally further apart from one another. In high-dimensional space, almost all pairs of points are equidistant, making distance-based algorithms (like KNN, K-Means, or SVMs) fail because they can no longer distinguish near points from far points.
3. **Computational Complexity:** Every added feature exponentially increases the memory consumption and computational processing required to train and run the model.

---

## Real-World Domain Cases

High-dimensional data issues appear consistently across two main domains in machine learning:

### Case 1: Text Data (NLP)
* When converting text to numbers using techniques like **Bag of Words (BoW)** or **TF-IDF**, every unique word across thousands of documents becomes an individual feature column.
* This leaves you with an enormous matrix filled mostly with zeros (high sparsity), forcing the model to do massive amounts of extra work to find meaningful patterns.

### Case 2: Image Data (Computer Vision)
* For a standard high-resolution image, every single pixel acts as a feature dimension. A single colored image can easily generate millions of input features.
* Without structural processing, models become too complex, overfit the training dataset, and require immense computing hardware to process.

---

## Strategic Solutions: Dimensionality Reduction

To counter the curse of dimensionality, we use techniques to shrink the feature space down to its most informative components. This is broadly achieved via two approaches:

1. **Feature Selection (Dropping Columns):** * Keeping only the most relevant features and removing the redundant or noisy ones.
   * *Examples:* Using regularization techniques like **Lasso (L1)** to zero out less important coefficients, or filtering out columns with low variance.
2. **Feature Extraction (Transforming Spaces):**
   * Projecting the high-dimensional data into a brand-new, lower-dimensional space.
   * *Examples:* **Principal Component Analysis (PCA)** or Linear Discriminant Analysis (LDA), which compress the data while preserving the maximum amount of original variance.
  
# Principal Component Analysis (PCA)

## 1. Introduction to Feature Extraction
**Principal Component Analysis (PCA)** is an unsupervised machine learning technique used for dimensionality reduction. Unlike Feature Selection, which drops columns entirely, PCA performs **Feature Extraction** by transforming a high-dimensional feature space into a brand-new, lower-dimensional space.

### Key Benefits of PCA:
* **Faster Execution:** Reducing the number of input dimensions directly accelerates model training times.
* **Data Visualization:** Compresses data with many features down to 2D or 3D spaces so it can be easily plotted and visually analyzed.

---

## 2. Feature Selection vs. Feature Extraction Intuition

Consider a dataset containing features to predict house prices, where you have two highly correlated features: `Room` (number of rooms) and `Washroom` (number of washrooms).

### Approach A: Feature Selection (Discarding Columns)
If you must choose between keeping `Room` or `Washroom` without knowing which is more important, you can analyze their spread (**variance**):
* You create a scatter plot of the data.
* You look for the axis along which the data points show the widest spread or maximum projection distance ($d$).
* You retain the column with the highest variance and completely discard the other.

### Approach B: Feature Extraction (Creating New Fields)
When both columns contain vital information and you cannot afford to throw either away, you combine them into a brand-new feature space:
* Instead of picking one over the other, PCA blends `Room` and `Washroom` into a new structural metric: `Size`.
* This new feature `Size` captures the maximum possible information (variance) from both original columns simultaneously.

---

## 3. Mathematical Intuition: Rotating the Axis

Geometrically, PCA works through a process of **rotating the coordinate axes** to find the directions of maximum variance.

1. **Finding Principal Component 1 (PC1):**
   * Imagine your data points plotted on a standard 2D plane with `room` on the x-axis and `washroom` on the y-axis.
   * PCA draws a new axis through the data in the direction of the longest stretch of the data cloud. This axis is **PC1** (or `room'`). 
   * The distance ($d$) represents the maximum variance of the projected data points along this line.

2. **Finding Principal Component 2 (PC2):**
   * PCA then draws a second axis (**PC2** or `washroom'`) that is strictly perpendicular (**orthogonal**) to PC1. 
   * This axis captures the remaining variance ($d'$). Because PC1 captured the primary spread, the variance along PC2 is much smaller ($d > d'$).

### Core Mathematical Constraints:
* **Number of Components:** The total number of Principal Components you can extract is always less than or equal to the number of original features ($n$):
  $$\text{Number of PCs} \le n$$
* **Orthogonality:** Every single principal component is completely perpendicular to all other components. This mathematically guarantees that there is zero correlation between your new features, entirely eliminating the problem of multicollinearity.

## 4. Mathematical Problem Formulation of PCA

To find the first Principal Component (PC1), we need to mathematically define the line that captures the highest amount of information. We do this by setting up a **Variance Maximization** problem.

### A. The Geometry of Projection
1. **The Unit Vector ($\vec{u}$):** We define a brand-new axis using a direction vector $\vec{u}$. To ensure we only care about its direction and not its scale, we force it to be a unit vector:
   $$\|\vec{u}\| = 1 \implies \vec{u}^T\vec{u} = 1$$
2. **Projecting Data Points ($u^T x_i$):** Take any original 2D or high-dimensional data point $\vec{x}_i$. The scalar projection of this point onto our new axis $\vec{u}$ is calculated using the dot product:
   $$\text{Projection} = \frac{\vec{u} \cdot \vec{x}_i}{\|\vec{u}\|} = \vec{u} \cdot \vec{x}_i = u^T x_i$$
3. **Projecting the Mean ($u^T \bar{x}$):** Similarly, if $\bar{x}$ is the center (mean point) of our original dataset, its projection onto the new axis is $u^T \bar{x}$.


### B. The Optimization Problem
The goal of PCA is to find a specific unit vector $\vec{u}$ such that the variance of the projected points is completely maximized. 

The standard formula for variance is $\frac{1}{n}\sum (x_i - \bar{x})^2$. Substituting our projected points into this formula gives the **Projected Variance**:

$$\text{Projected Variance} = \frac{1}{n} \sum_{i=1}^{n} \left( u^T x_i - u^T \bar{x} \right)^2$$

This sets up a constrained optimization problem: **Maximize this variance expression subject to the constraint that $\vec{u}$ remains a unit vector ($u^Tu = 1$).**

---

## 5. The Covariance Matrix

To solve this maximization problem cleanly using linear algebra, we pull the vector $\vec{u}$ out of the summation. This naturally exposes the **Covariance Matrix** (denoted as $S$ or $\Sigma$).

For a 3-feature dataset with variables $X$, $Y$, and $Z$, the Covariance Matrix is a square matrix that summarizes all structural relationships across your features:

| | $X$ | $Y$ | $Z$ |
| :--- | :---: | :---: | :---: |
| **$X$** | **$V_x$** | $C_{x,y}$ | $C_{x,z}$ |
| **$Y$** | $C_{y,x}$ | **$V_y$** | $C_{y,z}$ |
| **$Z$** | $C_{z,x}$ | $C_{z,y}$ | **$V_z$** |

### Key Properties of the Covariance Matrix:
* **The Main Diagonal ($V_x, V_y, V_z$):** These cells represent the **variance** of each individual feature with itself.
* **Off-Diagonal Elements ($C_{i,j}$):** These cells represent the **covariance** between two distinct features (how they move together).
* **Symmetry:** The matrix is perfectly symmetric along the diagonal because the covariance between $X$ and $Y$ is identical to the covariance between $Y$ and $X$ ($C_{x,y} = C_{y,x}$).

### Rewriting the Variance Objective
By factoring out $\vec{u}$, the original projected variance equation simplifies elegantly into matrix notation using the Covariance Matrix ($S$):

$$\text{Projected Variance} = u^T S u$$

This transforms our optimization challenge into finding the vector $\vec{u}$ that maximizes $u^T S u$ under the constraint $u^T u = 1$. This is solved using Lagrange Multipliers, which leads directly to finding the **Eigenvalues and Eigenvectors** of the Covariance Matrix!

---

## 6. Linear Transformations, Eigenvalues, and Eigenvectors

To truly understand how PCA extracts new axes, we have to look at the geometry of linear algebra.

* **Linear Transformations:** A matrix acts as a geometric transformation sheet. When you multiply a matrix by a vector, it typically **rotates** and **scales** that vector within the coordinate space.
* **Eigenvectors:** An eigenvector is a special vector whose **direction does not change** when a linear transformation is applied to it. It stays on its original span line; it is purely stretched or shrunk.
* **Eigenvalues ($\lambda$):** The eigenvalue is the scalar factor by which the corresponding eigenvector stretches, squashes, or reverses.



> **The PCA Connection:** As highlighted in the lecture snippet, the **largest eigenvector** of the covariance matrix points directly into the spatial direction of the **largest variance** in the data. The magnitude of this stretch matches its **eigenvalue**. The second largest eigenvector points in the direction of the second largest spread while remaining perfectly orthogonal (perpendicular) to the first.

---

## 7. Step-by-Step Mathematical Pipeline

To run a complete PCA reduction on a raw dataset, follow this step-by-step pipeline:

1. **Mean Centering / Standard Scaling:** Shift the data cloud so its center sits exactly at the origin $(0,0)$. Scale the features to ensure unit variance.
2. **Compute the Covariance Matrix ($S$):** Calculate the variance of each column along with the pairwise covariance between all columns.
3. **Eigendecomposition:** Compute the eigenvalues ($\lambda$) and eigenvectors ($\vec{v}$) of the covariance matrix.
4. **Sort and Select:** Sort the eigenvalues in descending order. Pick the top $k$ eigenvectors to form your target low-dimensional projection matrix.
5. **Transform Data:** Project the original features onto the selected eigenvectors using a matrix dot product.

---

## 8. Practical Code Implementation & Feature Transformation

Here is the complete Python workflow implementing manual PCA step-by-step using standard libraries (`NumPy`, `Pandas`, `Scikit-Learn`), followed by a coordinate transformation step to project 3D data into a 2D space.

### Step 1: Synthesize and Center the 3D Dataset

```
import numpy as np
import pandas as pd
from sklearn.preprocessing import StandardScaler

# Seed for reproducibility
np.random.seed(23) 

# Generate Class 1: 3D normal distribution centered at (0,0,0)
mu_vec1 = np.array([0, 0, 0])
cov_mat1 = np.array([[1, 0, 0], [0, 1, 0], [0, 0, 1]])
class1_sample = np.random.multivariate_normal(mu_vec1, cov_mat1, 20)
df = pd.DataFrame(class1_sample, columns=['feature1', 'feature2', 'feature3'])
df['target'] = 1

# Generate Class 2: 3D normal distribution centered at (1,1,1)
mu_vec2 = np.array([1, 1, 1])
cov_mat2 = np.array([[1, 0, 0], [0, 1, 0], [0, 0, 1]])
class2_sample = np.random.multivariate_normal(mu_vec2, cov_mat2, 20)
df1 = pd.DataFrame(class2_sample, columns=['feature1', 'feature2', 'feature3'])
df1['target'] = 0

# Merge and shuffle samples
df = pd.concat([df, df1], ignore_index=True).sample(40, random_state=23)

# Apply Standard Scaling (Mean Centering)
scaler = StandardScaler()
df.iloc[:, 0:3] = scaler.fit_transform(df.iloc[:, 0:3])
```

### Step 2: Build Covariance Matrix & Extract Eigenpairs
```
# Compute Covariance Matrix (row-wise calculation)
covariance_matrix = np.cov([df.iloc[:, 0], df.iloc[:, 1], df.iloc[:, 2]])

# Calculate Eigenvalues and Eigenvectors
eigen_values, eigen_vectors = np.linalg.eig(covariance_matrix)

print("Eigenvalues:\n", eigen_values)
print("\nEigenvectors (Columns):\n", eigen_vectors)

**Output Observations:**
* The generated eigenvalues match the scale of variance: `[1.3536, 0.9455, 0.7777]`.
* The columns of the `eigen_vectors` matrix represent our new principal directions.
```

### Step 3: Project 3D Data into a 2D Subspace

To compress our data from 3D down to 2D, we slice out the first two principal component rows from our sorted eigenvectors and calculate the dot product with our scaled data matrix:
```
# Select the top 2 principal components (PC1 and PC2 directions)
# Note: transposing or slicing based on np.linalg.eig column properties
pc = eigen_vectors[:, 0:2].T 

# Transform the original 3D features into the 2D plane
# Shape alignment: Matrix Dot Product (40 samples, 3 features) x (3 features, 2 principal components)
transformed_df = np.dot(df.iloc[:, 0:3], pc.T)

# Convert to a clean DataFrame
new_df = pd.DataFrame(transformed_df, columns=['PC1', 'PC2'])
new_df['target'] = df['target'].values

print(new_df.head())
```
