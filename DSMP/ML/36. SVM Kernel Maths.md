# Support Vector Machines (SVM) — Lecture 3: Kernels & Constrained Optimization

## 1. High-Level Summary
* **SVM Definition:** Support Vector Classifier (SVC) + Kernel Methods.
* **Core Advantage:** By integrating kernels, Support Vector Classifiers can construct complex, **non-linear decision boundaries**.

---

## 2. Kernels & The "Kernel Trick"

### 2.1 Non-Linear Intuition
Consider a 1D dataset mapping CGPA to a Binary Output (e.g., Side Effects):
* CGPA = 72 $\to Y = 1$
* CGPA = 32 $\to Y = 0$
* CGPA = 26 $\to Y = 0$
* CGPA = 5 $\to Y = 1$

In 1D space, no single linear threshold (point/line) can separate the $1$s from the $0$s because the $0$s are sandwiched in the center.

**Kernel Approach:**
1. Transform lower-dimensional data into a higher-dimensional space (e.g., mapping $x \to (x, x^2)$).
2. In higher dimensions, the data points become **linearly separable**.
3. A linear Support Vector Classifier (SVC) finds a hyperplane separating the classes.
4. Projecting this linear boundary back into the original lower-dimensional space forms a **non-linear decision boundary**.

```
Lower Dims (Non-separable) ---> [ Higher Dims Transformation ] ---> Linearly Separable ---> Linear Boundary ---> Project Back (Non-Linear Boundary)
```

### 2.2 Popular Types of Kernels
1. **Linear Kernel:** Standard dot product; used when data is already linearly separable.
2. **Radial Basis Function (RBF / Gaussian) Kernel:** Maps data into infinite-dimensional space using distance-based Gaussian functions.
3. **Polynomial Kernel:** Computes interactions across features up to degree $d$.
4. **Sigmoid Kernel:** Derived from neural network activation functions.

---

### 2.3 The "Kernel Trick"
* **The Problem:** Explicitly projecting data into higher dimensions (e.g., $1000\text{D}$ or infinite dimensions) involves massive computational and memory overhead.
* **The Solution (Kernel Trick):** A kernel function computes the **dot product** (similarity) of two vectors in higher-dimensional space **without actually transforming the data points into that higher-dimensional space**.
* **Key Benefit:** All calculations are performed efficiently in the original lower-dimensional space ($2\text{D}/\text{ND}$), saving immense computational cost while achieving non-linear separation.

## 3. Constrained Optimization & Lagrange Multipliers

In Linear Regression or OLS, unconstrained optimization is performed by setting the partial derivatives directly to zero: $\frac{\partial L}{\partial w} = 0$. In SVM, we face a **constrained optimization problem** (maximizing margin while respecting class boundary conditions).

---

### 3.1 Geometric Foundations: Gradients & Contours

* **Contour Lines (Level Sets):** Curves connecting points where a function $f(x, y)$ takes an identical value (like altitude lines on a topographical map).
* **Gradient Vector ($\nabla f$):** Points in the direction of the steepest rate of increase of the function.
* **Perpendicularity Rule:** The gradient vector at any point is strictly **perpendicular (orthogonal)** to the contour line passing through that same point.

---

### 3.2 The Constrained Optimization Condition

To maximize an objective function $f(x, y)$ subject to a constraint $g(x, y) = c$:
* Geometrically, the maximum occurs at the exact point where a contour line of $f(x, y)$ is **tangent** (touches smoothly) to the constraint curve $g(x, y) = c$.
* At this tangency point, the gradient vector of the objective function ($\nabla f$) and the gradient vector of the constraint ($\nabla g$) point in the **exact same (or opposite) direction**.
* Therefore, they are scalar multiples of each other:

$$\nabla f(x, y) = \lambda \nabla g(x, y)$$

Where $\lambda$ is a scalar called the **Lagrange Multiplier**.

---

## 4. Step-by-Step Mathematical Solution (From Handwritten Slides)

### Problem Definition
$$\text{Maximize } z = f(x, y) = x^2 y \quad \text{subject to constraint } g(x, y) = x^2 + y^2 = 1$$

---

### Step 1: Compute Gradients

1. **Objective Gradient ($\nabla f$):**
   $$\nabla f(x, y) = \begin{bmatrix} \frac{\partial f}{\partial x} \\ \frac{\partial f}{\partial y} \end{bmatrix} = \begin{bmatrix} 2xy \\ x^2 \end{bmatrix}$$

2. **Constraint Gradient ($\nabla g$):**
   $$\nabla g(x, y) = \begin{bmatrix} \frac{\partial g}{\partial x} \\ \frac{\partial g}{\partial y} \end{bmatrix} = \begin{bmatrix} 2x \\ 2y \end{bmatrix}$$

---

### Step 2: Apply the Tangency Condition ($\nabla f = \lambda \nabla g$)

$$\begin{bmatrix} 2xy \\ x^2 \end{bmatrix} = \lambda \begin{bmatrix} 2x \\ 2y \end{bmatrix}$$

This yields two scalar equations:
1. $2xy = \lambda (2x) \implies y = \lambda \quad (\text{assuming } x \neq 0)$
2. $x^2 = \lambda (2y)$

---

### Step 3: Solve System of Equations with Constraint

Substitute $y = \lambda$ into Equation (2):
$$x^2 = 2y(y) \implies x^2 = 2y^2$$

Substitute $x^2 = 2y^2$ into the constraint equation $x^2 + y^2 = 1$:
$$2y^2 + y^2 = 1 \implies 3y^2 = 1 \implies y^2 = \frac{1}{3} \implies y = \pm \frac{1}{\sqrt{3}}$$

Now find $x$:
$$x^2 = 2\left(\frac{1}{3}\right) = \frac{2}{3} \implies x = \pm \sqrt{\frac{2}{3}}$$

---

### Step 4: Evaluate Critical Points to Find Maximum $z = x^2 y$

The candidate critical points are:
1. $\left(\sqrt{\frac{2}{3}}, \frac{1}{\sqrt{3}}\right) \implies z = \left(\frac{2}{3}\right)\left(\frac{1}{\sqrt{3}}\right) = \mathbf{\frac{2}{3\sqrt{3}}}$ **(Maximum)**
2. $\left(\sqrt{\frac{2}{3}}, -\frac{1}{\sqrt{3}}\right) \implies z = \left(\frac{2}{3}\right)\left(-\frac{1}{\sqrt{3}}\right) = -\frac{2}{3\sqrt{3}}$
3. $\left(-\sqrt{\frac{2}{3}}, \frac{1}{\sqrt{3}}\right) \implies z = \left(\frac{2}{3}\right)\left(\frac{1}{\sqrt{3}}\right) = \mathbf{\frac{2}{3\sqrt{3}}}$ **(Maximum)**
4. $\left(-\sqrt{\frac{2}{3}}, -\frac{1}{\sqrt{3}}\right) \implies z = \left(\frac{2}{3}\right)\left(-\frac{1}{\sqrt{3}}\right) = -\frac{2}{3\sqrt{3}}$

---

## 5. The Lagrangian Function Formulation

Instead of solving gradient equations separately, we convert the constrained optimization problem into an **unconstrained optimization problem** by defining the **Lagrangian Function** $L(x, y, \lambda)$:

$$L(x, y, \lambda) = f(x, y) - \lambda \big(g(x, y) - c\big)$$

For our specific example:
$$L(x, y, \lambda) = x^2 y - \lambda (x^2 + y^2 - 1)$$

### Finding Critical Points via Partial Derivatives
Take partial derivatives with respect to $x$, $y$, and $\lambda$, setting each to $0$:

1. $\frac{\partial L}{\partial x} = \frac{\partial f}{\partial x} - \lambda \frac{\partial g}{\partial x} = 0 \implies 2xy - \lambda(2x) = 0$
2. $\frac{\partial L}{\partial y} = \frac{\partial f}{\partial y} - \lambda \frac{\partial g}{\partial y} = 0 \implies x^2 - \lambda(2y) = 0$
3. $\frac{\partial L}{\partial \lambda} = -(g(x, y) - 1) = 0 \implies x^2 + y^2 = 1$

Notice that setting $\frac{\partial L}{\partial x} = 0$, $\frac{\partial L}{\partial y} = 0$, and $\frac{\partial L}{\partial \lambda} = 0$ recovers the original system of equations.

## 6. Summary Comparison Table

| Concept | Unconstrained Optimization (e.g., OLS) | Constrained Optimization (e.g., SVM) |
| --- | --- | --- |
| **Objective** | Minimize/Maximize $f(x)$ freely | Minimize/Maximize $f(x)$ subject to $g(x) \le 0$ or $g(x) = c$ |
| **Method** | Set $\nabla f = 0$ | Form Lagrangian $L(x, \lambda) = f(x) - \lambda g(x)$; set $\nabla L = 0$ |
| **Role of Multiplier** | N/A | $\lambda$ balances objective optimization against constraint boundary limits |
