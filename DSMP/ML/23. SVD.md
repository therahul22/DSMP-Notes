# Linear Algebra: Advanced Matrix Decompositions

This document covers the advanced concepts of **Singular Value Decomposition (SVD)** and its relationship to Eigen Decomposition, specifically addressing non-square and rectangular matrices.

---

## 1. Beyond Square Matrices: SVD

While Eigen Decomposition is strictly limited to square matrices, **Singular Value Decomposition (SVD)** allows for the decomposition of any $m \times n$ matrix.

### The SVD Equation
For any matrix $A$ of order $m \times n$, the decomposition is:
$$A = U \Sigma V^T$$

* **$U$**: An $m \times m$ orthogonal matrix representing the output rotation.
* **$\Sigma$**: An $m \times n$ **rectangular diagonal matrix** containing the singular values.
* **$V^T$**: The transpose of an $n \times n$ orthogonal matrix representing the input rotation.

### The Role of the Rectangular Diagonal Matrix ($\Sigma$)
A rectangular diagonal matrix applies two transformations simultaneously:
1. **Dimension Change**: It maps data from one dimension to another (increasing or decreasing the feature space).
2. **Stretching**: It scales the data along the principal axes using its singular values (which are the square roots of the eigenvalues of $AA^T$ or $A^TA$).

---

## 2. Geometric Intuition of SVD
SVD decomposes a linear transformation into three distinct geometric stages:
1. **Rotation ($V^T$):** The input space is rotated to align with the eigenvectors of $A^TA$.
2. **Scaling ($\Sigma$):** The data undergoes dimensional reduction or expansion, along with scaling.
3. **Rotation ($U$):** A final rotation is applied in the output space.



---

## 3. SVD in PCA and Data Science

SVD is often preferred over standard Eigen Decomposition in machine learning (like in `sklearn`) because it is numerically more stable and does not require the matrix to be square.

### Relationship to Covariance Matrix
* **Derivation**: $U$ contains the eigenvectors of $AA^T$, and $V$ contains the eigenvectors of $A^TA$.
* **PCA Application**: If $X$ is a centered data matrix, performing SVD on $X$ directly yields the same principal components that would be obtained by performing Eigen Decomposition on the covariance matrix ($X^TX$).

### How to Apply SVD to a Dataset
1. **Mean Centering**: Subtract the mean from every feature in your dataset to center the data.
2. **Decomposition**: Apply the SVD algorithm ($A = U \Sigma V^T$) to your centered data matrix.
3. **Dimensionality Reduction**: 
    * The matrix $V$ (or $V^T$) provides the principal components (eigenvectors).
    * The singular values in $\Sigma$ indicate the variance captured.
    * Project the data onto the top $k$ principal components to reduce dimensionality.

## 4. Summary Comparison

| Feature | Eigen Decomposition | Singular Value Decomposition (SVD) |
| :--- | :--- | :--- |
| **Matrix Type** | Square matrices only | Any $m \times n$ matrix |
| **Diagonal Matrix** | Square ($\Lambda$) | Rectangular ($\Sigma$) |
| **Basis** | Eigenvectors | Singular vectors ($U$ and $V$) |
| **Primary Use** | Matrix powers ($A^{1000}$) | PCA, Noise reduction, Compression |
