# Mathematical Derivation of Gradient Boosting for Classification

In this lecture, we answer the core mathematical "whys" behind Gradient Boosting Classification:
1. Why is the initial base prediction $f_0(x)$ equal to the **log-odds** of the target?
2. Why is the pseudo-residual simply $(y_i - p_i)$?
3. Where does the leaf node transformation formula $\gamma = \frac{\sum \text{Residual}}{\sum p(1-p)}$ come from?

---

## 1. Defining the Loss Function in Log-Odds Space

In binary classification, the standard loss function is **Binary Cross-Entropy (Log-Loss)**:

$$L(y, \hat{y}) = - \frac{1}{N} \sum_{i=1}^N \left[ y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \right]$$

Where:
* $y_i \in \{0, 1\}$ is the actual binary target.
* $\hat{y}_i = p_i$ is the predicted probability.

### Why Convert Probability to Log-Odds Space?
Gradient Boosting adds outputs of weak decision trees sequentially:
$$f_M(x) = f_0(x) + \sum_{m=1}^M \gamma_m(x)$$

* **Unconstrained Prediction Space:** Probabilities are strictly bounded in $[0, 1]$. Summing raw tree outputs could push predicted probabilities out of bounds ($< 0$ or $> 1$). Log-Odds span from $-\infty$ to $+\infty$, making additive modeling unbounded and mathematically stable.
* **Gradient Behavior:** Operating in log-odds prevents vanishing gradients when probabilities approach $0$ or $1$.

### Substituting Log-Odds into the Loss Function
Let $\gamma_i = \text{log-odds}_i = \log\left(\frac{p_i}{1 - p_i}\right)$.
Rearranging for probability $p_i$ via the Logistic Sigmoid Function:

$$p_i = \frac{e^{\gamma_i}}{1 + e^{\gamma_i}} = \frac{1}{1 + e^{-\gamma_i}}$$

Substitute $p_i$ and $(1 - p_i) = \frac{1}{1 + e^{\gamma_i}}$ into the single-point Log-Loss $L(y_i, \gamma_i)$:

$$L(y_i, \gamma_i) = - \left[ y_i \log\left(\frac{e^{\gamma_i}}{1 + e^{\gamma_i}}\right) + (1 - y_i) \log\left(\frac{1}{1 + e^{\gamma_i}}\right) \right]$$

$$L(y_i, \gamma_i) = - \left[ y_i \left( \gamma_i - \log(1 + e^{\gamma_i}) \right) - (1 - y_i) \log(1 + e^{\gamma_i}) \right]$$

Expanding and grouping terms:

$$L(y_i, \gamma_i) = - y_i \gamma_i + y_i \log(1 + e^{\gamma_i}) + \log(1 + e^{\gamma_i}) - y_i \log(1 + e^{\gamma_i})$$

$$\mathbf{L(y_i, \gamma_i) = - y_i \gamma_i + \log(1 + e^{\gamma_i})}$$

---

## 2. Mathematical Step-by-Step Derivation

### Step 1: Deriving the Initial Prediction $f_0(x)$

The algorithm initializes with a constant log-odds value $\gamma$ that minimizes total loss:

$$f_0(x) = \arg\min_{\gamma} \sum_{i=1}^N L(y_i, \gamma) = \arg\min_{\gamma} \sum_{i=1}^N \left[ - y_i \gamma + \log(1 + e^{\gamma}) \right]$$

Take the derivative w.r.t. $\gamma$ and set it to $0$:

$$\frac{\partial}{\partial \gamma} \sum_{i=1}^N \left[ - y_i \gamma + \log(1 + e^{\gamma}) \right] = 0$$

$$\sum_{i=1}^N \left( - y_i + \frac{e^{\gamma}}{1 + e^{\gamma}} \right) = 0$$

Since $\frac{e^{\gamma}}{1 + e^{\gamma}} = p$ is constant for all samples:

$$-\sum_{i=1}^N y_i + N \cdot p = 0 \implies p = \frac{\sum_{i=1}^N y_i}{N} = p_{\text{avg}}$$

Converting this baseline optimal probability $p_{\text{avg}}$ back to log-odds:

$$\mathbf{f_0(x) = \gamma_0 = \log\left(\frac{p_{\text{avg}}}{1 - p_{\text{avg}}}\right)}$$

---

### Step 2(a): Deriving the Pseudo-Residual ($r_{im}$)

The pseudo-residual $r_{im}$ is defined as the negative gradient of the loss function w.r.t. the prediction $f(x_i)$:

$$r_{im} = -\left[ \frac{\partial L(y_i, f(x_i))}{\partial f(x_i)} \right]_{f(x_i) = f_{m-1}(x_i)}$$

Using our loss function $L(y_i, f(x_i)) = - y_i f(x_i) + \log(1 + e^{f(x_i)})$:

$$\frac{\partial L}{\partial f(x_i)} = - y_i + \frac{e^{f(x_i)}}{1 + e^{f(x_i)}} = - y_i + p_{i, m-1}$$

Taking the negative of this derivative gives:

$$\mathbf{r_{im} = - (- y_i + p_{i, m-1}) = y_i - p_{i, m-1}}$$

*(The pseudo-residual is simply the actual target minus the predicted probability from the previous step!)*

---

### Step 2(b): Building the Regression Tree

Fit a regression tree to the pseudo-residuals $r_{im}$, creating terminal leaf regions $R_{jm}$ for $j = 1, 2, \dots, J_m$.

---

### Step 2(c): Deriving the Leaf Output Formula ($\gamma_{jm}$)

For each leaf region $R_{jm}$, we need to find a single log-odds value $\gamma_{jm}$ that minimizes loss for all samples $x_i \in R_{jm}$:

$$\gamma_{jm} = \arg\min_{\gamma} \sum_{x_i \in R_{jm}} L(y_i, f_{m-1}(x_i) + \gamma)$$

Because there is no direct closed-form solution for this sum under Log-Loss, we approximate $L(y_i, f_{m-1}(x_i) + \gamma)$ using a **2nd-Order Taylor Series Expansion** around $f_{m-1}(x_i)$:

$$g(\gamma) \approx \sum_{x_i \in R_{jm}} \left[ L(y_i, f_{m-1}(x_i)) + \gamma \left( \frac{\partial L}{\partial f(x_i)} \right) + \frac{1}{2} \gamma^2 \left( \frac{\partial^2 L}{\partial f(x_i)^2} \right) \right]$$

To find the optimal $\gamma$, set $\frac{d}{d\gamma} g(\gamma) = 0$:

$$\sum_{x_i \in R_{jm}} \left[ \frac{\partial L}{\partial f(x_i)} + \gamma \left( \frac{\partial^2 L}{\partial f(x_i)^2} \right) \right] = 0$$

$$\gamma_{jm} = \frac{-\sum_{x_i \in R_{jm}} \frac{\partial L}{\partial f(x_i)}}{\sum_{x_i \in R_{jm}} \frac{\partial^2 L}{\partial f(x_i)^2}}$$

#### Calculating 1st and 2nd Derivatives:
1. **First Derivative:** $\frac{\partial L}{\partial f(x_i)} = - (y_i - p_i) = - \text{Residual}_i$
2. **Second Derivative (Hessian):**
   $$\frac{\partial^2 L}{\partial f(x_i)^2} = \frac{\partial}{\partial f(x_i)} \left( - y_i + \frac{e^{f(x_i)}}{1 + e^{f(x_i)}} \right) = \frac{e^{f(x_i)} (1 + e^{f(x_i)}) - e^{f(x_i)} e^{f(x_i)}}{(1 + e^{f(x_i)})^2}$$
   $$= \frac{e^{f(x_i)}}{(1 + e^{f(x_i)})^2} = \left(\frac{e^{f(x_i)}}{1 + e^{f(x_i)}}\right) \left(\frac{1}{1 + e^{f(x_i)}}\right) = \mathbf{p_i (1 - p_i)}$$

#### Final Leaf Output Formula:
Substituting the 1st and 2nd derivatives back into $\gamma_{jm}$:

$$\mathbf{\gamma_{jm} = \frac{\sum_{x_i \in R_{jm}} (y_i - p_{i, m-1})}{\sum_{x_i \in R_{jm}} p_{i, m-1} (1 - p_{i, m-1})} = \frac{\sum \text{Residual}}{\sum \text{PreviousProb} \cdot (1 - \text{PreviousProb})}}$$

---

### Step 2(d) & Step 3: Ensemble Update & Output

Update prediction model in log-odds space using learning rate $\eta$:

$$f_m(x) = f_{m-1}(x) + \eta \sum_{j=1}^{J_m} \gamma_{jm} I(x \in R_{jm})$$

**Final Classification Prediction:**
$$\hat{f}(x) = f_M(x) \quad \text{(in log-odds space)}$$
$$p_{\text{final}}(x) = \frac{1}{1 + e^{-\hat{f}(x)}} \quad \text{(in probability space)}$$
