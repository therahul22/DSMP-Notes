# Gradient Boosting Regression

Boosting is a general ensemble method in machine learning that creates a strong classifier or regressor by combining predictions from several weak models (typically shallow decision trees). Models are built sequentially, with each new model trained to correct the errors/residuals made by the existing ensemble.

---

## 1. Core Concept: Additive Modeling

Gradient Boosting constructs a predictive model by sequentially combining an initial base prediction with outputs from $M$ decision trees:

$$\hat{f}(x) = f_0(x) + f_1(x) + f_2(x) + \dots + f_M(x)$$

Where:
* **$f_0(x)$ ($m_0$):** The base prediction (the mean of target variable $y$ for squared error loss).
* **$f_1(x), f_2(x), \dots, f_M(x)$ ($m_1, m_2, \dots, m_M$):** Decision trees trained sequentially to fit the remaining errors (residuals) of the cumulative ensemble.

---

## 2. Theoretical Algorithm Breakdown

**Input:** Training set $\{(x_i, y_i)\}_{i=1}^N$, a differentiable loss function $L(y, f(x))$, number of iterations $M$.

1. Initialize $f_0(x) = \arg\min_{\gamma} \sum_{i=1}^N L(y_i, \gamma)$

2. For $m = 1$ to $M$:
   
   - **(a)** For $i = 1, 2, \dots, N$ compute pseudo-residuals:
   
  $$r_{im} = -\left[ \frac{\partial L(y_i, f(x_i))}{\partial f(x_i)} \right]_{f = f_{m-1}}$$
     
   - **(b)** Fit a regression tree to the targets $r_{im}$ giving terminal regions $R_{jm}$, for $j = 1, 2, \dots, J_m$.
   - **(c)** For $j = 1, 2, \dots, J_m$ compute output value $\gamma_{jm}$:
     $$\gamma_{jm} = \arg\min_{\gamma} \sum_{x_i \in R_{jm}} L(y_i, f_{m-1}(x_i) + \gamma)$$
   - **(d)** Update ensemble prediction model:
     $$f_m(x) = f_{m-1}(x) + \sum_{j=1}^{J_m} \gamma_{jm} I(x \in R_{jm})$$

3. **Output final model:** $\hat{f}(x) = f_M(x)$

---

## 3. Mathematical Terminology & Intuition

| Term / Symbol | Name | Description |
| :--- | :--- | :--- |
| **$f_0(x)$** | Initial Prediction | Starting point model (mean of target variable $y$ under squared loss). |
| **$r_{im}$** | Pseudo-Residual | Direction & magnitude of error ($y_i - f_{m-1}(x_i)$ for squared loss). |
| **$R_{jm}$** | Terminal Region | A specific leaf node partition created by tree $m$. |
| **$\gamma_{jm}$** | Leaf Output Value | Optimal prediction update assigned to all samples falling into leaf $j$ of tree $m$. |
| **$M$** | Iterations | Total number of decision trees added to the ensemble. |

## 4. Step-by-Step Example Walkthrough

### **Dataset Reference**
* **Input Features ($X$):** `R&D`, `Ops`, `Marketing`
* **Target ($y$):** `Profit` = $[192, 144, 91]$

---


### **Step 0: Base Model Initialization ($m_0$)**

#### **Mathematical Derivation**
$$f_0(x) = \arg\min_{\gamma} \sum_{i=1}^{N} L(y_i, \gamma)$$

For **Squared Error Loss** $L(y_i, \hat{y}) = \frac{1}{2}(y_i - \hat{y})^2$, setting the derivative with respect to $\gamma$ to zero:

$$\frac{\partial}{\partial \gamma} \sum_{i=1}^{N} \frac{1}{2}(y_i - \gamma)^2 = 0 \implies \sum_{i=1}^{N} (y_i - \gamma) = 0 \implies \gamma = \bar{y} \text{ (Mean of } y\text{)}$$

#### **Application to Dataset**
$$f_0(x) = \frac{192 + 144 + 91}{3} = \frac{427}{3} \approx 142$$

* **Base Model Predictions:** $f_0(x) = [142, 142, 142]$

---

### **Iteration 1 ($m = 1$)**

#### **Sub-step 1(a): Compute Pseudo-Residuals ($r_{i1}$)**
$$r_{i1} = -\left[ \frac{\partial L(y_i, f(x_i))}{\partial f(x_i)} \right]_{f = f_0} = y_i - f_0(x_i)$$


* Row 0: $192 - 142 = \mathbf{50}$
* Row 1: $144 - 142 = \mathbf{2}$
* Row 2: $91 - 142 = \mathbf{-51}$

#### **Sub-step 1(b): Fit Regression Tree ($m_1$)**
Train a decision tree using features $X$ (`R&D`, `Ops`, `Marketing`) to predict target residual array $r_{i1} = [50, 2, -51]$. The tree partitions the feature space into terminal leaf regions $R_{j1}$.

#### **Sub-step 1(c): Calculate Leaf Values ($\gamma_{j1}$)**
$$\gamma_{j1} =  rg\min_{\gamma} \sum_{x_i \in R_{j1}} L(y_i, f_0(x_i) + \gamma)$$

Computes the average residual of samples in leaf region $R_{j1}$.

#### **Sub-step 1(d): Update Ensemble Prediction**
$$f_1(x) = f_0(x) + \sum_{j=1}^{J_1} \gamma_{j1} I(x \in R_{j1}) \implies \hat{y}_1 = m_0 + m_1$$

---

### **Iteration 2 ($m = 2$)**

1. **Compute New Residuals:** $r_{i2} = y_i - f_1(x_i) = y_i - (m_0 + m_1)$
2. **Fit Decision Tree ($m_2$):** Train tree $m_2$ on inputs $X$ and residual targets $r_{i2}$.
3. **Compute Leaf Values ($\gamma_{j2}$):** Find optimal output values for leaves of tree $m_2$.
4. **Update Ensemble:**
   $$f_2(x) = f_1(x) + m_2 = m_0 + m_1 + m_2$$

---

### **Iteration 3 ($m = 3$) and Subsequent Steps**

1. **Compute New Residuals:** $r_{i3} = y_i - f_2(x_i)$
2. **Fit Decision Tree ($m_3$):** Train tree $m_3$ on inputs $X$ and residual targets $r_{i3}$.
3. **Update Ensemble:**
   $$f_3(x) = m_0 + m_1 + m_2 + m_3$$

---

## 5. Summary Table Flow

| Iteration / Model | Model Target | Accumulated Prediction Formula |
| :--- | :--- | :--- |
| **$m_0$ (Base)** | Target $y$ average ($ ar{y}$) | $f_0(x) = m_0$ |
| **$m_1$ (Tree 1)** | 1st Residuals: $r_{i1} = y_i - f_0(x_i)$ | $f_1(x) = m_0 + m_1$ |
| **$m_2$ (Tree 2)** | 2nd Residuals: $r_{i2} = y_i - f_1(x_i)$ | $f_2(x) = m_0 + m_1 + m_2$ |
| **$m_3$ (Tree 3)** | 3rd Residuals: $r_{i3} = y_i - f_2(x_i)$ | $f_3(x) = m_0 + m_1 + m_2 + m_3$ |
| **Final ($\hat{f}(x)$)** | Sum of base prediction + $M$ trees | $\hat{f}(x) = f_M(x) = f_0(x) + \sum_{m=1}^{M} f_m(x)$ |
