# Multiclass Logistic Regression Lecture Notes

## 1. Core Concepts & Problem Setup
* **The Transition to Multiclass:** While standard Logistic Regression natively handles binary classification (0 or 1), real-world data often demands sorting instances into three or more distinct classes. This topic is a frequent target for highly technical interview questions and serves as a fundamental concept in Deep Learning architectures.
* **Linear Foundation:** Because Logistic Regression remains a linear model at its core, it still works by drawing lines, planes, or hyperplanes to carve up the feature space into decision zones. 
* **Concrete Example Matrix:** Consider predicting student **Placement Status** using two features: **CGPA** and **IQ**. Unlike binary classification, our target column contains three distinct, categorical classes: 
  * **Yes (Y)**
  * **No (N)**
  * **Opt-Out (Opt)**
 
| CGPA | IQ | Placement Status (Output) |
| :--- | :--- | :--- |
| 9 | 90 | Y |
| 6 | 60 | N |
| 7 | 70 | Opt |

* **The Query Point Problem:** If an unseen data point arrives—for example, a student with a $\text{CGPA} = 6.5$ and an $\text{IQ} = 65$—how do we leverage linear boundaries to assign the correct placement category? We handle this using two main strategic frameworks: **One-vs-Rest (OVR)** or **Softmax Regression**.

---

## 2. Approach 1: One-vs-Rest (OVR) / One-vs-All (OVA)
The core philosophy of OVR is to break down a single complex multiclass problem into a series of simpler independent binary classification problems.

### The Training Phase
1. **Model Generation:** We train a total number of independent binary logistic regression models exactly equal to the number of classes ($K$) present in our dataset. For our placement example, since $K = 3$, we train exactly 3 distinct models.
2. **Dataset Split via One-Hot Encoding:** We conceptually copy the training data 3 separate times, altering the target labels using a binary layout for each dedicated model:
   * **Model 1 (Class Y vs. Rest):** Treats Class Y as $1$, and everything else (N, Opt) as $0$.
   * **Model 2 (Class N vs. Rest):** Treats Class N as $1$, and everything else (Y, Opt) as $0$.
   * **Model 3 (Class Opt vs. Rest):** Treats Class Opt as $1$, and everything else (Y, N) as $0$.
3. **Parameter Optimization:** Each binary model runs its own optimization loop to solve for its own unique weights ($\beta_0, \beta_1, \beta_2$).

### The Prediction Phase & Normalization
When a query point like $\{6.5, 65\}$ needs to be evaluated, it is passed into all 3 models simultaneously. Each model outputs an independent raw probability stating how likely the point belongs to its focus class:
* Model 1 predicts $P(\text{Yes}) = 0.6$
* Model 2 predicts $P(\text{No}) = 0.3$
* Model 3 predicts $P(\text{Opt-Out}) = 0.5$

**The Flaw:** Notice that these independent raw probabilities do not sum up to $1$ ($0.6 + 0.3 + 0.5 = 1.4$). To convert these values into a mathematically sound probability distribution, we must **normalize** the scores by dividing each by the sum of all outputs:
* $$P(\text{Yes}) = \frac{0.6}{0.6 + 0.3 + 0.5} = \frac{0.6}{1.4} \approx 0.43$$
* $$P(\text{No}) = \frac{0.3}{0.6 + 0.3 + 0.5} = \frac{0.3}{1.4} \approx 0.21$$
* $$P(\text{Opt-Out}) = \frac{0.5}{0.6 + 0.3 + 0.5} = \frac{0.5}{1.4} \approx 0.36$$

**Bottleneck:** If a problem has an exceptionally high number of classes (e.g., 100+ categories), you are forced to train a matching number of 100+ separate models, making the approach highly time-consuming and computationally expensive.

## 3. Approach 2: Softmax / Multinomial Logistic Regression
Instead of building a patchwork of individual binary models, Multinomial Logistic Regression handles all classes natively inside a single unified model using the **Softmax function**. 

### The Softmax Function
The Softmax function expands the binary Sigmoid function to handle vector representations across $K$ classes. It takes a vector of raw linear scores $\vec{z}$ and maps them into safe probabilities that natively sum to $1$.

$$\sigma(\vec{z})_i = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}$$

For our 3-class matrix, the individual mathematical terms expand out to:
$$\sigma(z_1) = \frac{e^{z_1}}{e^{z_1} + e^{z_2} + e^{z_3}}, \quad \sigma(z_2) = \frac{e^{z_2}}{e^{z_1} + e^{z_2} + e^{z_3}}, \quad \sigma(z_3) = \frac{e^{z_3}}{e^{z_1} + e^{z_2} + e^{z_3}}$$

### Model Parameters
Because this linear model must draw decision lines for each target class simultaneously, it maintains a dedicated set of parameters for each line. 
* Every individual line has 3 parameters ($\beta_0, \beta_1, \beta_2$) for our two input features.
* With 3 classes, the global architecture tracks a total of $3 \times 3 = 9$ parameters simultaneously.

---

## 4. Training Softmax Regression Natively

### The Categorical Cross Entropy Loss Function
During training, we apply one-hot encoding to split the target column into binary indicators for each class. However, instead of running separate binary algorithms, we optimize our 9 parameters collectively using the **Categorical Cross Entropy Loss** function ($L$):

$$L = -\frac{1}{n} \sum_{i=1}^{n} \sum_{k=1}^{K} y_i^k \log(\hat{y}_i^k)$$

Where:
* $y_i^k$ is the true one-hot encoded label component ($1$ if point $i$ belongs to class $k$, else $0$).
* $\hat{y}_i^k$ is the Softmax predicted probability for that specific class.

**How it works as an algebraic switch:** Because $y_i^k$ is only $1$ for the correct true target class and $0$ for all others, the internal summation collapses down for each data point to just the log probability of its true class. For example, if a point is actually Opt-Out ($y^{\text{opt}}=1$), the inner loss contribution is simply $\log(\hat{y}^{\text{opt}})$.

### The Optimization Loop
To calculate the perfect arrangement of all 9 parameters, we execute an iterative numerical loop using Gradient Descent:
1. **Initialize:** Start with 3 completely random lines by assigning random starter values to all $\beta$ slots.
2. **Compute Gradients:** Calculate the partial derivative of our global loss function with respect to every single parameter weight (e.g., $\frac{\partial L}{\partial \beta_0^1}$).
3. **Update Rule:** Adjust the weights over multiple epochs (running loops typically 100+ times) using the classic descent update step:
   $$\beta_0^1 = \beta_0^1 - \eta \frac{\partial L}{\partial \beta_0^1}$$

---

## 5. Inference and Prediction Flow
Once the training cycle successfully concludes and optimal values for all 9 parameters are locked down, predicting a new candidate instance follows a clean, single-pass pipeline:

1. **Calculate Linear Logits ($z$):** Compute the dot product of our query features with each of our 3 optimized decision lines:
   $$z_{\text{yes}} = \beta_0^{(1)} + \beta_1^{(1)}(\text{CGPA}) + \beta_2^{(1)}(\text{IQ})$$
   $$z_{\text{no}} = \beta_0^{(2)} + \beta_1^{(2)}(\text{CGPA}) + \beta_2^{(2)}(\text{IQ})$$
   $$z_{\text{opt}} = \beta_0^{(3)} + \beta_1^{(3)}(\text{CGPA}) + \beta_2^{(3)}(\text{IQ})$$
2. **Apply Softmax Transformation:** Run these raw linear outputs through the Softmax equation to generate our final predictions:
   $$\hat{y}^{\text{yes}} = \frac{e^{z_{\text{yes}}}}{e^{z_{\text{yes}}} + e^{z_{\text{no}}} + e^{z_{\text{opt}}}}$$

## 6. Strategic Selection: When to Apply OVR vs. Softmax

| Criteria | One-vs-Rest (OVR) | Softmax / Multinomial Regression |
| :--- | :--- | :--- |
| **Mutual Exclusivity** | **Non-Mutually Exclusive:** Use when an instance can simultaneously belong to multiple classes, as each classifier provides a fully independent probability score. | **Mutually Exclusive:** Essential when an instance can only belong to exactly one class. The Softmax function naturally enforces that all class probabilities sum cleanly to 1. |
| **Data Imbalance Handling** | **Superior for Imbalanced Data:** OVR frequently yields higher performance when data classes are highly skewed. Because it creates a dedicated model for each class, you can implement targeted handling for the minority class. | **Sensitive to Imbalance:** Optimizing all paths simultaneously across a single global loss metric can lead the majority classes to dominate the objective function during training. |
| **Computational Efficiency** | **Inefficient for High $K$:** Forces the system to construct, run, and maintain $K$ individual models, slowing down runtime performance as classes expand. | **Highly Efficient:** Computes updates for all parameters simultaneously within a single optimization pass, scaling much better on large datasets. |
| **Interpretability** | **Lower Interpretability:** The raw output values are separate and require subsequent manual normalization to become comparable. | **High Interpretability:** Natively provides a clean probability distribution across classes that is immediately ready to explain and interpret. |

### Task 1: Derive the Sigmoid Function from the Softmax Function
Show that when the number of classes $K = 2$, the Softmax expression mathematically reduces to the classic binary Sigmoid function.
* *Hint:* Set up $\sigma(z_1) = \frac{e^{z_1}}{e^{z_1} + e^{z_2}}$, divide both the numerator and the denominator by $e^{z_1}$, and define a single relative logit variable $z = z_1 - z_2$.

### Task 2: Derive Binary Cross Entropy from Categorical Cross Entropy
Prove that the Categorical Cross Entropy function simplifies directly into the standard Binary Cross Entropy formula when constrained to two outputs ($K=2$).
* *Hint:* Expand the internal class sum using $k \in \{0, 1\}$. Substitute the constraints $y_i^0 = (1 - y_i^1)$ and $\hat{y}_i^0 = (1 - \hat{y}_i^1)$ to witness the binary formula reappear.

### Task 3: Compute the Derivative of the Softmax Function
Locate the derivative $\frac{\partial \sigma(z_i)}{\partial z_j}$ under two scenarios:
1. When $i = j$ (the feature match path).
2. When $i \neq j$ (the cross-interaction paths).
* *Resulting Form:* $\sigma(z_i)(1 - \sigma(z_i))$ for matching indices, and $-\sigma(z_i)\sigma(z_j)$ for non-matching combinations.

### Task 4: Calculate the Gradients of the Cross Entropy Error
Execute the full multivariate chain rule derivation to prove that the final optimization gradient with respect to parameter weights yields the clean expression:
$$\frac{\partial L}{\partial \beta} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)x_i$$
