# Decision Trees: Regression, Advantages & Disadvantages

## 1. CART for Regression
Unlike Decision Trees for classification (which use **Gini Impurity** or **Entropy**), Decision Trees for regression tasks focus on predicting continuous numerical values.

### Splitting Criterion: Variance / MSE Minimization
Instead of measuring class purity, regression trees aim to minimize the variance (or Mean Squared Error) of target values within each node.

#### Mathematical Objective
For a given candidate split $\theta = (j, t_m)$ on feature $j$ with threshold $t_m$, the total weighted variance $G(Q_m, \theta)$ is calculated as:

$$G(Q_m, \theta) = \frac{n_m^{\text{left}}}{n_m} \text{Var}(Q_m^{\text{left}}) + \frac{n_m^{\text{right}}}{n_m} \text{Var}(Q_m^{\text{right}})$$

Where variance at node $Q$ is defined as:

$$\text{Var}(Q) = \frac{1}{|Q|} \sum_{y \in Q} (y - \bar{y})^2$$

The algorithm selects the split parameters $\theta^*$ that minimize total weighted variance across sub-nodes.

### Step-by-Step Feature Evaluation

#### A. Categorical Binary Feature (`Subject`)
* Splits into two groups: `Subject == Physics` vs `Subject != Physics`.
* **Left Subtree (Physics):** Test scores = `[82, 81, 73, 85, 61, 78]`. Calculate individual variance $\text{Var}_{\text{left}}$.
* **Right Subtree (Math):** Test scores = `[59, 60]`. Calculate individual variance $\text{Var}_{\text{right}}$.
* **Weighted Overall Variance:** G = (6 / 8) * Var_left + (2 / 8) * Var_right

#### B. Multi-Class Categorical Feature (`Grade_Level`)
* Evaluated using a **1-vs-All** strategy:
  1. `Freshman` vs `Non-Freshman`
  2. `Sophomore` vs `Non-Sophomore`
  3. `Junior` vs `Non-Junior`
* Weighted variance is computed for all 3 split options. The split yielding the lowest weighted variance is preserved as the candidate for `Grade_Level`.

#### C. Numerical Continuous Feature (`Hours_Studied`)
1. Sort unique numerical values: `[1, 3, 4, 6, 9]`.
2. Compute midpoints as candidate threshold values: `[2.0, 3.5, 5.0, 7.5]`.
3. Calculate weighted variance for each threshold split (e.g., `Hours_Studied <= 3.5`).
4. Select the threshold that yields the minimum variance.

> **Root Node Selection:** The overall lowest weighted variance across `Subject`, `Grade_Level`, and `Hours_Studied` determines the root split node.

## 3. Geometric Intuition & Predictions

### A. Geometric Boundaries
* Non-linear feature distributions are sliced using axis-aligned hyperplanes (vertical/horizontal lines across input axes).
* Slicing sequentially creates distinct rectangular decision regions.
* Slicing data down to individual points produces pure nodes with **zero variance** $(\text{Var}_{\text{left}} = 0)$, causing **extreme overfitting**.

### B. Prediction Mechanism
* **Regression:** The predicted value for any point falling into a specific region is the **mean (average)** of all training target values within that region.
* **Classification:** Predictions are determined via **majority voting (democracy)** among class labels within the region.

---

## 4. Advantages & Disadvantages

### Advantages
* **Clear & Interpretable:** Easy to explain and visualize decision rules.
* **Minimal Data Preparation:** No requirement for feature scaling, normalization, dummy variable creation, or extensive preprocessing. *(Note: Missing values must still be handled prior to model training).*
* **Logarithmic Prediction Complexity:** Prediction time complexity is $O(\log N)$, making execution extremely fast.
* **Mixed Data Types:** Natively handles both numerical and categorical inputs.
* **Non-Linear Relationships:** Capable of mapping highly non-linear decision spaces.
* **Feature Importance:** Automatically provides relative importance metrics for each feature based on total variance/impurity reduction.

### Disadvantages
* **Overfitting Risk:** Fully grown trees easily memorize noise. Mitigated using **pruning**, setting `max_depth`, or defining `min_samples_leaf`.
* **High Instability:** Small fluctuations in training data can drastically alter tree structure. Ensemble methods (Random Forests, Gradient Boosting) reduce this issue.
* **Piecewise Constant Predictions:** Outputs form discrete step functions rather than smooth continuous functions.
* **Inability to Extrapolate:** 
  > **Key Limitation:** Decision trees cannot predict outside the bounds of training target values. Unlike linear algorithms that use functional lines ($y = mx + c$), a Decision Tree assigns unseen out-of-range inputs to the nearest existing boundary leaf, returning its training mean.

## 5. Python Implementation (Decision Tree Regressor)

```python
import numpy as np
import pandas as pd
from sklearn.tree import DecisionTreeRegressor, plot_tree
import matplotlib.pyplot as plt

# 1. Prepare sample dataset
data = {
    'Subject': ['Math', 'Physics', 'Physics', 'Math', 'Physics', 'Physics', 'Physics', 'Physics'],
    'Grade_Level': ['Freshman', 'Freshman', 'Freshman', 'Junior', 'Sophomore', 'Junior', 'Junior', 'Freshman'],
    'Hours_Studied': [4, 1, 4, 6, 1, 3, 4, 9],
    'Test_Score': [59, 82, 81, 60, 73, 85, 61, 78]
}

df = pd.DataFrame(data)

# One-hot encoding for categorical variables
df_encoded = pd.get_dummies(df, columns=['Subject', 'Grade_Level'], drop_first=True)

X = df_encoded.drop('Test_Score', axis=1)
y = df_encoded['Test_Score']

# 2. Instantiate and fit Decision Tree Regressor
regressor = DecisionTreeRegressor(criterion='squared_error', max_depth=3, random_state=42)
regressor.fit(X, y)

# 3. Model predictions & Feature Importance
predictions = regressor.predict(X)
importance = dict(zip(X.columns, regressor.feature_importances_))

print("Feature Importances:", importance)

# 4. Plot Decision Tree
plt.figure(figsize=(10, 6))
plot_tree(regressor, feature_names=X.columns, filled=True)
plt.show()
```
