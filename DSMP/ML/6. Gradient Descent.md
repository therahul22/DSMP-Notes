# Gradient Descent

## 1. Core Mechanics

Gradient Descent is an optimization algorithm used to find the parameters (weights and biases) that minimize a model's cost function (error).

- **Cost Function ($J$):** Measures the error between predicted and actual values.
- **Gradient ($\frac{\partial J}{\partial w}$):** The derivative of the cost function. It points in the direction of the steepest ascent. We subtract it to go *down* the error curve.
- **Learning Rate ($\alpha$):** Determines the size of the step taken during each iteration.
- **Update Rule:** The foundational formula for updating any parameter $w$:

$$
w = w - \alpha \frac{\partial J}{\partial w}
$$

---

## 2. Single Variable Optimization (Intercept $b$ Only)

**Scenario:** The slope ($m$) is fixed. The model only needs to find the optimal intercept ($b$).

### Mathematical Formula

$$
\frac{dJ}{db} = -2 \sum (y - mx - b)
$$

### Python Implementation

> **Note:** This uses NumPy vectorization to calculate the error for all data points at once.

```python
# Constants
m = 78.35       # Fixed slope
b = 100         # Initial guess for intercept
lr = 0.01       # Learning rate
epochs = 100    # Number of iterations

for i in range(epochs):
    # 1. Calculate the gradient for b
    loss_slope = -2 * np.sum(y - m*X.ravel() - b)

    # 2. Update b using the learning rate
    b = b - (lr * loss_slope)
```

---

## 3. Multi-Variable Optimization ($m$ and $b$)

**Scenario:** Standard linear regression where both the slope ($m$) and intercept ($b$) are unknown and must be optimized simultaneously.

### Mathematical Formulas

- **Gradient for $b$:** $\frac{\partial J}{\partial b} = -2 \sum (y - mx - b)$
- **Gradient for $m$:** $\frac{\partial J}{\partial m} = -2 \sum ((y - mx - b) \cdot x)$

### Python Implementation (Vectorized)

> **Note:** Both parameters must be updated at the exact same time at the end of the loop.

```python
# Initial guesses
b = -120
m = 100
lr = 0.001
epochs = 50

for i in range(epochs):
    # 1. Calculate gradients for both variables
    loss_slope_b = -2 * np.sum(y - m*X.ravel() - b)
    loss_slope_m = -2 * np.sum((y - m*X.ravel() - b) * X.ravel())

    # 2. Update both variables simultaneously
    b = b - (lr * loss_slope_b)
    m = m - (lr * loss_slope_m)
```

---

## 4. Implementation Best Practices

### Vectorization vs. Nested Loops

- **Nested Loops:** Iterating row-by-row (e.g., `for j in range(X.shape[0])`) is useful for understanding the underlying math of the summation symbol ($\sum$), but it is computationally slow.
- **Vectorization:** Using `np.sum()` applies the operation to the entire array at the C-level. Always use this for production code.

### Managing the Learning Rate

- **Too High:** The step size is too large, causing the algorithm to bounce out of the "valley" and the error to explode (divergence).
- **Too Low:** The step size is microscopic, requiring millions of epochs to reach the bottom (inefficient convergence).
- **Dataset Scaling:** Larger datasets naturally generate larger sum gradients. You must lower your learning rate (e.g., **0.1 → 0.001**) as your dataset grows to prevent the gradients from exploding.
