This comprehensive guide covers the core concepts, underlying mathematics, scratch implementation, and evaluation metrics of Linear Regression.

## 1. Theoretical Overview & Core Concepts

Linear Regression is a fundamental supervised machine learning algorithm used to predict a continuous dependent target variable ($y$) based on one or more independent feature variables ($X$). It assumes a linear or continuous trend between inputs and outputs.

```
                     ┌── Simple Linear Regression (1 Input Element)
                     │
Linear Regression ───┼── Multiple Linear Regression (> 1 Input Element)
                     │
                     └── Polynomial Linear Regression (Curvilinear Relationships)
```

### Types of Linear Regression
* **Simple Linear Regression**: Involves exactly **one** independent variable ($X$) and **one** dependent variable ($y$).
  $$\text{Equation: } y = mx + b \quad \text{or} \quad \text{package} = m \times \text{cgpa} + b$$
  *Where:* $m$ represents the weight/slope, and $b$ represents the offset/y-intercept.
* **Multiple Linear Regression**: Involves **two or more** independent features predicting a single dependent variable.
  $$\text{Equation: } y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_n x_n$$
* **Polynomial Linear Regression**: Models non-linear, curved relationships by converting existing features into higher-degree powers ($x^2, x^3$). It is still mathematically classified as "linear" because it remains linear with respect to its unknown coefficients ($\beta$).

## 2. Mathematical Foundation (From Scratch)

To construct a regression algorithm without external tools, we look for a **line of best fit** that minimizes the mapping error between inputs and actual values.

### Defining the Error Function
For any given data point $(x_i, y_i)$, the vertical distance between the actual point and the predicted line point ($\hat{y}_i$) is its unique residual error ($d_i$).
$$d_i = (y_i - \hat{y}_i) \quad \text{where} \quad \hat{y}_i = mx_i + b$$

To calculate global loss, we compute the **Sum of Squared Errors (SSE)**:
$$E(m, b) = \sum_{i=1}^{n} d_i^2 = \sum_{i=1}^{n} (y_i - mx_i - b)^2$$

#### Why use Squares instead of Absolute Values (Modulus)?
1. **Penalizing Outliers**: Squaring differences grows exponentially for larger errors, ensuring the model avoids massive individual misses.
2. **Differentiability**: The absolute error function forms a sharp V-shape vertex that is non-differentiable at exactly $0$, complicating direct derivative optimization methods.

### Finding Optimal $m$ and $b$
We can solve for parameters $m$ and $b$ using two main approaches:
1. **Closed-Form Solution (Ordinary Least Squares - OLS)**: Direct mathematical formulas used primary on low-dimensional datasets.
2. **Non-Closed-Form Solution (Gradient Descent)**: An iterative optimization routine used heavily on massive, multi-dimensional feature spaces.

#### Step 1: Solving for $b$ (Y-Intercept)
To locate the minimum global error, we take the partial derivative of the error function with respect to $b$ and set it to $0$:
$$\frac{\partial E}{\partial b} = \frac{\partial}{\partial b} \sum_{i=1}^{n} (y_i - mx_i - b)^2 = 0$$
$$\Rightarrow \sum_{i=1}^{n} -2(y_i - mx_i - b) = 0 \Rightarrow \sum_{i=1}^{n} y_i - m\sum_{i=1}^{n} x_i - \sum_{i=1}^{n} b = 0$$

Since $\sum_{i=1}^{n} b = nb$, dividing through by total dataset rows ($n$) gives:
$$\bar{y} - m\bar{x} - b = 0 \Rightarrow b = \bar{y} - m\bar{x}$$
*Where:* $\bar{y}$ and $\bar{x}$ are the mean values of the target and feature columns respectively.

#### Step 2: Solving for $m$ (Slope)
Substituting $b = \bar{y} - m\bar{x}$ back into the error expression yields:
$$E(m) = \sum_{i=1}^{n} (y_i - mx_i - (\bar{y} - m\bar{x}))^2 = \sum_{i=1}^{n} ((y_i - \bar{y}) - m(x_i - \bar{x}))^2$$

Differentiating this expression with respect to $m$ and isolating the term gives the final OLS closed-form calculation for the slope weight:
$$m = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n} (x_i - \bar{x})^2}$$

#### Visualizing in 3D Space
Because our error function $E(m,b)$ changes across two distinct tuning inputs, it maps out a 3D convex surface. The ultimate engineering objective of training is reaching the lowest valley point of this topology, defining the absolute minimum point of net loss.

## 3. Python Implementation

### Code From Scratch (Building our own Class)
```python
import numpy as np

class ScratchLR:
    def __init__(self):
        self.m = None
        self.b = None
        
    def fit(self, X_train, y_train):
        # Convert inputs safely to numpy arrays
        X_train = np.array(X_train).flatten()
        y_train = np.array(y_train)
        
        x_mean = np.mean(X_train)
        y_mean = np.mean(y_train)
        
        # Calculate slope (m) using OLS closed-form formula
        num = np.sum((X_train - x_mean) * (y_train - y_mean))
        den = np.sum((X_train - x_mean) ** 2)
        
        self.m = num / den
        self.b = y_mean - (self.m * x_mean)
        
    def predict(self, X_test):
        X_test = np.array(X_test).flatten()
        return (self.m * X_test) + self.b
```

### Implementing Using `scikit-learn`
```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression

# 1. Load data
df = pd.read_csv('placement.csv')

# 2. Extract Data using .iloc 
# Note: X must explicitly be parsed as a 2D matrix structure
X = df.iloc[:, 0:1]  # Matrix Dimensions: (n_samples, n_features)
y = df.iloc[:, -1]   # Target Array Dimensions: (n_samples,)

# 3. Create Train-Test Split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=2)

# 4. Fit the Model
lr = LinearRegression()
lr.fit(X_train, y_train)

# 5. Extract calculated metrics
print(f"Weights (m): {lr.coef_}")
print(f"Intercept (b): {lr.intercept_}")

# 6. Inference evaluation for a single sample point
# We use .values.reshape(1, 1) because the algorithm requires a 2D input structure
sample_query = X_test.iloc[0].values.reshape(1, 1)
prediction = lr.predict(sample_query)
print(f"Predicted Package: {prediction[0]}")
```

#### Why does `scikit-learn` require `df.iloc[:, 0:1]` for $X$?
The library expects the feature configuration input $X$ to remain a structured 2D array or Matrix, even if it contains only a single individual column. Passing data slicing formats like `df.iloc[:, 0]` pulls data into a flat 1D Series object, which throws structural orientation shape syntax warnings.

## 4. Regression Metrics & Evaluation Efficiency

To calculate the structural error and goodness of fit across a model, we can measure performance using five distinct metrics.

### 1. Mean Absolute Error (MAE)
Measures the average magnitude of absolute errors across predictions.
$$\text{MAE} = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$$
* **Advantages**: Retains the exact same unit tracking format as our target data, making it intuitive to read. It is naturally robust against the influence of extreme outlier skew.
* **Disadvantages**: The absolute mathematical transformation graph is non-differentiable at exactly $0$, making optimization trickier in certain complex loss profiles.

### 2. Mean Squared Error (MSE)
Measures the average of the squared errors.
$$\text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$
* **Advantages**: Completely differentiable everywhere, which makes it ideal for framing direct mathematical loss functions.
* **Disadvantages**: Changes unit properties into squared variants (e.g., $\text{LPA}^2$), obscuring immediate context. It is highly sensitive to outliers, as large misses dominate the final metric score.

### 3. Root Mean Squared Error (RMSE)
The square root of the computed MSE value, bringing scale back into direct correlation.
$$\text{RMSE} = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2}$$
* **Advantages**: Brings the output metric back to the raw scale context of the original target units.
* **Disadvantages**: Like MSE, it is vulnerable to outlier values because larger errors skew the root computation upward.

### 4. $R^2$ Score (Coefficient of Determination)
Evaluates the "goodness of fit" by comparing model variance against a primitive baseline horizontal mean line.
$$R^2 = 1 - \frac{\text{SS}_{\text{Residual}}}{\text{SS}_{\text{Mean}}} = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$
* **Interpretation**: Represents the percentage of target variance explained by model features. An $R^2$ score of $0.80$ means $80\%$ of the variance is accounted for by the inputs.
* **Score Bounds**: Maxes out at $1$ for flawless fits. A score of $0$ indicates performance no better than predicting the dataset mean. If you run into a negative output, it indicates a structural blunder where predictions fit the data worse than a flat mean line.
* **Disadvantages**: Its value can only go up or stay flat as you add more columns—even completely irrelevant ones—which can give a false sense of model improvement.

### 5. Adjusted $R^2$ Score
Corrects the baseline flaws of standard $R^2$ by penalizing the inclusion of non-predictive features.
$$\text{Adjusted } R^2 = 1 - \left[ \frac{(1 - R^2)(n - 1)}{n - 1 - k} \right]$$
*Where:* $n$ matches total sample row counts, and $k$ represents your independent variable counts.
* **Case 1: Adding an Irrelevant Column**: If a generic column with zero structural connection is appended to the data matrix, the standard $R^2$ value shows a slight uptick. However, the value of $k$ increases simultaneously, increasing the equation's denominator and lowering the overall Adjusted $R^2$ value.
* **Case 2: Adding a Relevant Column**: If a highly correlated feature is added, the improvement in model predictive power causes $R^2$ to surge. This drop in the numerator easily offsets the increase in $k$, causing the total Adjusted $R^2$ output value to rise smoothly.
