# Logistic Regression Comprehensive Lecture Notes

## 1. Core Concepts
* **Classification vs. Regression:** Despite containing "regression" in its name, Logistic Regression is fundamentally a classification algorithm. It is a cornerstone topic frequently targeted in technical interviews and forms the bedrock architectural concepts used in deep learning (such as activation functions and cross-entropy losses).
* **Linear Decision Boundary:** It is a linear model. In a 2D space, the decision boundary is a line; in 3D, it is a plane; and in higher dimensions, it is a hyperplane.
* **Interpretation Dilemma:** It often feels counter-intuitive initially because its optimization structure differs from ordinary linear regression. We master it here through its highly elegant probabilistic interpretation.

---

## 2. Problem Setup: The Limitations of Hard Classification
Given a dataset containing two distinct classes (e.g., Red and Green), our objective is to determine a decision boundary that accurately separates them.

In a strict, binary classification framework, we require:
* Positive points (Green, labeled $y = 1$) to land in the positive region: $ax_1 + by_1 + c > 0$
* Negative points (Red, labeled $y = 0$) to land in the negative region: $ax_1 + by_1 + c < 0$

### Evaluating Models via Misclassifications
A naive approach evaluates a model's performance purely by counting its discrete misclassifications:

misclass = 0
for pt in points:
    if pt.color == "red" and (a * x1 + b * y1 + c) > 0:
        misclass += 1
    if pt.color == "green" and (a * x1 + b * y1 + c) < 0:
        misclass += 1

### The Breaking Point of Hard Counting
If two separate candidate models (boundaries) yield the exact same number of misclassifications, yet one has a slightly better slope that sits safer and further away from the data clusters, the discrete counting loop cannot differentiate between them.

Classification shouldn't be entirely black and white. Instead of utilizing a strict step function (which outputs a harsh 0 or 1), we must introduce a continuous function. We need a gradient of confidence:
* Points sitting very close to the line should receive low-confidence numbers.
* Points sitting far away from the line should receive high-confidence numbers.

---

## 3. The Sigmoid Function & Probabilistic Mapping
To transition from a hard step function to a smooth gradient, we utilize the Sigmoid function ($\sigma(z)$). It maps any real-valued number from $-\infty$ to $+\infty$ into a strict continuous probability space between $0$ and $1$.

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

### Defining Probabilities
Let the predicted probability of an observation $i$ belonging to the Green class be represented by $\hat{y}_i$ ("y-hat"):

$$\hat{y}_i = \sigma(z) = P(\text{getting green})$$

Where $z$ is the linear combination of inputs and weights:

$$z = \beta_0 + \beta_1 x_1 + \beta_2 x_2$$

Because probabilities must sum to 1, the probability that the observation belongs to the Red class is the complement:

$$1 - \hat{y}_i = P(\text{getting red})$$

---

## 4. Mathematical Derivation of the Loss Function

### Maximum Likelihood Estimation (MLE)
The likelihood function represents the product of the predicted probabilities for the actual true class of each observation.
* If the true label is Green ($y_i = 1$), we want $\hat{y}_i$ to be as close to $1$ as possible.
* If the true label is Red ($y_i = 0$), we want $(1 - \hat{y}_i)$ to be as close to $1$ as possible.

**Example Matrix:** Suppose we have a small dataset of 4 observations where the first two are Green ($y=1$) and the last two are Red ($y=0$). The Maximum Likelihood equation is written as:

$$\text{Likelihood} = \hat{y}_1 \cdot \hat{y}_2 \cdot (1 - \hat{y}_3) \cdot (1 - \hat{y}_4)$$

**Concrete Value Scenario:** If our model predicts probabilities of $0.8, 0.6, 0.7, \text{ and } 0.6$ for their respective true classes:

$$\text{Likelihood} = 0.8 \times 0.6 \times 0.7 \times 0.6$$

A larger product implies a superior model configuration. Our objective is to discover a model where this likelihood value is maximized.

### The Arithmetic Underflow Problem
In real-world applications containing thousands of data points, continually multiplying fractions between $0$ and $1$ results in numerical underflow (the value becomes too small for computer memory floating-points to accurately maintain).

To resolve this, we apply a natural logarithm ($\log$) across the product, converting the operations into a clean summation:

$$\log(\text{Likelihood}) = \log(\hat{y}_1) + \log(\hat{y}_2) + \log(1 - \hat{y}_3) + \log(1 - \hat{y}_4)$$

Because the logarithm of any number between $0$ and $1$ is strictly negative, our calculated value will be negative. To align this with standard mathematical optimization routines where algorithms seek to minimize error, we multiply the entire expression by a negative sign. We shift our target from maximizing likelihood to chasing the minimum negative log-likelihood.

$$-\log(\text{Likelihood}) = -\log(\hat{y}_1) - \log(\hat{y}_2) - \log(1 - \hat{y}_3) - \log(1 - \hat{y}_4)$$

### The Generalized Binary Cross Entropy / Log Loss Formula
Rather than writing split cases, we can mathematically condense the loss computation for any single data point into a single expression utilizing $y_i$ as an algebraic switch:

$$\text{Loss}_i = -y_i \log \hat{y}_i - (1 - y_i) \log(1 - \hat{y}_i)$$

* **When $y_i = 1$ (Green):** The right half cancels out: $-(1)\log \hat{y}_i - (0)\log(1 - \hat{y}_i) = -\log \hat{y}_i$
* **When $y_i = 0$ (Red):** The left half cancels out: $-(0)\log \hat{y}_i - (1)\log(1 - \hat{y}_i) = -\log(1 - \hat{y}_i)$

Averaging this master switch across all $n$ data points gives us the official Log Loss Error / Binary Cross Entropy ($L$) equation:

$$L = -\frac{1}{n} \sum_{i=1}^{n} \left[ y_i \log \hat{y}_i + (1 - y_i) \log(1 - \hat{y}_i) \right]$$

---

## 5. Optimization via Gradient Descent

### The Absence of a Closed-Form Solution
Unlike Ordinary Least Squares in linear regression, setting the derivative of the Log Loss function equal to zero leaves an equation that cannot be isolated algebraically. There is no closed-form analytical solution. We must approximate the optimal parameters using an iterative numerical optimization algorithm called Gradient Descent.

### The Gradient Descent Loop
1. Initialize the weights ($\beta_0, \beta_1, \beta_2$) with random values.
2. Continually update the weights by subtracting a fraction of the gradient scaled by the learning rate ($\eta$):

$$\beta_0 = \beta_0 - \eta \frac{\partial L}{\partial \beta_0}$$

$$\beta_1 = \beta_1 - \eta \frac{\partial L}{\partial \beta_1}$$

$$\beta_2 = \beta_2 - \eta \frac{\partial L}{\partial \beta_2}$$

---

## 6. Step-by-Step Mathematical Derivation of Gradients
Let us derive the partial derivative of our loss function with respect to weight $\beta_1$ for a single data point ($\frac{\partial L_i}{\partial \beta_1}$).

### Core Identities Needed:
* $\hat{y} = \sigma(z)$
* $z = \beta_0 + \beta_1 x_1 + \beta_2 x_2 \implies \frac{\partial z}{\partial \beta_1} = x_1$
* Derivative of Sigmoid: $\frac{\partial \hat{y}}{\partial z} = \sigma(z)(1 - \sigma(z)) = \hat{y}(1 - \hat{y})$
* Combined Chain Rule for Prediction: $\frac{\partial \hat{y}}{\partial \beta_1} = \frac{\partial \hat{y}}{\partial z} \cdot \frac{\partial z}{\partial \beta_1} = \hat{y}(1 - \hat{y})x_1$

### Differentiating the Individual Term Components:

#### Component A: Differentiating $-y \log(\hat{y})$
$$\frac{\partial}{\partial \beta_1} [-y \log(\hat{y})] = -y \cdot \frac{1}{\hat{y}} \cdot \frac{\partial \hat{y}}{\partial \beta_1}$$

Substitute our Chain Rule identity $\frac{\partial \hat{y}}{\partial \beta_1} = \hat{y}(1 - \hat{y})x_1$:

$$= \frac{-y}{\hat{y}} \cdot \hat{y}(1 - \hat{y})x_1$$

Cancel the common $\hat{y}$ terms:

$$= -y(1 - \hat{y})x_1$$

#### Component B: Differentiating $-(1 - y)\log(1 - \hat{y})$
$$\frac{\partial}{\partial \beta_1} [-(1 - y)\log(1 - \hat{y})] = -(1 - y) \cdot \frac{1}{1 - \hat{y}} \cdot \frac{\partial (1 - \hat{y})}{\partial \beta_1}$$

Note that $\frac{\partial (1 - \hat{y})}{\partial \beta_1} = -\frac{\partial \hat{y}}{\partial \beta_1}$. Substituting this eliminates the outer double negative:

$$= (1 - y) \cdot \frac{1}{1 - \hat{y}} \cdot \left[ \hat{y}(1 - \hat{y})x_1 \right]$$

Cancel the common $(1 - \hat{y})$ terms:

$$= (1 - y)\hat{y}x_1$$

#### Component C: Combining and Simplifying the Expressions
Now, add Component A and Component B together, factoring out the shared feature coordinate $x_1$:

$$\frac{\partial L_i}{\partial \beta_1} = \left[ -y(1 - \hat{y}) + (1 - y)\hat{y} \right] x_1$$

Expand the basic algebra within the brackets:

$$\frac{\partial L_i}{\partial \beta_1} = \left[ -y + y\hat{y} + \hat{y} - y\hat{y} \right] x_1$$

Notice that $+y\hat{y}$ and $-y\hat{y}$ cancel each other completely out:

$$\frac{\partial L_i}{\partial \beta_1} = (\hat{y} - y)x_1$$

### Total Global Gradient Formulations
Re-introducing our global sample size average $\frac{1}{n}\sum_{i=1}^n$, the final clean partial derivatives used inside the Gradient Descent loop are:

$$\frac{\partial L}{\partial \beta_1} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)x_{i1}$$

$$\frac{\partial L}{\partial \beta_2} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)x_{i2}$$

$$\frac{\partial L}{\partial \beta_0} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)$$
