# Gradient Boosting Classification

Gradient Boosting for Binary Classification builds an ensemble of models sequentially to predict binary outcomes (e.g., $0$ or $1$, Not Placed or Placed).

---

## 1. Regression vs. Classification in Boosting

| Feature | Gradient Boosting Regression | Gradient Boosting Classification |
| :--- | :--- | :--- |
| **Loss Function** | Mean Squared Error (MSE) | Log Loss (Binary Cross-Entropy) |
| **Prediction Space** | Raw continuous target values | **Log-Odds Space** ($-\infty$ to $+\infty$) |
| **Final Transformation** | Direct sum of tree outputs | **Logistic Sigmoid Function** $p = \frac{1}{1 + e^{-\text{(log-odds)}}}$ |

---

## 2. Core Transformation Formulas

1. **Log-Odds to Probability:**
   $$p = \frac{1}{1 + e^{-\text{log-odds}}}$$

2. **Residual (Pseudo-Residual):**
   $$r_i = y_i - p_i \quad \text{where } y_i \in \{0, 1\}$$

3. **Leaf Node Log-Odds Transformation ($\gamma$):**
   $$\gamma = \frac{\sum \text{Residuals}}{\sum \left[ p_{\text{previous}} \times (1 - p_{\text{previous}}) \right]}$$

### **Step 2: Train Tree $F_1$ & Assign Leaf Entry (`leaf_entry1`)**

#### **What is it?**
The regression decision tree $F_1(x)$ splits the data into leaf nodes:
* **Node #1:** Rows with `cgpa` $\le 6.375$ (Rows 1, 2, 3)
* **Node #3:** Rows with `cgpa` $> 6.375$ and `iq` $\le 132.5$ (Rows 0, 7)
* **Node #4:** Rows with `cgpa` $> 6.375$ and `iq` $> 132.5$ (Rows 4, 5, 6)

#### **What to do next?**
Transform the residual average outputs of each leaf into **log-odds updates ($\gamma$)**.

#### **Conversion Needed? YES!**
Decision tree leaves contain probability residuals. We **cannot** directly add probability residuals to log-odds predictions. We must convert leaf outputs to log-odds using:
$$\gamma = \frac{\sum \text{res1}}{\sum \left[ \text{pre1(prob)} \times (1 - \text{pre1(prob)}) \right]}$$

* **Node #1:** $\gamma_1 = \frac{3 \times 0.375}{3 \times (0.625 \times 0.375)} = \mathbf{1.6}$
* **Node #3:** $\gamma_3 = \frac{2 \times (-0.625)}{2 \times (0.625 \times 0.375)} = \mathbf{-2.67}$
* **Node #4:** $\gamma_4 = \frac{0.375 + 0.375 - 0.625}{3 \times (0.625 \times 0.375)} = \mathbf{0.18}$

## 6. Testing Phase Prediction Protocol

To predict for a test sample $X_{\text{test}} = (\text{cgpa} = 6.82, \text{iq} = 118)$:

1. **Start with Base Log-Odds:**
   $$\text{Log-Odds}_0 = 0.510826$$

2. **Add Leaf Output from Tree $F_1$:**
   * Sample falls into **Node #3** $\implies \gamma_1 = -2.67$.
   * $\text{Log-Odds}_1 = 0.510826 + (-2.67) = -2.159174$

3. **Add Leaf Output from Tree $F_2$:**
   * Sample falls into **Node #3** $\implies \gamma_2 = 1.09$.
   * $\text{Log-Odds}_2 = -2.159174 + 1.09 = -1.068349$

4. **Convert Final Log-Odds to Probability:**
   $$p_{\text{final}} = \frac{1}{1 + e^{-(-1.068349)}} = \mathbf{0.255717}$$

5. **Apply Threshold (0.5):**
   * Since $p = 0.255717 < 0.5 \implies \mathbf{\text{Class 0 (Not Placed)}}$.
