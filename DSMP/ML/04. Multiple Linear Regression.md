# Multiple Linear Regression (MLR)

## 1. The Transition to Real-World Data
In the real world, predictions rarely depend on just **one** factor. For instance, a student's placement package isn't just determined by CGPA; it depends on multiple **predictors** like IQ, 12th-board marks, profile strength, and technical skills.

```
Simple LR:    1 Input (e.g., CGPA) ───────────► Predicts Salary/Package
Multiple LR:  >1 Input (CGPA + IQ + Projects) ► Predicts Salary/Package
```

### The Geometric Shift: Line to Hyperplane
* In **Simple Linear Regression**, we fit a **2D Line of Best Fit** ($y = mx + b$).
* In **Multiple Linear Regression**, with 2 inputs, data becomes 3D, and the line becomes a **2D Plane** cutting through the space.
* For $n$ inputs, the model generalizes into an $n$-dimensional **Hyperplane**.


The general algebraic equation becomes:
$$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_n x_n + \epsilon$$

*Where:* $\beta_0$ is the intercept (analogous to $b$) and $\beta_1, \beta_2, \dots, \beta_n$ are the feature weights/coefficients (analogous to $m$).

---

## 2. Quick Workflow using `scikit-learn`
When using standard libraries, handling multiple predictors is straightforward. Instead of feeding a single column vector, we feed a multi-column matrix $X$.

```python
from sklearn.linear_model import LinearRegression
import pandas as pd

# Load data with multiple features
df = pd.read_csv('placement_multivariable.csv')
X = df[['cgpa', 'iq', 'projects']] # 2D Matrix (n_samples, n_features)
y = df['package']                 # 1D Target vector

# Instantiate and fit
mlr = LinearRegression()
mlr.fit(X, y)

print("Intercept (Beta_0):", mlr.intercept_)
print("Coefficients (Beta_1, Beta_2, Beta_3):", mlr.coef_)
```

## 3. The Mathematics Behind MLR (Matrix Form)
To manage multiple variables without messy equations, we bundle everything into matrices.

### Setting up the Matrices
Let's define our feature matrix $\mathbf{X}$, target vector $\mathbf{y}$, and coefficient vector $\boldsymbol{\beta}$ for $n$ observations and $m$ features:

$$\mathbf{X} = \begin{bmatrix} 
1 & x_{11} & x_{12} & \dots & x_{1m} \\
1 & x_{21} & x_{22} & \dots & x_{2m} \\
\vdots & \vdots & \vdots & \ddots & \vdots \\
1 & x_{n1} & x_{n2} & \dots & x_{nm} 
\end{bmatrix}_{(n \times (m+1))} 
\quad \mathbf{y} = \begin{bmatrix} y_1 \\ y_2 \\ \vdots \\ y_n \end{bmatrix}_{(n \times 1)}
\quad \boldsymbol{\beta} = \begin{bmatrix} \beta_0 \\ \beta_1 \\ \vdots \\ \beta_m \end{bmatrix}_{((m+1) \times 1)}$$

*Note:* A column of 1s is explicitly appended to the front of matrix $\mathbf{X}$ to pair with the intercept scalar $\beta_0$. 

Thus, our prediction vector $\mathbf{\hat{y}}$ simplifies directly to:
$$\mathbf{\hat{y}} = \mathbf{X}\boldsymbol{\beta}$$

### Setting up the Loss Function Matrix ($e^T e$)
The individual vertical error distances (residuals) are written as a vector $\mathbf{e}$:
$$\mathbf{e} = \mathbf{y} - \mathbf{\hat{y}} = \mathbf{y} - \mathbf{X}\boldsymbol{\beta}$$

To find the global Sum of Squared Errors ($E$), we perform a matrix dot product of the error vector with its own transpose ($e^T e$):
$$E = \mathbf{e}^T\mathbf{e} = (\mathbf{y} - \mathbf{X}\boldsymbol{\beta})^T(\mathbf{y} - \mathbf{X}\boldsymbol{\beta})$$

### The Matrix Proof (Step-by-Step)
Let's expand the error equation using the matrix transposition rule $(\mathbf{A}-\mathbf{B})^T = \mathbf{A}^T - \mathbf{B}^T$ and distribute the elements:

$$E = (\mathbf{y}^T - \boldsymbol{\beta}^T\mathbf{X}^T)(\mathbf{y} - \mathbf{X}\boldsymbol{\beta})$$
$$E = \mathbf{y}^T\mathbf{y} - \mathbf{y}^T\mathbf{X}\boldsymbol{\beta} - \boldsymbol{\beta}^T\mathbf{X}^T\mathbf{y} + \boldsymbol{\beta}^T\mathbf{X}^T\mathbf{X}\boldsymbol{\beta}$$

Because $\mathbf{y}^T\mathbf{X}\boldsymbol{\beta}$ computes down to a single scalar value, it is identical to its own matrix transpose $(\mathbf{y}^T\mathbf{X}\boldsymbol{\beta})^T = \boldsymbol{\beta}^T\mathbf{X}^T\mathbf{y}$. We can combine these middle terms:
$$E = \mathbf{y}^T\mathbf{y} - 2\mathbf{y}^T\mathbf{X}\boldsymbol{\beta} + \boldsymbol{\beta}^T\mathbf{X}^T\mathbf{X}\boldsymbol{\beta}$$

To minimize our loss, we take the partial derivative of $E$ with respect to the vector $\boldsymbol{\beta}$ and equate it to $0$:
$$\frac{\partial E}{\partial \boldsymbol{\beta}} = \frac{\partial}{\partial \boldsymbol{\beta}}(\mathbf{y}^T\mathbf{y}) - \frac{\partial}{\partial \boldsymbol{\beta}}(2\mathbf{y}^T\mathbf{X}\boldsymbol{\beta}) + \frac{\partial}{\partial \boldsymbol{\beta}}(\boldsymbol{\beta}^T\mathbf{X}^T\mathbf{X}\boldsymbol{\beta}) = 0$$

Applying standard matrix calculus derivative identities:
* $\frac{\partial}{\partial \boldsymbol{\beta}}(\mathbf{y}^T\mathbf{y}) = 0$
* $\frac{\partial}{\partial \boldsymbol{\beta}}(2\mathbf{y}^T\mathbf{X}\boldsymbol{\beta}) = 2\mathbf{X}^T\mathbf{y}$
* $\frac{\partial}{\partial \boldsymbol{\beta}}(\boldsymbol{\beta}^T\mathbf{X}^T\mathbf{X}\boldsymbol{\beta}) = 2\mathbf{X}^T\mathbf{X}\boldsymbol{\beta}$

Substituting these identities back gives:
$$-2\mathbf{X}^T\mathbf{y} + 2\mathbf{X}^T\mathbf{X}\boldsymbol{\beta} = 0$$
$$2\mathbf{X}^T\mathbf{X}\boldsymbol{\beta} = 2\mathbf{X}^T\mathbf{y} \implies \mathbf{X}^T\mathbf{X}\boldsymbol{\beta} = \mathbf{X}^T\mathbf{y}$$

Isolating the weight vector $\boldsymbol{\beta}$ by multiplying both sides by the inverse matrix $(\mathbf{X}^T\mathbf{X})^{-1}$ gives the **Normal Equation**:
$$\boldsymbol{\beta} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}$$

## 4. Implementing Multiple Linear Regression from Scratch
Here is how we turn the Normal Equation derived above into custom, clean Python code using `numpy` matrix calculations:

```python
import numpy as np

class CustomMultipleLinearRegression:
    def __init__(self):
        self.beta = None
        self.intercept_ = None
        self.coef_ = None
        
    def fit(self, X_train, y_train):
        X_train = np.array(X_train)
        y_train = np.array(y_train).reshape(-1, 1)
        
        # 1. Add a column of ones to account for the beta_0 intercept
        ones = np.ones((X_train.shape[0], 1))
        X_matrix = np.hstack((ones, X_train))
        
        # 2. Compute normal equation: beta = (X^T * X)^-1 * X^T * y
        # Using @ operator for matrix multiplication
        self.beta = np.linalg.inv(X_matrix.T @ X_matrix) @ X_matrix.T @ y_train
        
        # 3. Separate intercept and weight coefficients
        self.intercept_ = self.beta[0][0]
        self.coef_ = self.beta[1:].flatten()
        
    def predict(self, X_test):
        X_test = np.array(X_test)
        return (X_test @ self.coef_) + self.intercept_
```

## 5. The OLS Bottleneck Limit
While this closed-form Ordinary Least Squares (OLS) formula gives an exact analytical solution in a single step, it introduces a severe computational bottleneck on big data. 

Computing the matrix inverse operation $(\mathbf{X}^T\mathbf{X})^{-1}$ scales with a time complexity of **$O(m^3)$**, where $m$ is the total number of features. If your dataset contains a high number of features (e.g., $m > 10,000$), calculating the closed-form inverse calculation becomes highly inefficient, and we must shift to iterative optimization techniques like **Gradient Descent**.
