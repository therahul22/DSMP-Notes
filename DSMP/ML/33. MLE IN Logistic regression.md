# Maximum Likelihood Estimation (MLE) in Logistic Regression

---

## 1. Problem Formulation & Setup

In Logistic Regression, we are given a dataset with $n$ input features $X = \{x_1, x_2, x_3, \dots, x_n\}$ and a binary target variable $y \in \{0, 1\}$[cite: 1].

### Step 1: Target Distribution Assumption ($y \mid X$)
Since the label $y$ is binary ($0$ or $1$), we assume $y$ given $X$ follows a **Bernoulli distribution**[cite: 1]:
$$y \mid X \sim \text{Bernoulli}(p)$$

Where $p$ is the probability of the positive class ($y = 1$):
* $P(y = 1 \mid X) = p$
* $P(y = 0 \mid X) = 1 - p$

### Step 2: Parametric Model ($\beta$)
In Logistic Regression, the probability $p_i$ for observation $i$ is parameterized by weights $\beta = \{\beta_0, \beta_1, \dots, \beta_n\}$ mapped through the sigmoid function[cite: 1]:
$$p_i = \sigma(\beta^T X_i) = \frac{1}{1 + e^{-\beta^T X_i}}$$

### Step 3: Probability Mass Function (PMF)
The probability of observing a single ground-truth target $y_i$ is written as[cite: 1]:
$$P(y_i \mid X_i; \beta) = p_i^{y_i} (1 - p_i)^{1 - y_i}$$

#### How this formula acts as a smart switch:
* **When $y_i = 1$:** 
  $$P(y_i = 1) = p_i^{1} \cdot (1 - p_i)^{1 - 1} = p_i^{1} \cdot (1 - p_i)^{0} = p_i \cdot 1 = p_i$$
* **When $y_i = 0$:** 
  $$P(y_i = 0) = p_i^{0} \cdot (1 - p_i)^{1 - 0} = p_i^{0} \cdot (1 - p_i)^{1} = 1 \cdot (1 - p_i) = 1 - p_i$$

---

## 2. Derivations: Likelihood & Log-Likelihood

### The Joint Likelihood Function $L(y \mid X; \beta)$
Assuming all $n$ data samples are **independent**, the likelihood of observing the entire dataset is the product of individual probabilities[cite: 1]:

$$L(y \mid X; \beta) = P(y_1 \mid X_1) \cdot P(y_2 \mid X_2) \cdots P(y_n \mid X_n)$$
$$L(y \mid X; \beta) = \prod_{i=1}^{n} p_i^{y_i} (1 - p_i)^{1 - y_i}$$

### The Log-Likelihood Function $\log L(\beta)$
To prevent numerical underflow from multiplying small decimals and to simplify derivatives, we take the natural logarithm ($\log$)[cite: 1]:

$$\log L(\beta) = \log \left( \prod_{i=1}^{n} p_i^{y_i} (1 - p_i)^{1 - y_i} \right)$$

Applying log properties ($\log(a \cdot b) = \log a + \log b$ and $\log(a^b) = b \log a$)[cite: 1]:

$$\log L(\beta) = \sum_{i=1}^{n} \log \left( p_i^{y_i} (1 - p_i)^{1 - y_i} \right)$$
$$\log L(\beta) = \sum_{i=1}^{n} \left[ \log(p_i^{y_i}) + \log((1 - p_i)^{1 - y_i}) \right]$$
$$\log L(\beta) = \sum_{i=1}^{n} \left[ y_i \log(p_i) + (1 - y_i) \log(1 - p_i) \right]$$

---

## 3. What Needs to be Maximized vs. Minimized?

### What to Maximize: Log-Likelihood
In statistics, the objective is to find parameters $\beta$ that **maximize** the log-likelihood function[cite: 1]:

$$\hat{\beta}_{MLE} = \arg\max_{\beta} \sum_{i=1}^{n} \left[ y_i \log(p_i) + (1 - y_i) \log(1 - p_i) \right]$$

### What to Minimize: Binary Cross-Entropy Loss
In machine learning, optimization frameworks (like Gradient Descent) are designed to **minimize** a loss function. 

Multiplying the Log-Likelihood by $-1$ transforms it into a minimization task:

$$\text{Loss}(\beta) = -\log L(\beta) = -\sum_{i=1}^{n} \left[ y_i \log(p_i) + (1 - y_i) \log(1 - p_i) \right]$$

> **Key Takeaway:** Maximizing the Log-Likelihood is mathematically identical to minimizing Binary Cross-Entropy Loss[cite: 1].

## 4. Summary of Key Functions

| Concept / Term | Formula | Role / Function |
| :--- | :--- | :--- |
| **Sigmoid Function** | $p_i = \frac{1}{1 + e^{-\beta^T X_i}}$ | Maps linear combinations to probabilities between $0$ and $1$. |
| **Individual PMF** | $P(y_i) = p_i^{y_i} (1 - p_i)^{1 - y_i}$ | Expresses binary outcome probability in a single unified term[cite: 1]. |
| **Likelihood** | $L(\beta) = \prod_{i=1}^{n} p_i^{y_i} (1 - p_i)^{1 - y_i}$ | Measures plausibility of parameters $\beta$ across all data samples[cite: 1]. |
| **Log-Likelihood** | $\sum_{i=1}^{n} \left[ y_i \log p_i + (1-y_i) \log(1-p_i) \right]$ | Function to **maximize** to optimize parameters $\beta$[cite: 1]. |
| **Cross-Entropy Loss** | $-\sum_{i=1}^{n} \left[ y_i \log p_i + (1-y_i) \log(1-p_i) \right]$ | Objective function to **minimize** using Gradient Descent. |
