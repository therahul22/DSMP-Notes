# Introduction
Maximum Likelihood Estimation (**MLE**) is a fundamental statistical concept used heavily across machine learning—from classic algorithms like **linear regression** and **logistic regression** to deep architectures like **neural networks** and **softmax** classifiers. 

While it can feel highly mathematical, intimidating, and confusing at first, grasping its core intuition is essential. It serves as a bridge for understanding how machine learning models actually "learn" from data. Because of its foundational importance, it is a highly popular topic frequently targeted in technical interviews.

---

## 1. Probability vs. Likelihood

The confusion often begins with these two terms. They are essentially opposite viewpoints of the same mathematical function, depending on what you already know and what you are trying to find out.

| Feature | Probability | Likelihood |
| :--- | :--- | :--- |
| **What is known?** | The **parameters** of the distribution ($\mu$, $\sigma$, or $p$). | The observed **data / events** ($x_1, x_2, \dots, x_n$). |
| **What are we finding?** | The chance of a specific **event** occurring. | How plausible a specific **parameter** value is. |
| **Direction** | $\text{Parameter} \rightarrow \text{Event/Chance}$ | $\text{Event Data} \rightarrow \text{Parameter Plausibility}$ |

### Example 1: Tossing a Coin (Discrete Case)
Suppose you are dealing with a coin toss that follows a **Bernoulli distribution**, which has parameters $p$ (probability of Heads) and $q = 1 - p$ (probability of Tails). The Probability Mass Function (PMF) is:
$$p(x) = p^k (1-p)^{1-k} \quad \text{for } k \in \{0, 1\}$$

* **Probability Perspective:** You are explicitly told the coin is **fair** ($p = 0.5$). You want to calculate the chance of getting 5 Heads in a row ($HHHHH$). 
  $$\text{Probability} = (0.5)^5 = 0.03125$$
* **Likelihood Perspective:** Someone hands you a mysterious coin. You toss it 5 times and observe the data: $HHHHH$. You now doubt if the coin is actually fair. The **likelihood** measures how plausible a chosen parameter $p$ is, given your data. 
  * If you test $p = 0.5$: $L(p=0.5 \mid HHHHH) = (0.5)^5 = 0.03125$
  * If you test $p = 0.6$: $L(p=0.6 \mid HHHHH) = (0.6)^5 = 0.07776$
  * If you test $p = 1.0$: $L(p=1.0 \mid HHHHH) = (1.0)^5 = 1.0$

### Example 2: Height Estimation (Continuous Case)
Consider a continuous metric like human heights, which typically follows a **Normal (Gaussian) Distribution** governed by two parameters: mean ($\mu$) and standard deviation ($\sigma$). 

* **Probability Perspective:** Given a known population where $\mu = 150\text{ cm}$ and $\sigma = 10\text{ cm}$, you calculate the probability that a randomly drawn person's height falls between $170\text{ cm}$ and $180\text{ cm}$ (computed as the area under the curve).
* **Likelihood Perspective:** You observe a single data point of a person who is $100\text{ cm}$ tall. You evaluate the height of the Probability Density Function (PDF) at $x = 100$ to see how plausible different values of $\mu$ and $\sigma$ are. A model guessing $\mu = 100$ will yield a much higher likelihood value for this data point than a model guessing $\mu = 150$.

## 2. What is Maximum Likelihood Estimation (MLE)?

**Maximum Likelihood Estimation (MLE)** is a systematic method of estimating the unknown parameters of a statistical model given a set of observed data. Your goal is to find the exact parameter values that maximize the likelihood function—making the data you actually observed the most plausible outcome possible.

* In the **Coin Toss** example above, out of all possible values for $p$, the parameter value $p = 1.0$ gives the maximum possible likelihood ($1.0$) for the observed data ($HHHHH$). Thus, the MLE estimate $\hat{p} = 1.0$.
* In the **Height Estimation** example for a single data point ($x = 100$), the curve's peak (maximum likelihood value) occurs exactly when the distribution's mean matches that data point ($\mu = 100$).

## 3. Mathematical Derivation for Multiple Data Points (Normal Distribution)

When we observe more than a single data point, we can vary $\mu$ and $\sigma$ to see which combination maximizes the global likelihood of the entire dataset. 

### The Likelihood Function
Assuming that all collected data points ($x_1, x_2, x_3, \dots, x_n$) are **Independent and Identically Distributed (I.I.D.)**, the joint likelihood is the product of their individual probability density functions:

$$L(\mu, \sigma \mid x_1, x_2, \dots, x_n) = \prod_{i=1}^{n} \text{pdf}(x_i) = \text{pdf}(x_1) \cdot \text{pdf}(x_2) \cdots \text{pdf}(x_n)$$

For a Normal Distribution, the PDF for a single point $x_i$ is defined as:
$$\text{pdf}(x_i) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x_i - \mu)^2}{2\sigma^2}}$$

Substituting this in gives:
$$L(\mu, \sigma \mid x_1, \dots, x_n) = \prod_{i=1}^{n} \left( \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x_i - \mu)^2}{2\sigma^2}} \right)$$

### The Log-Likelihood Transformation
Maximizing a product of many small probabilities is computationally painful and prone to numerical underflow. Because the logarithm is a strictly increasing monotonic function ($a > b \implies \log a > \log b$), the value that maximizes the **Log-Likelihood** will perfectly match the value that maximizes the raw Likelihood. 

Using the logarithmic properties $\log(a \cdot b) = \log a + \log b$ and $\log(a^b) = b \log a$:

$$\log L(\mu, \sigma) = \sum_{i=1}^{n} \log \left( \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x_i - \mu)^2}{2\sigma^2}} \right)$$

Let's isolate a single term to simplify it before summing:
$$\log \left( (2\pi\sigma^2)^{-1/2} \cdot e^{-\frac{(x_i - \mu)^2}{2\sigma^2}} \right) = -\frac{1}{2}\log(2\pi\sigma^2) - \frac{(x_i - \mu)^2}{2\sigma^2}$$
$$= -\frac{1}{2}\log(2\pi) - \frac{1}{2}\log(\sigma^2) - \frac{(x_i - \mu)^2}{2\sigma^2}$$
$$= -\frac{1}{2}\log(2\pi) - \log(\sigma) - \frac{(x_i - \mu)^2}{2\sigma^2}$$

Summing this expansion across all $n$ independent data points yields our final **Log-Likelihood function**:
$$\log L(\mu, \sigma) = -\frac{n}{2}\log(2\pi) - n\log(\sigma) - \sum_{i=1}^{n} \frac{(x_i - \mu)^2}{2\sigma^2}$$

---

### Step 1: Derivation for Mean ($\mu$)
To find the optimal value for $\mu$, we take the partial derivative of the Log-Likelihood function with respect to $\mu$, set it equal to $0$, and solve:

$$\frac{\partial \log L(\mu, \sigma)}{\partial \mu} = 0 - 0 - \frac{1}{2\sigma^2} \sum_{i=1}^{n} 2(x_i - \mu)(-1) = 0$$
$$\frac{1}{\sigma^2} \sum_{i=1}^{n} (x_i - \mu) = 0$$

Since $\sigma^2 \neq 0$, we can eliminate the coefficient:
$$\sum_{i=1}^{n} (x_i - \mu) = 0$$
$$(x_1 - \mu) + (x_2 - \mu) + \dots + (x_n - \mu) = 0$$
$$(x_1 + x_2 + \dots + x_n) - n\mu = 0$$
$$n\mu = \sum_{i=1}^{n} x_i$$
$$\hat{\mu}_{MLE} = \frac{\sum_{i=1}^{n} x_i}{n}$$

> **Intuition:** The MLE for the mean ($\mu$) of a normal distribution is simply the standard **sample average** of your observed data points!

---

### Step 2: Derivation for Variance ($\sigma^2$)
Next, we take the partial derivative of the Log-Likelihood function with respect to $\sigma$, set it to $0$, and solve:

$$\log L(\mu, \sigma) = -\frac{n}{2}\log(2\pi) - n\log(\sigma) - \frac{1}{2}\sigma^{-2}\sum_{i=1}^{n}(x_i - \mu)^2$$

Recall standard derivative rules: $\frac{d}{d\sigma}(\log \sigma) = \frac{1}{\sigma}$ and $\frac{d}{d\sigma}(\sigma^{-2}) = -2\sigma^{-3}$.

$$\frac{\partial \log L(\mu, \sigma)}{\partial \sigma} = -\frac{n}{\sigma} - \frac{1}{2}(-2\sigma^{-3})\sum_{i=1}^{n}(x_i - \mu)^2 = 0$$
$$-\frac{n}{\sigma} + \frac{1}{\sigma^3}\sum_{i=1}^{n}(x_i - \mu)^2 = 0$$

Move $\frac{n}{\sigma}$ to the right side:
$$\frac{1}{\sigma^3}\sum_{i=1}^{n}(x_i - \mu)^2 = \frac{n}{\sigma}$$

Multiply both sides by $\sigma^3$:
$$\sum_{i=1}^{n}(x_i - \mu)^2 = n\sigma^2$$
$$\hat{\sigma}^2_{MLE} = \frac{\sum_{i=1}^{n}(x_i - \mu)^2}{n}$$

> **Intuition:** The MLE for variance ($\sigma^2$) maps precisely to the mathematical equation for **sample variance**.

## 4. How MLE Connects to Machine Learning

In parametric machine learning, algorithms assume an underlying data distribution and attempt to learn optimal parameters (like weights $\beta_0, \beta_1, \dots$ or $w$) from training data. 

### The General Pipeline in ML
1. **Analyze target distribution:** Figure out the conditional distribution of your target variable given the inputs ($y \mid x$).
2. **Select a parametric model:** Opt for a model that relies on explicit parameters (e.g., Linear Regression, Logistic Regression).
3. **Initialize weights:** Start with completely randomized parameter values.
4. **Define a Likelihood function:** Pick a function matching your distribution choice.
5. **Optimize:** Iteratively adjust the parameters until you find the values that yield the maximum likelihood value for the training data.

### MLE Implementation in Logistic Regression
In Logistic Regression, the target variable $y$ is binary ($0$ or $1$). Thus, we assume the conditional distribution $y \mid x$ follows a **Bernoulli distribution**. 

Instead of a fixed probability $p$, the probability of the positive class ($y=1$) changes dynamically based on the input features $x$ processed through the sigmoid function:
$$p_i = \sigma(w^T x_i) = \frac{1}{1 + e^{-w^T x_i}}$$

The Probability Mass Function for each individual data point is written as:
$$P(y_i \mid x_i) = p_i^{y_i} (1 - p_i)^{1 - y_i}$$

For the entire training dataset, assuming independent observations, the joint Likelihood is:
$$L(w) = \prod_{i=1}^{n} p_i^{y_i} (1 - p_i)^{1 - y_i}$$

Taking the natural log gives the **Log-Likelihood for Logistic Regression**:
$$\log L(w) = \sum_{i=1}^{n} \left[ y_i \log(p_i) + (1 - y_i) \log(1 - p_i) \right]$$

To train a Logistic Regression model using MLE, we search for the weight vector $w$ that maximizes this specific function. Notice that if you multiply this entire expression by $-1$, it becomes:
$$\text{Loss}(w) = -\sum_{i=1}^{n} \left[ y_i \log(p_i) + (1 - y_i) \log(1 - p_i) \right]$$
This is exactly the **Binary Cross-Entropy Loss** function used to train classifiers!

## 5. Key Interview Questions (FAQ)

### Q1. Is MLE applicable to all Machine Learning algorithms?
**No.** MLE is a general statistical framework meant specifically for **parametric** models (models defined by a fixed set of parameters like linear/logistic regression and neural networks). 
* **Non-parametric methods** (e.g., $k$-Nearest Neighbors, Decision Trees) do not assume a fixed data distribution and cannot use MLE.
* **Unsupervised algorithms** (e.g., $K$-means clustering) optimize geometric cluster distances rather than probability functions.
* **Reinforcement Learning** relies on maximizing cumulative rewards over time via environmental feedback loops, not distribution fitting.

### Q2. How is MLE related to Loss Functions?
They are two sides of the same coin. In machine learning, we talk about **minimizing a loss function** to reduce error. In statistics, we talk about **maximizing a likelihood function** to optimize data fit. For many common models, minimizing the loss function is mathematically identical to maximizing the likelihood under certain assumptions. 
* Minimizing Mean Squared Error (MSE) in Linear Regression $\equiv$ Maximizing MLE assuming Gaussian noise.
* Minimizing Binary Cross-Entropy Loss $\equiv$ Maximizing MLE assuming a Bernoulli distribution.

### Q3. Why do we talk about Loss Functions in ML instead of maximizing Likelihood?
* **Computational Efficiency:** Optimization algorithms (like Gradient Descent) are natively engineered to minimize objectives. Minimizing a loss function is often much cleaner and more computationally efficient to implement.
* **Generalization:** Not all machine learning tasks fit into clean probability distributions (like unsupervised tasks or decision trees), but almost any task can be assigned a loss function.
* **Flexibility:** Loss functions can easily be customized with penalties, such as adding $L_1$ or $L_2$ regularization terms to prevent overfitting.

### Q4. Why study MLE if we can just use Loss Functions?
Understanding MLE provides a formal statistical foundation for *why* specific loss functions are chosen in the first place. It provides deep interpretability regarding what your parameters actually represent, enables rigorous model comparison techniques (like AIC/BIC tests), and opens the door to advanced modeling fields like Bayesian inference and Expectation-Maximization (EM).
