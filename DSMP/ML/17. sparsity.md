# Understanding Sparsity: Lasso vs. Ridge Regression

## 1. What is Sparsity?
**Sparsity** means that a model's weight or slope vector ($m$) contains actual zeros. Instead of assigning a tiny fraction of importance to every single feature, a sparse model completely shuts off less important features by setting their coefficients to exactly `0`. This acts as automatic feature selection.

---

## 2. Why Sparsity Happens in Lasso, Not in Ridge
The structural difference lies entirely in where the regularization hyperparameter $\lambda$ lands after optimization:

* **In Ridge Regression ($L2$):** The penalty term adds $\lambda$ directly to the **denominator** of the slope equation:
  $$m = \frac{\sum (y_i - \bar{y})(x_i - \bar{x})}{\sum (x_i - \bar{x})^2 + \lambda}$$
  As $\lambda \to \infty$, the denominator grows massive, causing $m$ to shrink asymptotically closer to zero ($0.0001, 0.00001\dots$), but it mathematically never touches absolute zero.

* **In Lasso Regression ($L1$):** The penalty term places $\lambda$ directly into the **numerator** as a direct subtraction/addition force. If $\lambda$ becomes large enough, it completely nullifies the data correlation term in the numerator, forcing $m$ to equal exactly zero.

---

## 3. Mathematical Derivation of $m$ for Lasso
We start with the Lasso Loss function for a 2D line ($y = mx + b$):

$$L = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 + \lambda |m|$$

Substituting $\hat{y}_i = mx_i + b$ and the optimal intercept $b = \bar{y} - m\bar{x}$:

$$L = \sum_{i=1}^{n} (y_i - mx_i - \bar{y} + m\bar{x})^2 + \lambda |m|$$

To find the optimal slope $m$, we take the derivative with respect to $m$ ($\frac{\partial L}{\partial m}$) and set it to $0$. Because the absolute value function $|m|$ is non-differentiable at exactly $0$, we must analyze it by breaking it down into conditional cases based on the sign of $m$.

---

## 4. The 3 Cases for $m$ (Lambda vs. Coefficient Correlation)

Let the standard data correlation term be represented as:
$$D = \sum_{i=1}^{n} (y_i - \bar{y})(x_i - \bar{x})$$

### Case 1: When $m > 0$
For a positive slope, $|m| = m$, so the derivative $\frac{\partial |m|}{\partial m} = 1$.
$$\frac{\partial L}{\partial m} = 2 \sum (y_i - mx_i - \bar{y} + m\bar{x})(-x_i + \bar{x}) + \lambda = 0$$

Simplifying the summation algebra yields:
$$-2D + 2m \sum (x_i - \bar{x})^2 + \lambda = 0$$
$$m = \frac{D - \frac{\lambda}{2}}{\sum (x_i - \bar{x})^2}$$

* **Correlation:** There is a **strict inverse correlation** between $\lambda$ and $m$. Assuming $D$ is positive, as you increase $\lambda$, the numerator gets smaller, pulling $m$ down directly toward $0$.

### Case 2: When $m < 0$
For a negative slope, $|m| = -m$, so the derivative $\frac{\partial |m|}{\partial m} = -1$.
$$-2D + 2m \sum (x_i - \bar{x})^2 - \lambda = 0$$
$$m = \frac{D + \frac{\lambda}{2}}{\sum (x_i - \bar{x})^2}$$

* **Correlation:** When $m$ is natively negative, the data term $D$ is a negative number. By increasing $\lambda$, you add a positive value to a negative number, making it *less negative*. Therefore, **as $\lambda$ increases, $m$ increases from a negative value toward $0$.**

### Case 3: When $m = 0$ (The Sparsity Condition)
If the penalty strength $\frac{\lambda}{2}$ meets or exceeds the absolute value of the data correlation $|D|$, the numerator is completely wiped out:
$$\text{If } \frac{\lambda}{2} \ge |D| \implies m = 0$$

---

## 5. Why $m$ Stops Exactly at 0
Why doesn't an increasing $\lambda$ just push $m$ past zero into the opposite territory?

It cannot cross zero because the **direction of the regularization force instantly flips** the moment $m$ changes signs:
* If $m$ tries to drift slightly **positive ($m > 0$)**, the mathematical penalty instantly applies a **downward pull ($-\lambda$)** to drag it back to zero.
* If $m$ tries to drift slightly **negative ($m < 0$)**, the mathematical penalty instantly applies an **upward pull ($+\lambda$)** to drag it back to zero.

Because the math aggressively applies opposing forces from both sides of the origin, the coefficient gets **trapped perfectly at zero**. It cannot become too positive or too negative; it settles at the stable equilibrium point of absolute zero.
