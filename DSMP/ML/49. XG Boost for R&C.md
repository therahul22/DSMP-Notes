# Notes: XGBoost for Regression

## 1. Intro

* **Framework Core:** Even though XGBoost contains numerous performance and speed optimizations, its core mechanism is built directly upon **Gradient Boosting**.
* **Tree Building Distinction:** While standard Gradient Boosting uses vanilla Decision Trees (constructed via Gini Impurity, Entropy, or Variance Reduction), XGBoost constructs trees using specific custom criteria: **Similarity Score** and **Gain**.
* **Stage-Wise Learning:** Model predictions are built sequentially. Each subsequent tree is trained to predict the **pseudo-residuals** (errors) left behind by the combined model from the previous stage.

---

## 2. The Problem Statement

We are given a small continuous target dataset of 4 students to model a non-linear relationship between a student's **CGPA** ($X$) and their salary **Package** in LPA ($y$):

| Student | CGPA ($X$) | Package ($y$) |
| :---: | :---: | :---: |
| 1 | 6.7 | 4.5 |
| 2 | 9.0 | 11.0 |
| 3 | 7.5 | 6.0 |
| 4 | 5.0 | 8.0 |

* **Goal:** Train an XGBoost regression model to predict the salary package for a new student given their CGPA.

---

## 3. Solution Overview

```
 [ Base Estimator (Mean) ] ---> Residuals 1 ---> [ Decision Tree 1 ] * lr
                                                       |
                                                  Residuals 2 ---> [ Decision Tree 2 ] * lr ---> ...
```

1. **Stage 1 (Base Estimator):** Start with an initial naive guess independent of the features, which is the arithmetic mean of the target variable $y$.
2. **Pseudo-Residual Calculation:** Calculate the error (pseudo-residual) for every data point:
   $$\text{Residual} = y - \hat{y}$$
3. **Stage 2 (Tree Building):** Train a specialized decision tree using CGPA as the feature ($X$) and the computed residuals as the target variable ($y_{res}$).
4. **Shrinkage & Updating:** Scale the output of the decision tree by a learning rate ($\eta = 0.3$) to prevent overfitting, then add it to the base prediction:
   $$\hat{y}^{(\text{Stage 2})} = \text{Mean} + \eta \cdot \text{Tree}_1(X)$$
5. **Iterate:** Re-compute residuals against updated predictions and repeat for $N$ stages/trees until residuals approach zero.

---

## 4. Step-by-Step Calculation

### Step 1: Base Estimator & Stage 1 Residuals
* **Mean Prediction ($	ext{Model}_1$):**
  $$\text{Mean} = \frac{4.5 + 11.0 + 6.0 + 8.0}{4} = \frac{29.5}{4} = 7.375 \approx 7.3 \text{ LPA}$$
* **Residual 1 ($R_1 = y - 7.3$):**
  * Student 1 ($6.7$ CGPA): $4.5 - 7.3 = \mathbf{-2.8}$
  * Student 2 ($9.0$ CGPA): $11.0 - 7.3 = \mathbf{3.7}$
  * Student 3 ($7.5$ CGPA): $6.0 - 7.3 = \mathbf{-1.3}$
  * Student 4 ($5.0$ CGPA): $8.0 - 7.3 = \mathbf{0.7}$

---

### Step 2: Root Node Similarity Score
Place all initial residuals into a single root node: $\{-2.8, 3.7, -1.3, 0.7\}$.

* **Similarity Score (SS) Formula:**
  $$\text{Similarity Score} = \frac{\left(\sum \text{Residuals}\right)^2}{\text{Number of Residuals} + \lambda}$$
  *(where $\lambda$ is the $L_2$ regularization parameter; assumed $\lambda = 0$ for basic calculation).*

* **Root Node Calculation:**
  $$SS_{\text{Root}} = \frac{(-2.8 + 3.7 - 1.3 + 0.7)^2}{4 + 0} = \frac{(0.3)^2}{4} = \mathbf{0.02}$$

---

### Step 3: Determining the Root Split Criteria
Sort CGPA values: $5.0, 6.7, 7.5, 9.0$.  
Potential split thresholds (midpoints between adjacent values): **$5.85$**, **$7.1$**, and **$8.25$**.

#### Candidate 1: Split at $\text{CGPA} < 5.85$
* **Left Leaf ($SS_L$):** Residual $[0.7]$
  $$SS_L = \frac{(0.7)^2}{1 + 0} = 0.49$$
* **Right Leaf ($SS_R$):** Residuals $[-2.8, -1.3, 3.7]$
  $$SS_R = \frac{(-2.8 - 1.3 + 3.7)^2}{3 + 0} = \frac{(-0.4)^2}{3} = 0.05$$
* **Gain:**
  $$\text{Gain} = SS_L + SS_R - SS_{\text{Root}} = 0.49 + 0.05 - 0.02 = \mathbf{0.52}$$

#### Candidate 2: Split at $\text{CGPA} < 7.1$
* **Left Leaf ($SS_L$):** Residuals $[0.7, -2.8]$
  $$SS_L = \frac{(0.7 - 2.8)^2}{2} = \frac{(-2.1)^2}{2} = 2.20$$
* **Right Leaf ($SS_R$):** Residuals $[-1.3, 3.7]$
  $$SS_R = \frac{(-1.3 + 3.7)^2}{2} = \frac{(2.4)^2}{2} = 2.88$$
* **Gain:**
  $$\text{Gain} = 2.20 + 2.88 - 0.02 = \mathbf{5.06}$$

#### Candidate 3: Split at $\text{CGPA} < 8.25$
* **Left Leaf ($SS_L$):** Residuals $[0.7, -2.8, -1.3]$
  $$SS_L = \frac{(0.7 - 2.8 - 1.3)^2}{3} = \frac{(-3.4)^2}{3} = 3.85$$
* **Right Leaf ($SS_R$):** Residual $[3.7]$
  $$SS_R = \frac{(3.7)^2}{1} = 13.69$$
* **Gain:**
  $$\text{Gain} = 3.85 + 13.69 - 0.02 = \mathbf{17.52}$$

> **Decision:** Candidate 3 provides the maximum gain ($\mathbf{17.52}$). The root node split is chosen as **$\text{CGPA} < 8.25$**.

---

### Step 4: Second-Level Tree Splitting
The right leaf containing $[3.7]$ cannot be split further. We evaluate splits for the left node containing $\{0.7, -2.8, -1.3\}$ ($SS_{\text{Parent}} = 3.85$) across remaining potential thresholds: **$5.85$** and **$7.1$**.

```
                  Option A: Split at 5.85                   Option B: Split at 7.1
                  -----------------------                   ----------------------
               Parent Node [0.7, -2.8, -1.3]             Parent Node [0.7, -2.8, -1.3]
                        /         \                               /         \
                 Left [0.7]     Right [-2.8, -1.3]         Left [0.7, -2.8]   Right [-1.3]
                 SS_L = 0.49    SS_R = 8.40                SS_L = 2.20        SS_R = 1.69
                 Gain = 0.49 + 8.40 - 3.85                 Gain = 2.20 + 1.69 - 3.85
                      = 5.04 (WINNER)                           = 0.04
```

---

### Step 5: Output Values of Leaf Nodes
The leaf output formula (with $\lambda = 0$) evaluates to the simple average of residuals inside the leaf:
$$\text{Output Value} = \frac{\sum \text{Residuals}}{\text{Number of Residuals} + \lambda}$$

* **Leaf 1** ($\text{CGPA} < 5.85 \rightarrow \text{True}$): $\frac{0.7}{1} = \mathbf{+0.70}$
* **Leaf 2** ($\text{CGPA} < 5.85 \rightarrow \text{False}$, $\text{CGPA} < 8.25 \rightarrow \text{True}$): $\frac{-2.8 - 1.3}{2} = \mathbf{-2.05}$
* **Leaf 3** ($\text{CGPA} < 8.25 \rightarrow \text{False}$): $\frac{3.7}{1} = \mathbf{+3.70}$

---

## 5. Final Decision Tree & Updated Predictions

### Constructed Tree (Stage 2)

```
                       [ CGPA < 8.25 ]
                        /           \
                 (True)/             \(False)
        [ CGPA < 5.85 ]               Leaf 3
         /           \             Output: +3.70
   (True)/             \(False)
       Leaf 1          Leaf 2
    Output: +0.70   Output: -2.05
```

### Prediction Updates ($	ext{Model}_2$)
Using learning rate $\eta = 0.3$:
$$\hat{y}^{(\text{Stage 2})} = 7.3 + 0.3 \times (\text{Leaf Output})$$

| Student CGPA | Actual $y$ | Stage 1 Prediction | Leaf Traversal & Output | Stage 2 Prediction ($	ext{Model}_2$) | Residual 2 ($y - \text{Model}_2$) |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **6.7** | 4.5 | 7.3 | Leaf 2 ($-2.05$) | $7.3 + 0.3(-2.05) = \mathbf{6.69}$ | $4.5 - 6.69 = \mathbf{-2.19}$ |
| **9.0** | 11.0 | 7.3 | Leaf 3 ($+3.70$) | $7.3 + 0.3(3.70) = \mathbf{8.41}$ | $11.0 - 8.41 = \mathbf{2.59}$ |
| **7.5** | 6.0 | 7.3 | Leaf 2 ($-2.05$) | $7.3 + 0.3(-2.05) = \mathbf{6.69}$ | $6.0 - 6.69 = \mathbf{-0.69}$ |
| **5.0** | 8.0 | 7.3 | Leaf 1 ($+0.70$) | $7.3 + 0.3(0.70) = \mathbf{7.51}$ | $8.0 - 7.51 = \mathbf{0.49}$ |

> **Result:** Every residual magnitude has shrunk towards 0 ($|R_2| < |R_1|$), verifying that sequential tree additions push predictions closer to true values.

## 6. Original Paper Split Building Methods

The XGBoost research paper introduces two distinct tree construction algorithms based on dataset size:

1. **Exact Greedy Algorithm (Used in this lecture):**
   * Iterates through **every single unique feature value** across all features to evaluate candidate split points.
   * Guarantees finding the optimal split point.
   * Best suited for small-to-medium datasets that fit in memory.

2. **Approximate Algorithm:**
   * Uses weighted percentiles (Weighted Quantile Sketch) to group continuous features into discrete bins.
   * Evaluates split candidates only at bin boundaries instead of every data point.
   * Designed for high scalability on massive datasets or distributed environments.
