# XGBoost for Regression

## 1. Intro

* **Framework Core:** Even though XGBoost contains numerous performance and speed optimizations, its core mechanism is built directly upon **Gradient Boosting**.
* **Tree Building Distinction:** While standard Gradient Boosting uses vanilla Decision Trees (constructed via Gini Impurity, Entropy, or Variance Reduction), XGBoost constructs trees using specific custom criteria: **Similarity Score** and **Gain**.
* **Stage-Wise Learning:** Model predictions are built sequentially. Each subsequent tree is trained to predict the **pseudo-residuals** (errors) left behind by the combined model from the previous stage.

---

## 2. The Problem Statement

We are given a small continuous target dataset of 4 students to model a non-linear relationship between a student's **CGPA** ($X$) and their salary **Package** in LPA ($y$):

| Student | CGPA ($X$) | Package ($y$) |
| :---: | :---: | :---: |
| 1 | 6.7 | 4.5 |
| 2 | 9.0 | 11.0 |
| 3 | 7.5 | 6.0 |
| 4 | 5.0 | 8.0 |

* **Goal:** Train an XGBoost regression model to predict the salary package for a new student given their CGPA.

---

## 3. Solution Overview

```
 [ Base Estimator (Mean) ] ---> Residuals 1 ---> [ Decision Tree 1 ] * lr
                                                       |
                                                  Residuals 2 ---> [ Decision Tree 2 ] * lr ---> ...
```

1. **Stage 1 (Base Estimator):** Start with an initial naive guess independent of the features, which is the arithmetic mean of the target variable $y$.
2. **Pseudo-Residual Calculation:** Calculate the error (pseudo-residual) for every data point:
   $$\text{Residual} = y - \hat{y}$$
3. **Stage 2 (Tree Building):** Train a specialized decision tree using CGPA as the feature ($X$) and the computed residuals as the target variable ($y_{res}$).
4. **Shrinkage & Updating:** Scale the output of the decision tree by a learning rate ($\eta = 0.3$) to prevent overfitting, then add it to the base prediction:
   $$\hat{y}^{(\text{Stage 2})} = \text{Mean} + \eta \cdot \text{Tree}_1(X)$$
5. **Iterate:** Re-compute residuals against updated predictions and repeat for $N$ stages/trees until residuals approach zero.

---

## 4. Step-by-Step Calculation

### Step 1: Base Estimator & Stage 1 Residuals
* **Mean Prediction ($${Model}_1$$):**
  $$\text{Mean} = \frac{4.5 + 11.0 + 6.0 + 8.0}{4} = \frac{29.5}{4} = 7.375 \approx 7.3 \text{ LPA}$$
* **Residual 1 ($R_1 = y - 7.3$):**
  * Student 1 ($6.7$ CGPA): $4.5 - 7.3 = \mathbf{-2.8}$
  * Student 2 ($9.0$ CGPA): $11.0 - 7.3 = \mathbf{3.7}$
  * Student 3 ($7.5$ CGPA): $6.0 - 7.3 = \mathbf{-1.3}$
  * Student 4 ($5.0$ CGPA): $8.0 - 7.3 = \mathbf{0.7}$

---

### Step 2: Root Node Similarity Score
Place all initial residuals into a single root node: $\{-2.8, 3.7, -1.3, 0.7\}$.

* **Similarity Score (SS) Formula:**
  $$\text{Similarity Score} = \frac{\left(\sum \text{Residuals}\right)^2}{\text{Number of Residuals} + \lambda}$$
  *(where `λ` is the L₂ regularization parameter; assumed `λ = 0` for basic calculation).*

* **Root Node Calculation:**
  $$SS_{\text{Root}} = \frac{(-2.8 + 3.7 - 1.3 + 0.7)^2}{4 + 0} = \frac{(0.3)^2}{4} = \mathbf{0.02}$$

---

### Step 3: Determining the Root Split Criteria
Sort CGPA values: $5.0, 6.7, 7.5, 9.0$.  
Potential split thresholds (midpoints between adjacent values): **$5.85$**, **$7.1$**, and **$8.25$**.

#### Candidate 1: Split at $\text{CGPA} < 5.85$
* **Left Leaf ($SS_L$):** Residual $[0.7]$
  $$SS_L = \frac{(0.7)^2}{1 + 0} = 0.49$$
* **Right Leaf ($SS_R$):** Residuals $[-2.8, -1.3, 3.7]$
  $$SS_R = \frac{(-2.8 - 1.3 + 3.7)^2}{3 + 0} = \frac{(-0.4)^2}{3} = 0.05$$
* **Gain:**
  $$\text{Gain} = SS_L + SS_R - SS_{\text{Root}} = 0.49 + 0.05 - 0.02 = \mathbf{0.52}$$

#### Candidate 2: Split at $\text{CGPA} < 7.1$
* **Left Leaf ($SS_L$):** Residuals $[0.7, -2.8]$
  $$SS_L = \frac{(0.7 - 2.8)^2}{2} = \frac{(-2.1)^2}{2} = 2.20$$
* **Right Leaf ($SS_R$):** Residuals $[-1.3, 3.7]$
  $$SS_R = \frac{(-1.3 + 3.7)^2}{2} = \frac{(2.4)^2}{2} = 2.88$$
* **Gain:**
  $$\text{Gain} = 2.20 + 2.88 - 0.02 = \mathbf{5.06}$$

#### Candidate 3: Split at $\text{CGPA} < 8.25$
* **Left Leaf ($SS_L$):** Residuals $[0.7, -2.8, -1.3]$
  $$SS_L = \frac{(0.7 - 2.8 - 1.3)^2}{3} = \frac{(-3.4)^2}{3} = 3.85$$
* **Right Leaf ($SS_R$):** Residual $[3.7]$
  $$SS_R = \frac{(3.7)^2}{1} = 13.69$$
* **Gain:**
  $$\text{Gain} = 3.85 + 13.69 - 0.02 = \mathbf{17.52}$$

> **Decision:** Candidate 3 provides the maximum gain ($\mathbf{17.52}$). The root node split is chosen as **$\text{CGPA} < 8.25$**.

---

### Step 4: Second-Level Tree Splitting
The right leaf containing $[3.7]$ cannot be split further. We evaluate splits for the left node containing $\{0.7, -2.8, -1.3\}$ ($SS_{\text{Parent}} = 3.85$) across remaining potential thresholds: **$5.85$** and **$7.1$**.

```
                  Option A: Split at 5.85                   Option B: Split at 7.1
                  -----------------------                   ----------------------
               Parent Node [0.7, -2.8, -1.3]             Parent Node [0.7, -2.8, -1.3]
                        /         \                               /         \
                 Left [0.7]     Right [-2.8, -1.3]         Left [0.7, -2.8]   Right [-1.3]
                 SS_L = 0.49    SS_R = 8.40                SS_L = 2.20        SS_R = 1.69
                 Gain = 0.49 + 8.40 - 3.85                 Gain = 2.20 + 1.69 - 3.85
                      = 5.04 (WINNER)                           = 0.04
```

---

### Step 5: Output Values of Leaf Nodes
The leaf output formula (with $\lambda = 0$) evaluates to the simple average of residuals inside the leaf:
$$\text{Output Value} = \frac{\sum \text{Residuals}}{\text{Number of Residuals} + \lambda}$$

* **Leaf 1** ($\text{CGPA} < 5.85 \rightarrow \text{True}$): $\frac{0.7}{1} = \mathbf{+0.70}$
* **Leaf 2** ($\text{CGPA} < 5.85 \rightarrow \text{False}$, $\text{CGPA} < 8.25 \rightarrow \text{True}$): $\frac{-2.8 - 1.3}{2} = \mathbf{-2.05}$
* **Leaf 3** ($\text{CGPA} < 8.25 \rightarrow \text{False}$): $\frac{3.7}{1} = \mathbf{+3.70}$

---

## 5. Final Decision Tree & Updated Predictions

### Constructed Tree (Stage 2)

```
                       [ CGPA < 8.25 ]
                        /           \
                 (True)/             \(False)
        [ CGPA < 5.85 ]               Leaf 3
         /           \             Output: +3.70
   (True)/             \(False)
       Leaf 1          Leaf 2
    Output: +0.70   Output: -2.05
```

### Prediction Updates ($\text{Model}_2$)
Using learning rate $\eta = 0.3$:
$$\hat{y}^{(\text{Stage 2})} = 7.3 + 0.3 \times (\text{Leaf Output})$$

| Student CGPA | Actual $y$ | Stage 1 Prediction | Leaf Traversal & Output | Stage 2 Prediction ($\text{Model}_2$) | Residual 2 ($y - \text{Model}_2$) |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **6.7** | 4.5 | 7.3 | Leaf 2 ($-2.05$) | $7.3 + 0.3(-2.05) = \mathbf{6.69}$ | $4.5 - 6.69 = \mathbf{-2.19}$ |
| **9.0** | 11.0 | 7.3 | Leaf 3 ($+3.70$) | $7.3 + 0.3(3.70) = \mathbf{8.41}$ | $11.0 - 8.41 = \mathbf{2.59}$ |
| **7.5** | 6.0 | 7.3 | Leaf 2 ($-2.05$) | $7.3 + 0.3(-2.05) = \mathbf{6.69}$ | $6.0 - 6.69 = \mathbf{-0.69}$ |
| **5.0** | 8.0 | 7.3 | Leaf 1 ($+0.70$) | $7.3 + 0.3(0.70) = \mathbf{7.51}$ | $8.0 - 7.51 = \mathbf{0.49}$ |

> **Result:** Every residual magnitude has shrunk towards 0 ($|R_2| < |R_1|$), verifying that sequential tree additions push predictions closer to true values.

---

## 6. Original Paper Split Building Methods

The XGBoost research paper introduces two distinct tree construction algorithms based on dataset size:

1. **Exact Greedy Algorithm (Used in this lecture):**
   * Iterates through **every single unique feature value** across all features to evaluate candidate split points.
   * Guarantees finding the optimal split point.
   * Best suited for small-to-medium datasets that fit in memory.

2. **Approximate Algorithm:**
   * Uses weighted percentiles (Weighted Quantile Sketch) to group continuous features into discrete bins.
   * Evaluates split candidates only at bin boundaries instead of every data point.
   * Designed for high scalability on massive datasets or distributed environments.

# XGBoost for Classification

## 1. Intro
* **Underlying Foundation:** XGBoost for classification fundamentally follows the **Gradient Boosted Decision Trees (GBDT)** framework.
* **Core Philosophy:** Models are trained sequentially using **Stage-wise Additive Modeling**.
* **Tree Building Difference:** Standard GBDT uses vanilla decision trees (built via Entropy or Gini Impurity). XGBoost uses customized decision trees constructed via **Similarity Score (SS)** and **Gain**.

---

## 2. Prerequisite & Disclaimer

### Prerequisites
* **XGBoost for Regression:** Familiarity with XGBoost regression basics.
* **GBDT Classification:** General understanding of how gradient boosting solves binary classification.
* **Log of Odds:** Understanding logarithmic odds space and converting between odds and probabilities.

### Disclaimers
1. **Focus on Core Fundamentals:** XGBoost stands for *eXtreme Gradient Boosting* due to hardware, speed, and algorithmic optimizations. This lecture isolates the underlying mathematical flow rather than specific software optimizations.
2. **Calculation Focus:** Focus on conceptual understanding rather than minor manual arithmetic rounded values.

---

## 3. Problem Statement

We are given a toy binary classification dataset predicting whether a student gets **placed ($y=1$)** or **not placed ($y=0$)** based on their **CGPA ($X$)**:

| Student | CGPA ($X$) | Placed ($y$) |
| :---: | :---: | :---: |
| 1 | 5.70 | 0 |
| 2 | 6.25 | 1 |
| 3 | 7.10 | 0 |
| 4 | 8.15 | 1 |
| 5 | 9.60 | 1 |

* **Goal:** Construct an XGBoost classifier to predict placement probability for a student based on their CGPA.

---

## 4. Overview

```
Stage 1 (Base Model: Log-Odds) ---> Residuals 1 ---> Tree 1 * eta
                                                         |
                                                    Residuals 2 ---> Tree 2 * eta ---> ...
```

1. **Stage 1 (Base Estimator):** Start with an initial guess in log-odds space independent of features.
2. **Probability Conversion:** Convert log-odds predictions to probabilities using the logistic function.
3. **Pseudo-Residuals:** Compute errors ($y - p$).
4. **Stage 2 (Tree Building):** Build an XGBoost decision tree on residuals using **Similarity Score** and **Gain**.
5. **Update Model:** Multiply leaf outputs by learning rate ($\eta = 0.3$) and add to the base log-odds prediction.

---

## 5. Solution (Step-by-Step Calculation)

### Stage 1: Base Estimator & Pseudo-Residuals

#### 1. Calculate Initial Log of Odds
For binary classification, the base prediction $M_1$ is the target's overall log of odds:

$$\log(\text{odds}) = \log\left(\frac{p}{1-p}
\right)$$

Where $p$ is the proportion of positive targets ($y = 1$):
* Total samples ($N$) = $5$
* Positive class count ($y=1$) = $3$
* $p = \frac{3}{5}$, $1-p = \frac{2}{5}$

$$\text{Base Log-Odds} = \log\left(\frac{3/5}{2/5}
\right) = \log(1.5)  \approx \mathbf{0.405}$$

Every sample is initially assigned a prediction of **$0.405$** in log-odds space.

---

#### 2. Convert Log-Odds to Probability
Transform log-odds ($\text{LO}$) into probability ($p$) via the standard logistic function:

$$p = \frac{e^{\text{LO}}}{1 + e^{\text{LO}}} = \frac{e^{0.405}}{1 + e^{0.405}}  \approx \mathbf{0.60}$$

---

#### 3. Compute Initial Pseudo-Residuals ($R_1$)
$$\text{Residual}_1 = y_i - p_i = y_i - 0.60$$

| CGPA ($X$) | Placed ($y$) | Pred 1 (Log-Odds) | Pred 1 (Prob $p$) | Residual 1 ($R_1$) |
| :---: | :---: | :---: | :---: | :---: |
| **5.70** | 0 | 0.405 | 0.60 | $0 - 0.60 = \mathbf{-0.60}$ |
| **6.25** | 1 | 0.405 | 0.60 | $1 - 0.60 = \mathbf{0.40}$ |
| **7.10** | 0 | 0.405 | 0.60 | $0 - 0.60 = \mathbf{-0.60}$ |
| **8.15** | 1 | 0.405 | 0.60 | $1 - 0.60 = \mathbf{0.40}$ |
| **9.60** | 1 | 0.405 | 0.60 | $1 - 0.60 = \mathbf{0.40}$ |

---

### Stage 2: Building the XGBoost Classification Decision Tree

#### 1. Root Node Similarity Score (SS)
The formula for **Similarity Score in Classification** is:

$$\text{Similarity Score (SS)} = \frac{\left(\sum\text{Residual}_i
\right)^2}{\sum \left[ p_i \cdot (1 - p_i) 
\right] + \lambda}$$

*(Assuming regularization parameter $$\lambda = 0$$).*

For the root node containing all residuals $\{-0.60, 0.40, -0.60, 0.40, 0.40\}$:
* **Numerator:** $(-0.60 + 0.40 - 0.60 + 0.40 + 0.40)^2 = (0)^2 = 0$
* **Denominator:** $5 * [0.60 	* (1 - 0.60)] + 0 = 5 	* 0.24 = 1.20$

$$SS_{\text{Root}} = \frac{0}{1.20} = \mathbf{0}$$

---

#### 2. Evaluating Potential Split Criteria
Sorted CGPA: $5.70, 6.25, 7.10, 8.15, 9.60$.  
Split Thresholds (midpoints): **$5.97$**, **$6.67$**, **$7.62$**, **$8.87$**.

```
Split Candidate 1: CGPA < 5.97
  Left Leaf  [-0.60]             --> SS_L = (-0.60)^2 / (1 * 0.24) = 1.50
  Right Leaf [0.40,-0.60,0.40,0.40]--> SS_R = (0.60)^2 / (4 * 0.24)  = 0.375 ≈ 0.37
  Gain = 1.50 + 0.37 - 0 = 1.87

Split Candidate 2: CGPA < 6.67
  Left Leaf  [-0.60, 0.40]       --> SS_L = (-0.20)^2 / (2 * 0.24) = 0.08
  Right Leaf [-0.60, 0.40, 0.40] --> SS_R = (0.20)^2 / (3 * 0.24)  = 0.05
  Gain = 0.08 + 0.05 - 0 = 0.13

Split Candidate 3: CGPA < 7.62
  Left Leaf  [-0.60, 0.40, -0.60] --> SS_L = (-0.80)^2 / (3 * 0.24) = 0.888 ≈ 0.88
  Right Leaf [0.40, 0.40]         --> SS_R = (0.80)^2 / (2 * 0.24)  = 1.333 ≈ 1.33
  Gain = 0.88 + 1.33 - 0 = 2.22  (MAX GAIN)
```

$$
\rightarrow \mathbf{\text{Chosen Split Threshold: CGPA } < 7.62} \quad (\text{Gain} = \mathbf{2.22})$$

---

#### 3. Leaf Output Values
Formula for **Output Value in Classification**:

$$\text{Output Value} = \frac{\sum \text{Residual}_i}{\sum \left[ p_i \cdot (1 - p_i) 
\right] + \lambda}$$

* **Left Leaf ($\text{CGPA} < 7.62$):** Residuals $\{-0.60, 0.40, -0.60\}$  
  $$\text{Output}_L = \frac{-0.60 + 0.40 - 0.60}{3 	\times 0.24 + 0} = \frac{-0.80}{0.72} = \mathbf{-1.11}$$

* **Right Leaf ($\text{CGPA} \ge 7.62$):** Residuals $\{0.40, 0.40\}$  
  $$\text{Output}_R = \frac{0.40 + 0.40}{2 	\times 0.24 + 0} = \frac{0.80}{0.48} = \mathbf{+1.66}$$

---

### Stage 2 Prediction Updates & New Residuals

Using learning rate $\eta = 0.3$:

$$\text{Pred}_2 (\text{Log-Odds}) = 	\text{Base Log-Odds } (0.405) + 0.3 	\times (\text{Leaf Output})$$

$$\text{Pred}_2 (\text{Prob}) = \frac{e^{\text{Pred}_2(\text{Log-Odds})}}{1 + e^{\text{Pred}_2(\text{Log-Odds})}}$$

| CGPA ($X$) | Actual ($y$) | Pred 1 (LO) | Leaf Hit | Pred 2 (LO) | Pred 2 (Prob $p_2$) | Residual 2 ($y - p_2$) |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **5.70** | 0 | 0.405 | Left ($-1.11$) | $0.405 + 0.3(-1.11) = \mathbf{0.072}$ | $\frac{e^{0.072}}{1+e^{0.072}} = \mathbf{0.518}$ | $0 - 0.518 = \mathbf{-0.518}$ |
| **6.25** | 1 | 0.405 | Left ($-1.11$) | $0.405 + 0.3(-1.11) = \mathbf{0.072}$ | $\mathbf{0.518}$ | $1 - 0.518 = \mathbf{0.482}$ |
| **7.10** | 0 | 0.405 | Left ($-1.11$) | $0.405 + 0.3(-1.11) = \mathbf{0.072}$ | $\mathbf{0.518}$ | $0 - 0.518 = \mathbf{-0.518}$ |
| **8.15** | 1 | 0.405 | Right ($+1.66$) | $0.405 + 0.3(1.66) = \mathbf{0.903}$ | $\frac{e^{0.903}}{1+e^{0.903}} = \mathbf{0.712}$ | $1 - 0.712 = \mathbf{0.288}$ |
| **9.60** | 1 | 0.405 | Right ($+1.66$) | $0.405 + 0.3(1.66) = \mathbf{0.903}$ | $\mathbf{0.712}$ | $1 - 0.712 = \mathbf{0.288}$ |

> **Result:** Residuals progressively shrink toward zero across boosting rounds.

---

## 6. Outro

* **Iterative Progression:** Subsequent decision trees ($\text{Tree}_3, \text{Tree}_4, \dots$) are trained using feature $X$ and the updated residuals ($R_2, R_3, \dots$).
* **Combined Ensembling Formula:**  
  $$\text{Final Prediction (LO)} = 	\text{Base Log-Odds} + \eta \cdot 	\text{Tree}_1(X) + \eta \cdot 	\text{Tree}_2(X) + \dots$$
